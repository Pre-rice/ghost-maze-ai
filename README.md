# ghost-maze-ai

鬼迷宫的 AI 开发与谜题设计工作区。目标是产生极棒的谜题：布局简洁，推理公平，关键发现能让玩家重新理解眼前的关系。

训练 AI 是可选方法。当前结合设计构思、原生引擎搜索、反例检验和作者的实际试玩反馈，探索什么样的关系能带来巧妙发现。

## 可以看到什么

- [地图总目录](docs/ai-map-catalog.md)：已交付作品、参考解法、简评及来源，也保留未入集和撤回作品的记录。**含答案。**
- [地图集设计小册](https://github.com/Pre-rice/ghost-maze/blob/main/docs/map-design-guide.md)：精选作品的基本信息、设计思想与关键发现，供人查阅。**含解谜关键。**
- [持续设计方法](docs/methodology.md)：从真实正反反馈中总结的经验，以及这些经验怎样影响后续设计。

## 当前能力与局限

可以核对地图合法性，求解并证明最短步数，区分无解与预算内未知，检查所有并列最优的规则边界，并用具体反例检验设计设想。不同解法按鬼每一步移动与停顿的轨迹区分。

这些证据能检验方案是否成立，不能证明谜题有趣或令人顿悟。作品质量仍依据实际反馈，不把长路线、必要事件数量或搜索成本当作精妙程度。

已有规划模型和搜索对照实验，尚未证明训练模型能替代现有原生求解方法。当前没有把模型训练当作必须完成的阶段。

## 与游戏的关系

[鬼迷宫网站](https://ghostmaze.novic.cc/)用于游玩、回放和编辑；[游戏仓库](https://github.com/Pre-rice/ghost-maze)维护唯一玩法引擎及 AI 自主试玩 skill。本仓调用该引擎开展研究，获作者明确选择的地图才进入网站地图集。
