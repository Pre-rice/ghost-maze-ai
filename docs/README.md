## 追溯与可选路线

[archive索引](archive/README.md)分为 reviews（真实评述）、selection（当时筛选）、worklogs（阶段过程）、delivery（修复交付）、plans（可选计划）、research（调研）和既有 llm-workflow-v1。档案只在查证时读；已从中提炼的可用经验归methodology。

旧训练计划不是当前必走路线，旧代理指标也不自动取得质量资格。原始反馈、地图、证书和模型未训练的事实保持，不因文档整理补标签或重新生成作品。
