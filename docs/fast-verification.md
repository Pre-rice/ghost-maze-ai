# 快模拟器与 A* 验证

更新：2026-09-24。固定游戏规则仍为 `9825376f2cf93f844146c83214f680425c22498b`。

## 入口

```bash
npm run solve -- examples/puzzle-units/unit-02.json
npm run solve:fast -- examples/puzzle-units/unit-02.json
npm run solve:fast -- examples/puzzle-units/unit-02.json --nodes 0
```

`solve` 保留原引擎完整状态 BFS，作为独立对照；`solve:fast` 使用对齐后的紧凑模拟器和 A*。两者都只允许四方向与楼梯操作，按钮按实际站位和方向触发。

代码入口为 [快环境](../src/search/fast-environment.js)、[A*](../src/search/fast-solver.js) 和[差分测试](../test/reference/fast.test.mjs)。旧 `solveMap` 位于 `src/validate/solver.js`，现在是新 A* 的兼容包装，不再运行旧的预算外贪心预搜索。

## 已修正

- 规范化复用权威 `MapDefinition`，不再自行解释已淘汰出生点字段或按数组长度猜层数。
- 每次动作只拾取同格第一个物品，与当前游戏一致。
- 状态键保留体力、生命、终止标志、鬼顺序与物品顺序。
- 动态门位图改为 `BigInt`，避免第 33 位及之后与低位混淆。内部快状态不能直接 `JSON.stringify`；公开求解结果不含 BigInt。
- 墙采用写时复制，修改子状态不污染父态或兄弟分支。
- 胜利以真实 `isWon` 标志为准，出生点恰好等于终点不会凭空得到零动作证书。
- 下界使用所有层终点的多源 BFS，包含配对楼梯；放宽锁门、单向门、字母门和按钮占用，保留实墙、玻璃与活动格。
- A* 堆节点保留自己的代价和父链；过时队列条目不会因覆盖同键记录而混淆，证书用固定原引擎重放并核对终局物理状态。

## 结果和预算

沿用 [三态约定](reference-contract.md)，另有以下细节：

| 情况 | 结果 |
| --- | --- |
| 目标节点由 A* 正式取出 | `solved`，`optimality: proven` |
| 预算中断，但已发现可重放解 | `solved`，`optimality: not_proven` |
| 预算中断且没有证书 | `unknown` |
| 乐观距离仍不可达 | `proven_unsat`，`reason: relaxed_unreachable` |
| 搜索前沿穷尽 | 根据是否有证书返回已解或 `proven_unsat` |

不会因为贪心没找到、达到节点上限或耗时超限而标成无解。时间预算为软限制，环境准备和最终原引擎重放不计入搜索时限；状态数不是精确字节内存上限。

旧兼容字段 `solvable` 现在为 `true / false / null`，`null` 表示未知。`confidence: approx` 对应有证书但未证明最优；旧 `minSteps` 只是当前证书的成功动作数，应结合 `optimality` 解释，移动成本另看 `movementCost`。

`withGhosts:false` 是去鬼后的诊断实验，结果明确带 `scope.withGhosts:false`，不能当作原图无伤证书。旧结构验证接口同样保留未知状态。旧 CLI 遇到未知返回退出码 3；它保留的阶段筛选和威胁门仍仅属于旧基线政策。

## 资源支配剪枝

完整去重键仍保留体力。A* 另建专用于支配判断的布局分组：其他物理状态完全相同，若已有路线的成功动作数更少或相等、剩余体力更多或相等，则新路线没有更强的无伤后续能力，可以剪去。

动作更少但体力也更少，与动作更多但体力更多的路线互不支配，均保留。这个判断依赖固定规则中的体力单调消耗和无复活搜索范围；规则升级后须重新审计，不能把省略体力的分组键当成等价状态键。

## 验证证据

- 24 张固定种子的微型地图，分别在探索和死亡循环模式运行 120 步差分。
- 两种模式下各 200 步多层差分，覆盖按钮、楼梯、鬼转层和重置。
- 上述合计至少 6,160 次动作对照，另外检查终止后的复活；逐步核对玩家、资源、鬼顺序、物品、动态墙和胜负，验证父态不被写入污染。
- 在 24 张微图上与独立参考 BFS 比较可解性和最短成功动作数。
- 定向案例覆盖 33 位以上的门状态、同格多钥匙、预算三态、初始站在终点、跨层绕行及多个终点。

这些是有限回归与差分覆盖，不是所有可能地图上的形式化等价证明。两张已知种子不变，最短动作仍为 10 和 13，第二题移动成本为 12。

## 小规模性能记录

| 单元 | 原引擎 BFS 中位耗时 | 快 A* 中位耗时 | BFS / A* 展开数 | 解长 |

| unit-01 | 34.92 ms | 2.05 ms | 47 / 16 | 10 |

仅说明这两个小案例上的改善；大图仍可能因状态空间和预算返回未知，不能据此推断训练收敛时间或普遍加速倍数。
