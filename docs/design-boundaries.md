# 当前谜题设计与资料复用边界

更新：2026-10-13。本页为现行要求；旧严格审查、回放与调整依据见[历史审查](archive/reviews/rule-boundaries-20261012.md)。

1. **规则一致。** 运行、搜索、证书、回放共用同级本体；规则内容锁核对。鬼争同一格时仍能看见玩家新位置者优先，最高优先级相同共同入格；夹击玩家共同进入、死亡扣一次生命。编号、数组顺序不决定行为。不可见边缘判断不能成为解谜点。
2. **全部最优的重合边界。** 对全部并列最优无伤无复活解检查，任一利用非死亡重合就拒绝；仅一条参考安全不够。夹击死亡与非最优通关中的重合允许。未来训练资料与呈现地图沿用同一标准，不扩大为“任一错误分支重合都拒绝”。
3. **玻璃只辅助观察。** 换为实墙后，全部可达物理局面与实际动作后继必须一致，观察／探索差异可保留；不能只检查所选参考仍能通关。未完成检查为未知。
4. **可组合的中性入口。** 后续尽量开局不被追，可以先观察。真的从外部进入一步，再比较玩家、鬼、门和物品；指定初相位、钥匙数及区外鬼条件写清。单元可解不代表整图兼容，整图还要重新验证。
5. **合法动作与分享。** 完整地图校验、按钮依附和楼梯配对；独立证明解与最优性，地图码和操作码往返逐局面核对。去终点重放确认安全，不利用先判胜掩盖追击；网页只在新增规则或交互时集中检查。
6. **证据范围。** 禁止原图事件、删除门或鬼、只选最优路线是不同问题。明确全解／最优／单条路线的范围；穷尽无解与预算未知分开，必要性与解长均不赋予趣味标签。
7. **复用与真实反馈。** 当前复用名单见[policy](../data/manifests/puzzle-library-policy.json)，全部亲缘组整体拆分。旧源图、真人原反馈和证书不覆盖，不转移好评；只记录实际收到的定性反馈与体验条件。

《借影》已按用户授权维护，原59步控距安置仍保持；其余已确认图保持。历史失败或未拟复用地图不批量审查，不以档案中存在为当前通过。质量审查与反馈维护见[方法](methodology.md)。
