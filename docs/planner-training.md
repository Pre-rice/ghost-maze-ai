# 求解训练的当前实验

用户于2026-10-15明确恢复主线训练。本轮先用本地CPU检验求解能力，不训练人类质量评分器；目标仍是产出精品谜题，模型拟合与作品质量不能互相替代。原阶段在`research/planner-baseline-20261015`隔离保存；用户批准网页正式发布并恢复主线后，现整合到main。十三张地图保持。

## 可复现入口

同级本体须为对应规则快照，先运行`npm run check`。Node22负责原生物理标签，Python3负责CPU树模型；本轮环境为NumPy2.3.5、scikit-learn1.8.0，不需要GPU或外部付费调用。

```sh
npm run prepare:library -- runs/<新实验>/verified-library
node scripts/prepare-planning-graph.mjs runs/<新实验>/verified-library runs/<新实验>/graph
python3 scripts/train-planning-baseline.py runs/<新实验>/graph runs/<新实验>/baseline
```

所有输出目录必须不存在，旧原件不覆盖。训练输入二进制与行表均校验哈希。模型、数据与完整轨迹只放ignored的runs和新私人包；Git保存脚本、证据摘要与决策依据。

## 监督与验收边界

- 标签只来自穷尽共同引擎后的反向BFS，预算未知不能提供精确距离。保留全部同长安全动作，不把参考路线之外的最优动作当错误。
- 使用全信息局面和原生一步后继；不输入标题、mapId、亲缘组、步号、精确剩余成本、未来动作或人类评分。物理原图不变。
- 正例限最优且不依赖非致死鬼重合的后继。已审十三图的初态安全最短与物理最短一致，不能推及任意图。
- 以亲缘组整体留出，绝不随机拆步骤。当前十三图仅两个保守家族，交叉评估只能作为开发诊断，不能宣称独立泛化。
- 固定三种随机种子，比较参考路线局面、全部可续解局面与手工距离基线，完整报告失败。按地图平均动作准确率；另外做闭环通关、最优性与搜索量比较。
- 模型仅调整A*同一合法下界优先级内的次序，不替换规则、不剪掉物理解。离线节点数不能冒充实际速度；若离线没有收益，不进入网站。

## 本轮判断

已完成分类、表示修复、同图拟合诊断、原生计时与剩余成本回归，见[实验记录](archive/research/planner-baseline-20261015.md)。V2消除当前225组表示冲突，同图13/13最优，但整家族留出策略仍0/13；模型辅助原生搜索约慢5.8倍。仅排序同下界的理论可省量不足1%，此加速方案不进入网站。学习找可行解的成本模型也弱于手工基线。

后续实验采用独立程序练习资料：只训练机械规划，不把生成数算精品数；生成器作为一个家族，种子留出只声明同分布机械检验。地图集全部留出作开发挑战，既有家族结果不能重新称全新测试。

已完成48练习训练／24同生成器留出：闭环模型19–20/24，手工16/24，最优没有稳定提升；精品仍0/13。完整回溯能使两种排序都通关，学习在精品少展开一些，但相对随机排序不稳定，且多数路线非最优。后续检验低成本模型的实际收益，不能直接替换网站最优求解。

关系输入、缩小模型和鬼额外成本监督均已实测；部分基础闭环提升到21–22/24，但精品仍0–1/13且非最优，计入成本后没有整体替换价值。去鬼子问题已验证11190局面下界合法，减少搜索量而未加快当前单次求解；默认关闭，网站不接入。补入12张长程练习后，两张长程留出仍全部直接失败；样本很少，不能推论所有长程训练无效。两种权重均完整保留，没有精品迁移改善。

## 上阶段结果

给定两个明确鬼停位目标，单独检验局部安排能力，未修改游戏胜负。19张练习母图的45个任务用于训练，4张留出母图9个任务用于同生成器检验；9张适用精品母图29个任务仅作既有开发挑战，任务不是独立地图。输入不含是否必须腾位、鬼身份或未来答案。

三种子模型完成同生成器3–5/9任务、最优2/9；手工进度基线完成5/9、最优4/9。精品给定目标完成5–7/29、最优0/29；其中15个必须腾位任务全部失败，14个必须保持原鬼的对照仅完成5–7个。不能把子任务完成写成原游戏通关，更不能称学会设计精妙谜题。304条成功及失败前缀均已原生复核。

对称鬼状态归并是独立的确定性优化：当前13图展开8345→7749，同批本机约104.60→99.36ms；幅度小，默认关闭，有历史身份监控时拒绝启用，未接入网站。它不算模型进展。

上述阶段按当时指令收尾暂停；用户随后明确批准网站发布并恢复主线，现从失败诊断继续。实际缺口是长程条件规划、跨结构迁移，以及自主选择和组合子目标；本阶段没有训练人类质量评分器，没有新增精品。完整结果、失败与协议见[阶段记录](archive/research/planner-baseline-20261015.md)及[证据v5](../data/manifests/planning-training-cpu-20261015-v5.json)。

## 恢复后的固定资料对照

用户批准网站发布并恢复主线后，先复盘旧闭环：精品15个必须腾位目标、三种子45次尝试全部进入不可恢复状态，不是仅在活路上绕圈。用同一7921训练候选、1650维输入和控制器，区分“仍可完成目标”及“剩余目标成本”监督，没有稳定提升；每次必须腾位仅0–1/15成功且非最优。342条全部尝试已原生复核，模型不进入网站。结果与复现命令见[本轮记录](archive/research/planning-recovery-objectives-20261015.md)。

据此不继续只调单步标签或随机加图；已继续完成显式多步后路检查与相同预算上限的手工／随机对照。这个判断只适用于当前资料与模型，不能推论训练无效；给定目标规划也仍未解决自主选择和组合子目标。

## 有界规划的后续结果

原动作分类配合每候选8次安全展开，精品给定目标完成由5／7／7提高到17／17／18（29任务），其中必须腾位完成7／5／7（15任务），模型最优仍0。同预算上限的手工12/29、随机14／14／10；三类都明显受益于搜索，不能把全部进步归给模型。64展开未稳定更好，部分任务过早耗尽共享4096预算。零展开266条旧路线完全重现，全部798条新对照成功／失败前缀已原生复核；没有新增图或质量标签。[详细结果与限制](archive/research/planning-bounded-lookahead-20261015.md)。

下一步复用已展开图、让未知可以继续，比较完整规划的相同预算对照并实测原生成本；给定目标规划仍未解决目标选择、组合和精品生成。不接入网站。
