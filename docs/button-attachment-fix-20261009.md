# 按钮依附漏检与修正（2026-10-09）

用户指出“按钮必须依附在墙上”。原候选 `borrowed-shelter-20261009` 的 B 按钮在 `(1,4)` 指向左侧，但 `vWalls[4][1]` 为 EMPTY，左邻格也已激活，实际没有墙面。这是生成合法性漏检，原版已撤回；[修正版试玩入口](../examples/borrowed-shelter-wallfix-20261009/README.md)独立保存。

本体动作入口按按钮坐标及方向触发，没有检查墙面依附；原版因此可以通关。可通关证书只能证明物理路线成立，不能代替地图合法性检查。此前的浏览器审查也漏掉了这处悬空按钮。

修正仅将 B 改为向上，依附同格已有实墙 `hWalls[4][1]`，没有补墙改变通路。改变方向也恢复了原按钮占用的左移动作，所以重新验证了修正版，而不是直接沿用旧图结论。原图、证据、分享码和真实录制均保留，不改写历史数据；用户反馈仅记录合法性错误，不补谜题质量标签。
