# 怎样持续设计更好的谜题

目标是产生极棒的地图，让玩家经过推理，发现可理解却不明显的巧妙解法。当前以精妙单元为主；以后进入整图时仍要验证单元间的联系与实际入场。训练 AI、人工提出点子与程序搜索都是可选手段，投入多少样本或完成哪个训练阶段，不替代作品质量。

## 尤里卡时刻改变了什么

好的突破常常改变玩家对一个已有元素的理解。玩家先有一个合理但不充分的计划，遇到明确的矛盾，再发现已知机制还能承担另一种作用；理解后，原来的阻碍和解法连成一个整体。这是当前依据反馈形成的工作假说，不能当成万能配方，也不要求每题都制造陷阱或模仿同一套路。

三个由用户亲自总结的例子：

| 图 | 认识的改变 | 可继续探索的设计问题 |
| --- | --- | --- |
| 《错位》 | 按钮操作可以使鬼靠近、激活追逐，把它引离入口 | 一种通常用来开路的操作，还能改变什么前提？ |
| 《接力》 | 靠近门的开关可用于困鬼，且需先安排另一只鬼 | 一个操作的安全，怎样依赖先前看似无关的安排？ |
| 《再借》 | 重新引动已安置的鬼，让威胁变成挡住另一鬼的工具 | 看似已经完成的事情，为什么还必须重新启用？ |

这三个例子共同支持“用途重理解与相互准备”的价值，不证明两鬼、字母门、三次按钮或长路线普遍精妙。《借影》另提供控距走位的正例，肯定来自看回放后的发现；《回环》是带五步提示后的有限肯定。完整作品、简评和体验条件见[地图集设计小册](https://github.com/Pre-rice/ghost-maze/blob/main/docs/map-design-guide.md)。

难点应来自关系，而不是隐藏信息。发现后应能解释为什么有效，也应能用此前看得见的布局和规则推导出来。不要把未知编号、不可见追逐记忆、对称重合或有争议的玻璃行为当成惊喜。规则优先机制可以像《再借》一样按公开位置与视线使用，仍需排除全部最优解中的重合。

| 《先手》重复 A，《借舍》左上与突出出生格 | 有路线或保留多个最优收尾，不等于格子、按钮有推理价值 | 分别检查出生点内移、支路、重复按钮和任务钥匙；删后若核心不变，应删或给出具体保留理由 |
| 《暂驻》去掉钥匙任务后仍获肯定 | 必经路上的任务标签可以删去，少量门也能承载挑战 | 钥匙、门槛和额外结构究竟改变什么判断？少一格却多绕路也不是自动改进 |
| 《换岗》的入场意见与争位机制纠正 | 单元要可观察、可接入，规则应一致且符合直觉 | 中性初态之外，真的执行进入一步，核对鬼、门、物品；检查编号不参与后继 |
| 本轮追加目标中，39份改稿虽使旧前缀失效，仍可插入取物后照搬原引鬼与切门 | 一条具体旧走法失效，不足以证明需要新的总体认识；安全取物机会也可能只是独立差事 | [研究与反例](archive/research/objective-preparation-20261016.md)：把“同一已知计划加不动鬼的准备”纳入普通替代，参考进度进入完整键；只排除具体机械重复，不把没有这类证书当趣味分，也不改变网站含停顿的解法分组 |
| 《送客》被明确指出与上一张核心相同、反而更简单，浪费试玩时间 | 有安全错误计划、多个必要事件和简洁轮廓，仍可能只是旧解法；交付筛选不能由规则QA替代 | [原话与处理](../data/manifests/see-off-review-20261017.json)：构造前先写熟悉旧题者需要新增哪项理解，精简后再审是否还存在；同母图换目标、改收尾或删准备条件不自动成为新作品。重复稿留研究，不以候选数量体现持续推进 |
| 《转圜》有分队、保护失效、重开和借鬼等必要条件，用户仍表示“随便就试出来”“根本没有解谜深度” | 已知套路的局部组合仍可快速试出；方法已有原则却未在交付中执行，不能再加一层必要性就称更深 | [实际评述](../data/manifests/turning-room-review-20261017.json)：把用户已经会的引鬼、隔门安置、重新招回卡位当作已知能力，先审是否还需新认识。当前暂停这组相似交付，构件留研究；不补写用户实际路线，不否定已有好评图 |
| 《互锁》机器上确需至少三段控制位置，用户仍评价“没让我感觉到新意”“平平无奇”；没有报告具体思考路线 | 不同的控制顺序与可达约束，还不等于玩家必须重新理解某种用途；不能只换一套结构后继续以新题交付 | [原话与判断修正](../data/manifests/interlock-review-20261017.json)：暂停这一方向的相似交付，包括尚未交付的不可逆开路／控制移交构件。下一轮先写已有经验会给出的合理整体计划、哪里不足及需改变哪项认识；只增加换面或按键次序不放行。不是断言所有双操作面均无潜力，也不补写用户实际走法 |
| 《回望》获“不错”并原版入集；双0研究稿让相同门承担先开通路与暂留屏障两种用途 | 规划价值可以来自同一类元件的不同后续作用，不靠更多钥匙；用户未具体报告顿悟，不补写感受 | [实际门态对照](archive/research/objective-preparation-20261016.md#后续从真实局面提取门的准备作用)核对其余物理局面相同的有无后路；区分全解与仅最优必要。新增B只为强制用门也不自动增强，下一张先审是否多了一项需要理解的关系；对照数量不当质量分 |
| 20步原型的0改空仍保留同一最佳动作与鬼轨迹，上A改空虽同20步却必须换路线；三次按钮也可能只是同处连按 | 必要动作或相同解长不直接说明元件性质及新认识；区分完整方案与只看N | [本轮反例](archive/research/gate-protection-followup-20261016.md)：同时审门改空／改墙、原路线能否重放和关键关系是否仍成立；双操作面先排除串行与重复按键，不把检验数量或机器必要性当趣味分 |
| 自动安排研究中，相同鬼位、门及资源仍因玩家所在区域不同而有无后路 | “已安置”须同时说明玩家获得了什么活动空间，不能只记鬼停在哪 | [真实前缀与反例](archive/research/automatic-arrangements-20261016.md)：目标包含玩家可逆区域并绑定原图；数量不代表趣味，完整求解后的分析不冒充自主规划或提速 |
| 11格反例的全部最优都不穿0门，改普通门后却从8步降为6步（设计者核验） | 元件能通过保留保护、排除替代计划发挥作用；未出现在参考路线，不等于无价值 | [可复验反例](archive/research/unspent-gate-20261017.md)：分别核对使用事件、原图失败与改图替代，不凭参考解未经过判冗余，也不把这项小关系当新意或挑战证明 |

《调度》原25格版本获用户明确好评，称其“非常优美，非常有趣”“集大成者”；用户实际报告从尝试在外围困鬼，转向安排内圈鬼位。这支持匀称结构与用途重理解可以共同帮助体验，不证明5×5、三鬼或多次调度普遍有效。同时，用户发现关门丢失了本应保留的当步追击：原引擎只保存旧玩家坐标，却用新墙态检查旧视线。修正后原50步失效，70步新最优会把鬼带出内圈；原版好评不得移给新规则或未来改稿。下次新机关先对照“操作前墙态和位置→操作后墙态和位置→新墙态允许的一步”，不能用同源求解与回放自洽代替规则直觉验收。[真实评述与影响](archive/reviews/pre-action-vision-20261018.md)。

用户随后在正确规则下再次试玩《调度》，明确评价“新版甚至更妙”“需要更复杂的调度”“核心思想几乎完全不变”，并选入地图集。此前因所有新最优都使鬼出内圈，就认定核心需恢复，是把一个空间形态条件当成设计目的。现在依实际反馈撤回该条件：核心是协调鬼位形成可达态，内外圈活动方式可变化。下一轮先写关键认识与相互制约，再列哪些只是实现形态；不能只为保住参考的停位/范围限制去堵住更有价值的玩法。这是本图的真实对照，不据70比50长就普遍支持加步数，也不把新增往返当增强。[新版评述](../data/manifests/inside-shunting-current-review-20261018.json)。

这些是有来源的经验，不是已经校准的趣味评分。单个反例不能证明一种机制无潜力；相同套路被掌握后是否仍有新关系，也要逐题判断。若之后反馈与当前经验冲突，保留旧依据，写清新证据改变了哪项判断。

《悬置》的设计者检验另提出“暂缓完成”：一个较彻底的困鬼安排可能占掉之后接近按钮的条件，刻意保留半成品才有后续。[原图与反例](../examples/suspended-exit-20261015/README.md)中，两种安全的提前处理计划均无续解；这支持检查跨阶段条件，不证明已经带来人的顿悟。下一张先比较“立刻处理完”和“保留什么以后再做”两项合理计划，再决定是否需要新机关；不能只把多次引鬼改叫暂缓完成。出生点内移也要同时审实际入场：本轮省一步的版本保持中性入场，省两步的版本尚不满足，未采用。

《换手》的设计者对照进一步区分了“共享机关”和“真正互相制约”：两图共享A的62步初版仍能顺次处理，因而没有交付。最终把新鬼纳入旧鬼的实际阻挡关系，再删任务钥匙、额外门及开场独立困鬼段，15格仍保留四项全解必要关系。[原图与反例](../examples/shift-handoff-20261015/README.md)尚无真人评价。下一次先试删去整段、独立角色或资格物品，确认留下什么需要提前理解的条件；既不能为复杂性保留原稿，也不能把局部必要、长解或共享字母自动当作精妙。

《换席》原版的设计者对照说明，条件内最小之后仍须无条件删改。左A按钮能省路但并非必要，删去后重新合并按钮室与原A门、缩短目标支路，把单钮19格36步方案收至16格30步；目标A门原本迫使最后关A，删后发现可用反向让路收尾，因而放弃原保留条件。首四项关系仍全解必要，第二次优先只对最优必要；[生成时来源与反例](../examples/seat-exchange-20261016/README.md)保持，后续真人评价为“不错”但“新意不大”。下一次同时审“保住现有解释”的精简和不受其约束的替代，不能把事件定义引用某门态当成该门不可删的理由；阶段用真实操作历史表示，并进入完整键。用户增强版另证：最后的反向卡位与关闭上A门右侧停位都变为全解必要；第27步按A当步安全却丢失全部后路。这说明原先的精简仍保留了新意不足的普通办法，增强通过后续目标改变了对该办法的判断，而不是否定精简原则。

《调度》的设计者检验另提出一项待反馈假说：当外围开关的控制方向不足时，短暂进入再退出可以让玩家位置本身提供新的引动方向；进入不必只为当次完成目标。三鬼底排构造中，两种内部引动与至少两次退出对全部通关必要，但这还不是人的顿悟证据。原十二门版的许多封闭退路只是强制成对开关；删到六门后关键关系保持，保留更自由的控制。完全开放退路的最优又变为外圈追逐与优先卡位，另存研究，不盲目按门数或步数选。下次仍审玩家能否靠熟悉配方逐段执行，不能拿这项新必要性替代交付判断。[原图、反例与范围](../examples/inside-shunting-20261017/README.md)。

## 每个新点子先写一张设计卡

《寄存》的设计者删减对照发现，上A门删去后最短步数、全部最优动作均不变，但全部参考在去掉终点判胜后死亡；普通门删去也同最短，却出现绕过预期交错操作的35步普通解。以后“同解”分别核对动作、逐步物理结果与去终点安全，再审非最优替代，不能凭一个相同数字决定删留。最初的目标暂存事件也能被安全操作台顺次实现，只有操作台位置与离站追距联系后才出现待玩家验证的规划要求。[原图、反例及范围](archive/research/goal-buffer-20261018.md)不作新意评价，也不证明所有可绕过的关系都值得保留。

《腾挪》的设计者精简另说明，删减需要组合复算：两钥匙、三扇0门稿中，单独删除右钥匙资格任务会出现30步普通方案；同时开放三扇0门、移除该任务后，却仍保留42步及原三种最优。改变视线关系后，原本由资格门施加的约束可以不再需要。出生内移和边缘整理后为19格41步。原稿及对照留在[来源与验收](../examples/corner-clearance-20261018/README.md)，后续用户明确认为仍是旧思路；不把保持步数等同于保持体验，也不把单项必要性当成禁止组合精简的理由。

在布局或搜索前，先回答六句。没有新认识的提案，不靠加面积、鬼、机关或路线补足。

1. 玩家要完成什么？最自然的计划是什么？
2. 这个计划在哪里遇到看得见的矛盾？是暂时困难，还是留下了之后无法补救的条件？
3. **关键发现是什么？发现前后，对哪个元素或关系的理解发生了改变？**
4. 这个发现相对已认可和已否决的题新增了什么？为什么掌握旧套路后还要重新思考？
5. 玩家凭什么观察和推断它？开局、入场、失败后的诊断是否公平？
6. 最少需要哪些结构？理解之后，执行是否简洁，额外往返是否还有新的推理作用？

先围绕突破逆向构造小机制：把关键关系做出来，再让前置安排与后续后果互相约束。不要先生成长路线，再用解释给每段绕圈赋予价值。程序适合找捷径、反例和结构对照；模型与设计者的自评只能提出待验证假说。

## 从设计卡到交付

1. **先审机制，再审新意与可推断性。** 新运用先用最小局面对照基本通道，确认视线、同回合移动、碰撞和争位符合已知直觉；不能把共同引擎的一致结果当成合理机制的证明。 对照小册和上表，写出具体新认识及普通解法为什么不足。先排除仅有强制顺序、重复困鬼、局部操作顺手就解的提案。
2. **构造并找反例。** 检查直接取目标、一直保留已有保护、连续按按钮、少安排一只鬼等实际替代。区分“一条错误后缀失败”和“这个局面全部续解无解”，区分所有通关必要与仅最优必要。删鬼会改变角色与压力：《再借》删任一鬼后，原44步参考仍可安全通关；这种改图不能代替原图禁止搬运或受挡事件的必要性检验，见[本轮方法反例](archive/research/stair-relocation-20261013.md)。
   新多层提案先做普通区域替代审查：展开后关键发现与前后准备都不变，只多了切层操作时，不以必须使用楼梯放行；《隔岸》否决与《楼间》撤图表明，步骤唯一和结构精简也不代表实际推理。不能为制造分叉添加无意义死路。

   楼梯候选曾用两条等长前缀检验“更靠近鬼反而保留后续空间”，但用户指出其依赖不合理追击延迟，规则修正后无解，已撤回假说的交付资格。等长前缀和必要性仍只证明给定规则下的关系，不能掩盖规则本身的问题。旧依据见[本轮楼梯研究](archive/research/stair-valve-20261013.md)。
   [安全进展研究](archive/research/safe-progress-commitments-20261017.md)进一步发现，失去后路可能早于后来仍能完成的开门／取物。先定位错误计划的首次失去续解点，再比较后续表面进展和正确准备；不要把最后可见操作当成首个错误。六份原图的13份见证由61次独立续解核对，但《相让》《互锁》也有这种结构，因此只作反例来源，不当新意指标、合理性判定或趣味分。

   [共享空间反例](archive/research/shared-space-20261018.md)显示，三次进出、两鬼都移动与全局共用字母，仍可由“先独立停好每只鬼，再做目标”完整实现。先实际寻找这类通关替代，再解释参考中的依赖；预先想好的角色不能代替逐步视线核对。禁止取物后移动的监控只否定所描述的跨阶段关系，不把其穷尽无解反过来当作难度或趣味分。
3. **做经济性审查。** 去掉出生突出格、重复按钮、支路、任务钥匙和门属性；既做保持设想关系的精简，也审查不受该关系约束的删改。条件内局部最小不等于无冗余，更不等于优美。保留元素要说明它改变哪项判断或如何让表达更清楚。
4. **通过规则验收。** 合法性、共同引擎证书、最优性、全部并列最优无伤无复活解的重合边界、玻璃换墙全可达物理结果、中性开局与指定实际入场、编号无关、地图及操作码往返。预算不足记未知，不能放行。详见[设计边界](design-boundaries.md)。
5. **先审实际规划，再交付少量已审题。** 必要事件如果自动由唯一安全路线带出，不算玩家主动发现；只有一个局部分叉、后续只是执行的构造留为教学研究。当前主线要求多个会相互改变后续条件的规划判断和一个非显然的核心认识，不能用小题定位或免责声明替代这一门槛。 正式域名试玩与默认暂停的折叠参考链接；写清证据范围，不先宣称精妙。不自动上架，不自动启动训练；地图与回放只用正式域名，用户自行访问。

## 调整已有地图：精简、优美、增强

本轮[用户五图对照](archive/reviews/map-adjustments-20261014.md)修正了此前偏重逐项删除的经济性判断。删后无解只能证明该位置参与当前布局，不证明搬到别处、压缩通路后仍需要那么多格；同样的核心也可能用更舒服的外形表达。以后设计交付前做删除审查，也做布局重排。

**精简看表达和执行。** 先写出应保留的关键发现、前后准备与玩家需要作出的决定，再尝试移动按钮、并置有关元件、缩短无信息的连接段、内移出生或目标。走路若只把玩家送到已经确定的操作位，可尝试减少；涉及控距、视线、鬼位、门态或选择顺序的位移不能当赶路删除。《周转》将A移近，15格36步保留三次调动思想；《错位》把A/B并置，让新增门态要求更紧凑。更短不自动更好，不能把核心矛盾或合理选择一起删掉。

**优美看轮廓和阅读。** 区分有意环形、结构表达所需空洞，与突兀的内部虚空、扭曲突出和零散凹口。可以填成融入外形的单入口死路，也可平移区域、元件来整理外边界；不是一律填满或强求对称。《接力》增加一个无任务格去掉中央虚空，解谜仍31步；这种格子的用途是表达美观，不能因为解法不经过就再删。按钮靠近相关控制、减少门标签堆积，钥匙等兴趣点尽量不与鬼初始位置重合，都帮助玩家阅读。填格仍须核对是否意外提供掉头、等候、视线或捷径。

本轮真人反馈纠正两项假说：《回位》B本在2×3空白区中央，短距离并置反而破坏匀称；《同行》本是正常转角，所谓“凹口”并不存在，补格只增加冗余。此前按控制集中和填缺口判断改善，现在必须先说明真实赶路或外形缺陷，并同时看按钮在所属区域的构图，不能只看邻近关系。下一次先对照整体形状与元件重心；没有明确改善就保留原版。《接力》《暂驻》确实改善虚空的正例不扩大成普遍填空法。见[本轮真实反馈](archive/reviews/map-maintenance-review-20261014.md)。

《再借》获准窄环版说明可以大胆删去外围准备，只要关键发现仍然成立；重新引动第一鬼并阻挡目标守卫在两版全部通关中仍必要。下一次同时写清删去哪些旧要求、留下哪种认识，不把完整流程不变作为唯一可接受的精简，也不把更短、少按钮当自动成功。

**增强看认识和条件。** 这是可选步骤。删除一个旧掉头位、改变一个开放条件，如果迫使玩家先准备正确门态或利用另一处空间，可以增加推理深度；只增加重复按键和往返，不算增强。《错位》要求最后引鬼前B关闭，并先借A准备安全操作；《换岗》封右下掉头空间，要求选择左上与正确门态。必经路上的钥匙可以删去任务标签，也可保留为引导兴趣点；须明确是在改变资源条件、引导程度还是单纯外观，不把全部非必要钥匙视为冗余。

本轮进一步对照：《归途》移钥匙保留所有最优动作，《回环》同样移钥匙却跳过全部按钮，说明兴趣点需要按其资源约束单独判断。《再借》缩窄后最优仍重引，但较慢解可绕过，保留分隔墙后才恢复核心必要性；按钮从三次减到一次不能单独判好坏。核心发现保留、完整流程不变、趣味与难度相同是不同结论，报告必须区分，不能用其中一个代替另两个。

每个调整单独记：原图、目的、保留的关键、刻意改变的要求、预期减少的赶路／阅读负担。纯精简与美化比较旧参考能否映射、最优控制及鬼位阶段是否保持；增强允许这些变化，但必须说明新增了什么需要提前理解的条件。步数、面积和按钮次数只作对照，不能代替结论。先检查所有门和玻璃是否严格连接两个活动格，边界必须是墙；移动终点、删格、收轮廓后清掉原机关边，原始输入非法不能靠规范化后求解掩盖。再审直达、永久困鬼、旧掉头、提前取物等普通替代，再核验新版本全部最优无重合、冷开局和实际入场、玻璃、编号无关及码往返。预想成立只作设计者证据，不冒称人类体验等价或难度已提高。

用户已明确给码并要求更新的版本按授权处理，原版证据不覆盖；自行尝试的改图作为独立候选交付，获认可后才替换地图集。这套调整也用于新图，不只用于旧图返工。

## 每次反馈后的固定维护

原话、日期、提示／回放条件与真人路线是否存在分别保存，不补数值分、用时或实际动作。随后更新[地图总目录](https://github.com/Pre-rice/ghost-maze-ai/blob/main/docs/ai-map-catalog.md)；只有用户明确选入的图才上架，并同步[设计小册](https://github.com/Pre-rice/ghost-maze/blob/main/docs/map-design-guide.md)的该题条目。亲缘改图不继承反馈。

在本文件只提炼会改变下次选择的经验：**依据 → 当前解释 → 下一次检验 → 适用范围／反例**。详细实验与旧判断放[历史档案](archive/README.md)，不再向 AGENTS、README、状态页反复追加同一过程。当前状态只写有效结果与待做事项，下一轮开工必读本文件；查证时按链接回到来源。

每张交付后比较“设计时预测的关键发现”与“用户实际提到的发现”。预测准确与否也保留；肯定简洁不能扩大为顿悟已达成。再次遭遇同样的负反馈，就检查设计卡和删减审查是否确实执行，而不是继续换外形。

判断推进效果主要看：是否出现新的、用户确认的关键发现；同样的冗余和无新意批评是否重复；想法是否用更清楚的结构表达。候选数量、解长和代理分数只作工具诊断。当前已获《再借》的明确新意正反馈，但经验不能保证每题成功；它的作用是让下一轮可复用真正奏效的认识，并及时否定失败的假说。

## 路线选择保持开放

优先尝试能产出精品的设计推理、验证搜索与反馈循环。只有当训练能解决明确瓶颈、具备合适的独立数据与验收办法时，才比较其收益与投入；不用为了已有训练计划凑相似地图。旧[训练方案](archive/plans/ai-training-plan.md)保留为可选路线的研究材料，不是必须完成的阶段承诺。当前重整与网站求解已完成并推送，持续恢复设计。用户最新允许探索多层，取代此前仅聚焦单层的粗略判断；单层仍可继续。多层需要由楼梯承担精妙部分，先检验具体关系，不能据一个入门题推断已找到精品路线。楼梯规则已按相邻通道修正；《楼间》原件留存，另存入门关修补版，不把旧规划行用于新规则或转移真人好评。《留客》退役。后续《隔岸》被否决、《楼间》按最新决定撤出，当前回单层新关系；原机械证据与原入门评述保留。新点子仍先写设计卡，模型训练不自动启动。

当前反馈已否决《隔岸》的楼梯价值并撤出《楼间》。此前“切换控制面”机械证据仍成立，但普通区域可保留同一理解，故它不足以支撑多层精品方向；同类未布局提案取消，优先单层新关系。
