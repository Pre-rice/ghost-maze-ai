# 行动段：成本等价，不代表加速

2026-10-15。当前十三张精品图只用作物理与成本对照，没有新真人路线、质量评分或独立设计家族；网站求解器未改。[证据摘要](../../../data/manifests/planning-event-actions-20261015.json)。

此前模型即使复用规划前沿，在给定停位目标上仍显著慢于BFS，也不稳定产生最短路线。因此停止旧树模型调参，先检验能否把无事件赶路和强制追逐段从决策中分开。行动段保留全部真实操作与精确成本；“什么时候鬼动、什么时候停”可以逐步重建，不用于合并网页最优解分类。

每一步仍调用本体引擎。鬼位、墙态、资源、楼层、终止状态任一变化都保留为事件；事件后只有一种新的安全物理后继时才继续到下个分叉。排除重复物理局面的正成本往返，仅限全信息、无伤、无复活、没有历史限制的范围；新历史任务不能直接沿用此压缩。加权规划在最小成本目标出队时才能证明最短，不能发现目标就停。
