# 拿掉字母开关：一次性通路与普通门的机制反例

2026-10-18。承接《互锁》未感新意与[暂留研究](late-opening-handoff-20261017.md)留下的方向，本轮先拿掉字母开关，检验普通门与一次性通路能否造成互相制约的搬运。以下是设计者的构造与穷尽反例，没有新候选、真人试玩或质量标签；网站、引擎、十五张地图集与《转圜》原版均未改动。

## 留下的机制事实

以下均用共同引擎逐个局面核对，不是新规则：

- 数字门（keys 0 或 1）在玩家通过后永久变空墙。因此玩家通过的那一刻，也为鬼打开了同一条通道；鬼的寻路只承认空墙和打开的字母门。
- 普通门对玩家恒开、对鬼恒闭、挡双方视线；游戏内没有开关普通门的动作。它既是玩家的免费通道，也是鬼的永久屏障。
- 鬼失去全部视线时完全不动；移动目标按"操作后位置优先、其次操作前位置"选取，所以它最多再朝旧位置走一步。
- 按字母按钮的当步，鬼的视线按翻转后的墙态判断（旧研究已记录，本轮复验）。关门当步就能让正对着的鬼立刻失去目标。

## 构造与关键反例

构造 A：8×4、双鬼、一扇 0门、一扇终点 1门、一根柱子。最优 24 步，4 条全部最优，全部最优无重合、去终点安全、冷初态入场。

把 0门 换成普通门后，最优解与步数完全相同（24 步，同一串动作）。原因是参考解在穿门前先把守门的鬼引到另一条行列上，鬼从未需要穿过那扇门。**这条对照直接否决了把它当作"一次性通路"候选**：机制在图上存在，但解法没有使用它。它实际表达的只是"引开守门鬼"，与《错位》的既有认识接近。

同图其余删除对照（只说明元件参与当前解，不作趣味或新意结论）：

| 改动 | 结果 |
| --- | --- |
| 删第二鬼 | 24 → 18 步 |
| 删守门鬼 | 24 → 16 步 |
| 终点钥匙门直接打开 | 24 → 6 步 |
| 0门换实心墙 | 穷尽无解 |

## 为什么"鬼跟进"没有发生

一次性门消失后鬼能通过，但前提是它看得见玩家。参考解恰恰通过走位让守门鬼停在门的不同行列上，于是三只鬼都没有使用新通道。由此得到本轮的具体教训：**先检验"目标事件是否真的出现在参考解里"，再谈机制价值**；只验证"换掉元件会改变结果"不够。

反过来，只要玩家总是可以先把鬼引开，"门消失"就永远只是可选负担。它要承担实际作用，只剩两种可能：

1. 玩家无法引开守门鬼（空间被压到只剩隔间），它必然看见玩家穿门；
2. 玩家需要鬼跟进来，例如借它的占位挡住另一只鬼。

第二种接近《再借》的既有理解，必须先写出这次新增的、不同的认识，否则不进入布局。

## 顺着第一条构造出的 B：鬼必然跟进，并用普通门隔离

把门格贴到鬼的正对面，玩家没有引开路线，构造 B（21 格、17 步）成立：玩家穿 0门 后追鬼一路跟进右房；按钮在一间只能经普通门 d1 进入的小室 R，追鬼被 d1 挡在门外；玩家再从 d2 回到外圈，经左侧走廊回到终点。

删除对照全部参与当前解：

| 改动 | 结果 |
| --- | --- |
| 0门换普通门 | **穷尽无解**：鬼留在左侧走廊，堵住回程必经点 |
| 删 d1、删 d2、删按钮 | 均穷尽无解 |
| 删鬼 | 15 步，玩家直接从右房原路返回 |
| 终点门初始打开 | 8 步 |

这里终于出现了机制被真正使用的证据：一次性门消失后追兵才跟得进来，而**它跟进来反而被带走**，离开玩家回程要经过的左侧走廊。换成普通门，鬼留在原地，回程即死。

## 但构造 B 不能交付：入场与冷初态未满足

- 鬼初始就在玩家出生点的同一行，第一步无可避免地被看见。
- 出生点 (2,1) 上方开一格作实际入场时，入场当步鬼就会移动到出生点，玩家当场死亡。这不是"入场会改变鬼位"，而是入场即结束。
- 试图在出生侧留出腾挪格，又会让鬼看见门格的位置远离出生点；把鬼挪到门格斜角，穿门时它就看不见玩家，一次性门重新变回不参与解法的元件。

同批的冷初态版（26 格、17 步）补上了 `cold:true`，但三条必需性同时失效：0门换普通门仍有 17 步解、单向出口换普通门仍有解、删鬼后步数完全不变。说明"必然跟进"在这个尺寸上既救不了入场，也不再承担作用。

## 三分离版：边界全过，追兵却不构成威胁

按上一节的建议把出生点、门格、鬼位分成三方：出生 (1,2)、门格 (2,5)、鬼 (0,5)。这确实同时满足了冷初态与入场：入场从 (1,1) 向下一步，鬼与出生点不同行列，入场当步不会被看见；玩家走到门格时鬼在它同一排，穿门当步鬼追到门格，正式跟进右房。

完整构造 27 格、21 步、`cold:true`，但四条对照同时暴露了它的空洞：

| 改动 | 结果 |
| --- | --- |
| 0门换普通门 | **21 步，动作序列完全相同** |
| 单向出口换普通门 | 21 步，相同 |
| 删鬼 | 21 步，路线略变 |
| 删 d1、删 d2、删按钮 | 均穷尽无解 |

原因很直接：玩家全程只停一次，而且停在普通门小室里；追兵与玩家同速，玩家只要不停就能一直保持两格以上距离，最后钻进左侧走廊，追兵在右房失去视线就停。**鬼跟进来了，但它既没挡住玩家、也没迫使玩家改变路线。**"把追兵从回程路线上带走"这句预期，实际上变成了"追兵自己跟丢"。

这说明这条关系还缺一个真正的约束：**玩家必须在鬼能看见的地方停留足够久，或者必须两次经过同一区域**，否则"跟进"只是无损的副作用，换不换一次性门都一样。

## 本轮结论与下一步

机制本身已经成立：**一次性门消失后，追兵能跟进来；它跟进之后可能被普通门房间隔离，也可能自己跟丢。** 但要让这条机制真正承担作用，必须补上"玩家被迫停留或折返"的条件；只要玩家一路跑，任何同速追兵都不构成约束，0门也随之退化成普通门。

下一轮先设计"必须停留"的最小局面——按两次按钮、取一次物、或必须原路折返一次——再检验 0门 与隔离室是否仍然必要。不要再先做完整地图再回头补压力；本轮两版都是这样失去必需性的。
