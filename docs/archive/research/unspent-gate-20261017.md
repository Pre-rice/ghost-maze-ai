# 未走过的门也能限制计划

2026-10-17。设计者的机制反例，不是新关卡交付、真人试玩或新意证明。十五张地图集、网站与规则保持。

## 先区分使用与约束

“最优路线没经过”不足以证明一个元件无用。元件也可以通过阻止一条计划、保留一处保护发挥作用，最佳路线可能始终不使用它。下面用一个可复验的小构造明确这一范围，不由它推断新意或难度。

11格单鬼构造给出直接反例：出生点上方有一条较长通路，下方有0门捷径；两路到达同一个A按钮，按钮开启目标门。上路的单向门允许从出生侧进入，却阻止玩家从按钮侧倒退逃走。

| 对照 | 共同引擎的结果 |
| --- | --- |
| 原图 | 最优8步，唯一物理最优，整条路线从未消耗0门 |
| 只把0门换普通门 | 原生与快速求解均为6步，可以安全走下方捷径 |
| 原图先下、右通过0门 | 前缀本身安全，但完整后续穷尽无解 |

原图短路失效的原因可见：穿0门会让鬼跟来，玩家到按钮时不能再停一步；向上逃后又被单向门限制。普通门仍挡鬼，才允许走短路并按A。因此0门不是最佳路线使用的通道，却实际排除了一个更短计划。这里只核对全部最优不消耗0门，不声称所有较慢通关路线都不消耗。

复验：`node examples/mechanism-lab/unspent-gate-20261017.mjs`。脚本构造原图并直接使用共同引擎，不复制物理规则；同时核对原生／快速最优、全部最优边界、分享及操作码往返、去终点安全、冷初态与指定实际入场。49个可达物理局面、225次后继核对包括致死动作；外部(1,2)向右进入出生点，全程内部局面与独立游玩相同。这个指定入口不推广为任意整图可直接接入。
