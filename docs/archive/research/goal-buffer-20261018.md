# 目标缓冲与开关交错

2026-10-18。目标是验证“先腾空目标”是否可以被可见的准备关系打破，不把反直觉标签本身当新意。最终候选[《寄存》](../../../examples/goal-buffer-20261018/README.md)尚无玩家评价、未入集；原型和失败构造在[冻结清单](../../../data/manifests/goal-buffer-20261018.json)。

最初28格稿让上鬼停在起初空着的目标，但安全操作台允许任意重复开关，原“必须两次B”的设想存在一次B、三次A的37步替代。把左操作台移到下方后，单独改动又出现16步不开关捷径：出生和横向视线可先把下鬼送入上侧，不需要原计划。保留这些反例，不将目标停位必要误写为主动规划已经成立。

出生内移、顶排隔墙恢复后，左A会释放下鬼追向操作台；准备上鬼与离站追距开始交错。四排收为三排、右上B门删除，最终21格、33步、36条原始最优，合并为九种含停顿鬼轨迹。近站先行和未移动上鬼便释放左A的实际安全前缀都无续解。禁止左A后再操作B也穷尽无解；但先多按一次B再按A并非致命错误，仍可追加B补救，不能把它当无后路证明。

两次删门说明为什么还要审最优以外的替代与终点判定：

- 普通门改空边，最优33步及全部原始最优不变，却增加一条35步绕行，在左A后不必再按B。是否保留这项安排是明确的设计取舍，不能称普通门对通关必要。
- 上A改空边，仍有同一组33步最优，但全部36条去终点重放都会死亡。原图则全部安全。这项精简被拒绝；“同最短、同动作”不足以排除判胜时机的漏洞。

全量物理、编号与指定外部入场验收见候选证据。两个可删地形格保留完整矩形，明示为轮廓取舍。目标没有特殊规则；当前设计预期落在暂时让出目标和A/B交错后的撤离条件，不以“鬼停在终点”替代对已有控距／困鬼题的新意比较。没有调用自主试玩skill，也没有新增训练或人工评分。

研究稿有一次未封顶历史计数导致查询预算未知，已保留原输出；有限布尔监控复算后才作结论。全部通关查询含非最优及合法重合，交付的重合边界另审全部最优，二者不混用。
