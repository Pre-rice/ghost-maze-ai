# 不可逆通道、影响方向与目标口补位

2026-10-19。用户优化《同调》《换边》、认可《留隙》的维护已完成；本页记录之后的设计者研究与候选形成，不是新真人反馈、盲测或质量评分。地图集保持18张。

## 从实际反馈核对“有纠缠”

在可达局面中暂去其余鬼，仍调用本体计算同一回合，比较当前鬼的行动。新旧《同调》和《寄存》都有与原最优同成本的全程无影响路线；《留隙》《腾挪》《调度》禁止影响后无解。被否定为老思路的《腾挪》也需要影响，用户认可的优化《同调》则不要求直接挡鬼，所以不能把这一条件当质量阈值。

用户新增中廊A在原图禁止操作后无解；恢复删去的普通门则有59步解。这支持控制位置补偿缩短通道、撤掉独立保护改变要求的具体解释，不以85步与59步推断人的难度。

## 几个构造怎样被否定

开放方室八份最优均利用重合，且有不改变最短的删鬼反例。双室共角初稿与有限保护稿无解；扩大下室能解，却有第三鬼同路线／同成本的乘客问题。提前移动必要不能强留它，取内侧物的增强也没有得到合格稿。

两条可消费通道的53步稿确有安全错误开门后全续解无解，但“首钥匙前一定开两0”的原预想被63步反例否定。参考31与51步玩家、鬼位和门态相同，只多完成一把钥匙的差事。去上钥匙形成45步共同准备构件；去右钥匙31步则可以省一条0，删除任务须分别核验。

单钥匙稿的上0改普通门后仍可同45步，却不再需要鬼互相影响；这次改变了保护原因，不能由相同步数或路线判定设计理解未变。整段压缩到5×6的39步保留两0消费，5×5的33步却可完全省一条0，不按更小自动取代。14处柱内目标和8份可消费横接没有建立预期的双方接力要求，不从中递补挑战题。

## 留下的用法与范围

先查独立差事与只走一圈的普通计划，再区别同时响应、单向帮助与持续互换作用；当前查询只诊断具体关系。两条关系都必要仍不证明顿悟，必须回到可解释的总体方案和实际反馈。所有原件、错误预想、反例与预算结果分开保存，未新增训练、自动试玩或网站功能。后续继续主线，研究快照不是停点。

小空位原型的有限门态、端口与内部静态替代均无解，停止该构造；不是所有小室不可能的证明。随后单组门双圈35步初稿仍可普通清理。把钥匙放到原来方便停鬼的位置，补真实接近面后得到50步检查点；尚未在该检查点完成交付QA，后续删门和总体计划核对另存。54份原件另存[快照81清单](../../../data/manifests/causal-roles-20261019.json)，不回写80或用研究收尾代替持续工作。

## 三路让路仍只是构件

现行十八图缓存的全部鬼轨迹代表未见一名追者同时挡两路；范围不是所有玩家路线，更不是质量依据。新构造实现了这种过程，20／26／36步安全稿却多由开场直接带出。两个较完整稿的最优90／72步使用重合，另有106／74步无重合参考，仍不能通过“全部最优”边界。距离、端口和通路对照另存[29份原件](../../../data/manifests/triple-guard-20261019.json)。

删右列并廊后，较完整任务无解，可解短稿仍只有开头一次；初始守卫距离偏移的安全稿都有不用该过程的同最优通关。把兴趣点移到两侧停位后，单上钥匙、单下钥匙、双钥匙2门三种任务均走完全相同的28步参考，新增钥匙只是必经格标签。故停止该批，不把新局部事件或安全错误分支当作足够的总体挑战。后续两空位四鬼稿从取物与离开一起审起，仍未交付。

## 消耗保护的反例与贴身追逐边界

两房数字门构造原想在0后方停鬼，取角落钥匙，再由另一鬼接替保护。初稿与目标接近面变更均无解；一份完整可达摘要中，34个两钥匙局面只在左上死路，取得任务不代表能返回。右侧加普通门或墙能解，却有最优重合；打开钥匙死路后得到26步安全稿，原0可直接改墙／普通门，最优26步及所选逐步玩家鬼位不变。删0并内移出生则有23步冷开局，原26步去首动作的25步参考仍成立；同参考仍不等价于整题。故撤回这批“消费后接替保护”的解释，未递补候选。

推演反复把“指定守卫不再跟来”误当成“玩家获得了可掉头的空隙”。在单层连续空边移动、已有隔空边贴身鬼、本步不关门且不提前判胜的条件下，那只鬼会请求玩家旧格；旧格本来无鬼，即使它争位落败，也有胜者进入，继续与新玩家隔空边相邻。因此争位本身不能清掉全部贴身追逐。普通门／单向门越过后、按钮关门与楼梯不属于此空边命题；数字门越过后变空，仍不能按永久屏障理解。这是限定条件下的推理，不是一般不可解性定理，更不影响已有借鬼设计的价值。

原生3×3空地枚举1至4鬼全部非重合初态，共1458图、604次符合条件的非致死空边移动，旧玩家格均有鬼；含132次优先争位和32次同级重合。普通门与0的两动作对照分别能／不能解除贴身，作为有限代码核对，不替代有条件推理或新增验收规则。原件、失败预想、手工失误及查询范围见[快照87清单](../../../data/manifests/replacement-shield-20261019.json)。继续将保护具体到某只守卫的停位与接近方向，不把鬼当实墙的一般替代；无新训练或自动试玩。
