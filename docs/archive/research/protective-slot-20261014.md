# 保护位置研究：反例与精简

2026-10-14。设计者研究，不是用户反馈。原件保留在私人研究目录，公开交付为[《腾位》](../../../examples/protective-slot-20261014/README.md)。没有训练或质量评分。

起点是让已困住的鬼离开，后鬼接替保护位置。与《再借》相比，预期改变的是从“重新阻挡”到“解除阻挡、传递空位”；先写设计卡，再用原生规则找反例。

| 先前判断 | 实际反例／核验 | 现在的处理 |
| --- | --- | --- |
| 18格保护槽可以迫使先安排出口鬼 | 9步穿普通门、15步把鬼引到上方，完全绕过交接 | 不交付；保留原图和反例，不用参考路线编设计解释 |
| 多只鬼先后到过中心就是交接 | 出生移到B后，熟悉的先引左鬼20步解胜过预想方案；“经过”监控过弱 | 改为出口鬼真实静止、实际离开、另一鬼在相同闭门保护位真实静止，历史进入状态键 |
| 四鬼、B门与普通门都承载核心 | 分别删B、普通门、侧A后仍最优且核心成立；共同删也成立 | 删整组B及门属性，不能凭预想保留保护元件 |
| 三层制动需要四鬼，因此第四鬼有价值 | 删中间鬼后仍22步，核心真实交接及初期优先制动均为全部通关必要 | 不为“三级”字样留第四鬼；保留三鬼的距离变化 |
| 南A也保护后半程 | 三鬼精简版删南A后唯一22、全部最优安全、核心仍全部通关必要 | 再删南A，只留一个A按钮和一扇A门 |

最终19格三鬼。在公开的争位局面，出口鬼仍看到玩家新位置，优先进入门下；侧鬼停住，另一鬼继续靠近。这不是简单让整队一起停住，而是调整间距。随后出口鬼离开，另一鬼接替门后保护，原出口鬼成为回程追者。

自然先引左鬼的 `D,U`，以及只按A困出口鬼的实际前缀，均由两种环境穷尽续解无解；正确安排后可解。原图分别禁止初期优先制动与真实保护位交接，均穷尽无解。唯一最优22；163可达局面、810动作含死亡、六排列／改编号共4860后继相同；实际入场与逐步码往返通过。

网页QA随后发现原19格初态出口被鬼覆盖，玩家不知道目标位置。原19格原件与QA留档，不改网页；给出口增加一格可见空间，当前20格、唯一23。重新证明初期制动与真实交接均全部通关必要，全部最优安全；164可达局面、815动作与六排列／变编号共4890次一致。指定真实入场、全程码往返及七项产品网页检查通过。新增出口格解释信息，不宣称增加难度。

这些证明核心存在并且没有普通捷径，不能证明玩家会顿悟或觉得有挑战。题目仍可能被熟悉套路的玩家快速理解；保留未评价状态，等真实反馈再比较预期与体验。所有版本沿用保守亲缘组，不按候选数量或动作行数宣称训练数据质量进展。

下一次检验：先区分一个元素是真的给另一只鬼提供保护，还是仅经过相同格；先试出生移位与不同处理顺序，再写必要性结论。若删减后核心不变，减少表达，而不是为多层队列或较长最优保留元素。
