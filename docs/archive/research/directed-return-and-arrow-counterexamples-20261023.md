# 单向门核心与回程承诺：2026-10-23

按用户指引，先收尾《门庭》入集，再探索单向门。先核对原生语义：玩家只沿箭头通过，鬼双向不能通过且看不穿；过门仍保留旧视线的一步追击。单纯把追者停在门前，是普通门也有的作用，不能据此宣称方向属性是核心。

《回流》的设计预期是脱身需要考虑下一次返回：最近出口会留下堵住回口的追者，要改用另一出口，再进入处理目标前守卫。仍有熟悉的引鬼和优先卡位；不能把方向因果、两次返回必要、无严格逐只计划或37步扩大为人的新意与顿悟。

原图分别允许和禁止非最优重合核对：最多一次回口进入、不带下廊鬼进房、禁用任一出口、禁用优先争位，均穷尽无解；取钥匙前预先移动上鬼也没有完整解。两个实际安全错误前缀——第一次返回后向上，或就近经右口离开——均无任何无伤续解。这些是设计者反例，不是玩家实评。

独立构造、原生／快速、七条最优全部无伤无复活无非死亡重合及去终点、408态4060次排列及变编号后继、分享往返通过。指定外部五步中性进入另证，随后七条最优内部逐步物理一致；没有声称迷雾知识或计步一致。桌面／手机、明暗主题下原站本地求解37步七种与同页回放正常，cloud:check通过。没有修改网站或检查正式部署。

初版“禁用优先争位”监控误读diagnostic的reason字段，实际字段为decision；其37步结果无效，单独标记并保留。v2改读visible_target_priority后，两种重合范围都穷尽无解，公开证据只用v2。其余事件查询不依赖该字段。

经济性不是盲删：右上闲角删除，出生与右口靠近、钥匙移近一格减少执行；左上角虽可删而不改最优，却会破坏房间轮廓，保留。钥匙移到下廊上排可19步，但下鬼始终不动，另存排除。原稿、无解及所有改图保留，不给亲缘稿搬运评价。
