# 《诱饵》：一条新规则的完整谜题

2026-10-18。本文件与实验环境只存在于 `experiment/one-shot-passage` 分支。main 未涉及，`../ghost-maze` 未改动。

## 规则提案：标记（DROP）

新增一个动作 **DROP**：玩家原地放下一个标记，占一步。

- 标记按层存放，进入完整状态键；
- 鬼移动时：看得见玩家 → 追玩家（操作后位置优先，其次操作前位置）；看不见玩家 → 走向最近的标记；走到标记格 → 标记消失；
- 其余规则不变：同速、一格、十字视线、门与墙、按钮与物品、无伤、无复活。

**为什么这是双向规则**：标记让鬼的目标**可以不是玩家**——玩家第一次能主动决定鬼去哪，而且这个决定有代价（一步，且标记位置可能更糟）。对比回声模式（让鬼更执着地追玩家）只能加压，标记既可能让某些图更容易、也可能更难。

## 谜题《诱饵》（第一版，后续已收紧）

- 6×3 活动区（x=0..5、y=0..2），18 格活动格；
- 起点 (0,2)，终点 (5,1)；
- 终点由 A 门守住，门在 (4,1)-(5,1)，初始关闭；
- 按钮 A 在 (2,0)，朝上；
- 封住 (5,0)-(5,1) 与 (5,1)-(5,2)，终点只能经 A 门进入；
- 鬼在 (4,0)。

参考解（11 步，例如 `URRDROPUUDROPDRRR`）：

1. 从 (0,2) 上到 (0,1)、(0,0)；
2. 在 (0,0) 放下第一个标记，鬼从 (4,0) 转向标记；
3. 玩家沿上排推进，在 (2,0) 按 A 打开终点门；
4. 在 (2,0) 或更靠右的位置放下第二个标记，把回头的鬼再次引开；
5. 经 (4,1) 穿 A 门进入终点 (5,1)。

**核心发现：标记不是“一次性引开”，而是一段可以被鬼消耗的时间。玩家必须规划“放几次、放在哪”，才能在自己与鬼之间持续制造时间差。** 16 条最优解全部需要放两次标记，没有一条能只放一次完成。

> 这一版在删除审查后被收紧到 10 格（见文末“删除审查”与“收紧后的定稿”），本节保留原版是为了记录收紧前的状态与 16 条解的空间。

## 规则细节（实现边界）

1. **标记只能放在玩家当前格**：玩家不能与鬼同格，所以标记不可能落在鬼身上；
2. **多标记取最近**，距离平手时按 `(x,y)` 排序取最小——不依赖放置顺序，符合“编号/顺序无关”；
3. **标记不影响视线**：鬼的十字视线判定完全不看标记；标记只是一个移动目标；
4. **标记不阻挡玩家或鬼的移动**；
5. **鬼踩到标记格时标记消失**（同一步内先移动后消失）；
6. **同一格可以重复放标记**（多占一步，通常无意义，但没有禁止）；
7. **本原型只支持单鬼**：多鬼时它们会被同一个标记吸引并可能同格重叠，而用户已明确禁止重叠作为设计要素。若以后要多鬼，必须给“哪只鬼追哪个标记”定义不依赖编号的规则（例如按与标记的距离分配、或限制一只鬼只认最近的标记且不同鬼不共享目标），否则维持单鬼。

对应的环境实现已经按前六条落地，平手排序是刚补上的（此前依赖数组顺序，会在多标记场景下破坏顺序无关性）。复验脚本在修正后依旧全绿。

## 与现有作品的区别

- 《错位》《接力》《再借》都是“用已有元素的新用法”；
- 《诱饵》需要**一个本体不存在的手段**：玩家可以主动给鬼一个假目标；
- 它不是“引鬼”的变体：引鬼要求玩家被看见、且鬼的目标仍是玩家；标记允许玩家在**完全不被看见**的情况下改变鬼的路线，而且可以重复使用。

## 实现路径与风险

要在正式游戏里成立，需要：

1. 引擎新增 `DROP` 动作与标记状态（进入状态键）；
2. 网站增加一个“放置标记”的输入方式；
3. 回放格式新增动作码（会改变现有回放协议，需要版本化）；
4. 求解器与训练资料需要支持新动作。

**风险**：这是规则级改动，会改变现有回放协议与所有历史证书的兼容性。若要做，建议只在“新规则地图”上启用，老图维持旧协议，并用新版本号区分。

参考解：

```
UDROPDROPDDDRRRRUURDROPDDDROPLLLUUUURRRR
UDROPDROPDDDRRRRRUUDROPDDDROPLLLUUUURRRR
```

两条解都是“放标记 → 前进 → 再放标记 → 折返 → 按按钮 → 再放标记”的节奏，**需要四次标记、两次折返**。这说明标记规则不是只能做短题，也能支撑“长解 + 多次决策”的挑战结构；而且两条最优解同样长、同样需要四次标记，不存在“少放一次也能过”的捷径。

两个结构合起来构成一组：**10 步入门版 + 28 步挑战版**，同一规则、两种深度。入门版已固化为 `examples/decoy-20261018/`；挑战版已固化为 `examples/decoy-challenge-20261018/`。
