## 当前判断与实际缺失

观察机会不等于已经学会。[知识前提复查](../../../examples/discovery-course-20261023/reviews/knowledge-assumptions-20261025.md)保留64插入前41条所选参考快照：首关已有最后一步追击与无效方向不推进，第8有按钮推进和闭A远停，第11过1仍留钥匙；普通门严格远停按当时快照编号首次为36布阵，不代表此前其它探索中不可能看出。继续让完整题提供逐步修正认识的机会，不为规则清单添加无趣演示。

后续[未采用构造与范围](../../../examples/discovery-course-20261023/drafts/followups-after-first-key-20261027/README.md)：反向保护稿存在同最优重合，单鬼过桥仍只是熟悉安置换楼层，错开双环的修正稿有同最优逐只方案；逆渡换口的上向与普通均14步逐只通关，旧动作失效不等于产生新题；方向场三稿最终仍退化为熟悉的逐只安置；留隙固定口及再借排队稿需要重合，再借右向口照搬原解、反向无解，均未追加机关。首32项还未先核对左鬼能安全引动，属未执行已有预检要求，不能当一般机制结论；没有继续加门修补或用数量辩护。

双向帮助的再借改题及两种初位均穷尽无解，未接入；其中一初位还是热开局。不继续加门修补。63另起空间且没有互挡，采用理由改为首资源的少元件完整问题，不声称原假说实现。其风险仍是保护装置是否太直白、三段引鬼是否线性、错误起手能否读懂；必须等真实审查，不能拿全解条件辩护。

其它失败稿不恢复递补；包括楼梯落点、共享保护、双环箭头、方向取物及四组拼接等，具体范围在[此前完整状态](status-before-first-key-candidate-20261027.md)及其链接。单向改普通门只放宽玩家通行，原合法解继续存在本属预期；要比较新增反向计划改变的准备或补救条件，不能要求旧解失效。该关系不推广到改变鬼通路的门替换。
