# 当前方法论

采用质量多样性搜索、学习型地图编辑、完整状态求解和人类偏好学习，先研究小单元，再研究操作依赖、单元联系和整图。完整实现设计见 [AI 训练方案](../plans/ai-training-plan.md)。

当前已完成 P0 参考与快验证基础，物理环境与三态求解接口见 [参考约定](../../reference-contract.md) 和 [快验证说明](../../fast-verification.md)，实际进度见 [status.md](status-before-reorganization-20261013.md)。原 LLM 生成—评审—经验库流程保留为基线，不等同于参数训练；旧原文在 [归档](../llm-workflow-v1/docs/methodology.md)。

交付条件是合法、可重放的真实无伤解。未知不等于无解，复杂度不等于好玩；机器证据与人工偏好分别记录。
