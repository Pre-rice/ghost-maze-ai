# 旧方案归档

`llm-workflow-v1` 保存初始化之前的 README、Claude Code 指引、方法论、评审协议、地图格式、经验及包配置原文。文件清单和旧提交见该目录的 `manifest.json`。

这些文件作为历史资料与对照方法保留，不再定义当前阶段范围。旧源码和旧测试仍在原位置，通过带 `:legacy` 的命令运行。当前入口是仓库根目录 `AGENTS.md`、`README.md` 和 [状态记录](../status.md)。

本目录只保存文档及配置快照，不是一个需要重新安装依赖的独立项目。历史数值和经验应回到原实验证据核验，不能因它们写在旧文档中就视为普遍规律。
