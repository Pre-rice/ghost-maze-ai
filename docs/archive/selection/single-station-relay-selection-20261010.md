# 《借位》的机制关系筛选（剧透）

本轮希望用一个小结构表达两次不同的判断：先把鬼挪开，才能改变门态；门态改变并处理另一只鬼之后，刚才的安全停位又成为撤离障碍。地图不增加钥匙任务，两个开关都在同一操作格。难度意图来自安置位置的用途改变，实际是否精妙仍要看用户试玩。

## 提案与取舍

此前的两按钮提炼 a/b/c 轮没有得到合格题。手工 d 轮虽缩到十三格，解法仍是轮流处理两只鬼，未采用。e 轮保留上下安置区和共用操作格，变动少量门的归属、初态、按钮位置和鬼位。种子 1010501，检查 20243 个提案后停在十个粗筛候选；选索引 10743。

粗筛检查可解、两鬼引动、两组机关使用、移动交错、末尾停止追逐、反序鬼数组可重放。移动交错只是待审线索；例如候选 3283、4750、20242 包含明显的大段追逐，未采用。10743 的两次安置之间夹着另一只鬼的移位，而且第二次安置解决第一次留下的障碍，才进入关系验证。

原提案有七扇字母门、29 动作。把 `(2,3)` 与 `(3,3)` 之间的 A 门改为空，看似保持五项关系且少一扇门，但回放揭示末段重新变成追逐。此前精简条件只检查关门当刻，漏掉了之后的撤离；本轮补上完整证书的末段停位检查。该版未交付，历史保留在 `runs/single-station-relay-20261010/retired-preview/`。

最终将该门改为实墙：十三格、六扇字母门、两个按钮，最短 31 动作。78 次精简尝试，最终审计未决为零；只声明保留指定安置关系和安全离场证书的单项编辑范围内不可继续精简。不是全局最小，也不证明每个格子或两个鬼各自的独立必要性。

## 常规计划遇到什么障碍

起点是 `(4,4)`，右墙为 A 按钮，下墙为 B 按钮。下鬼起于 `(3,4)`，上鬼起于终点 `(1,1)`。

开 A 能向上离开起点，但终点门尚未打开。立即按 B 会打开操作格左边的门，下鬼就在门后，按键推进的一回合会被抓。这条指定计划在第 2 动作死亡。

只沿右边往上绕一趟也没用：没有从侧面建立正确视线，下鬼仍留在原位。返回操作格再按 B，第 8 动作死亡。它说明位置远离玩家不等于鬼已离开开门后的捕获位置。

把下鬼暂时放到 `(3,2)`，再按 B、引出上鬼后，局面看起来已经整理好了。如果直接关 A，从左边向终点走，下鬼仍可以横向看到 `(2,2)`，在那里抓住玩家。这条指定计划在第 21 动作死亡。临时停位对按 B 安全，却不适合最后撤离。

这三条是人工提出并实际重放的审查计划，不是用户真实行为，也不代表所有自然思路都会同样失败。

## 突破解法改变了什么前提

先开 A，沿右侧到 `(4,1)`，短暂进入 `(3,1)` 再退回 `(4,1)`。下鬼从 `(3,4)` 走到 `(3,3)`，又因仍能看到玩家旧位置，补一步到 `(3,2)`。右侧实墙切断后续视线，玩家可以返回操作格。这次移动不是把鬼带着绕圈，而是制造一个可用于按 B 的停位。

按 B 后，操作格左门打开，终点入口也打开，而 `(3,1)` 与 `(3,2)` 之间的 B 门关闭。再从右侧到 `(4,1)`，将上鬼引至 `(2,1)`；向下退出视线，让它补一步停在 `(3,1)`。下鬼的临时位置和新门态允许完成这次操作。

此时不能急着关 A。回到操作格，从左边走 `(3,4)→(2,4)→(2,3)→(2,2)→(3,2)→(3,3)→(4,3)→(4,4)`。下鬼依次被引到 `(3,3)、(3,4)、(2,4)、(2,3)、(2,2)、(3,2)、(3,3)、(4,3)`。几个拐弯连续改变它看到的是新位置还是旧位置，让它最终留在操作格上方。

最后关 A：上鬼左侧的门关闭，下鬼向操作格的门关闭。下部实墙又隔开左侧撤离路线的横向视线。玩家从左侧上行至终点，两只鬼在这段路线中均保持原位。这里的保护成立于所选撤离路线；两只鬼不是四面封死。

关键重理解是：`(3,2)` 只解决“现在能不能按 B”，并不解决“以后能不能离开”。必须借这个停位先处理另一只鬼，再主动引动已经安置好的鬼，换到适合最终门态的位置。

## 原图关系证明

每项都在最终原图上单独禁止指定事件或有序子序列，任意其他合法走位、额外按钮和更长解均允许。快 A* 与直接调用固定原引擎的 BFS 分别穷尽无解。

| 被禁止的关系 | 原引擎枚举状态 | 能支持的结论 |
|---|---:|---|
| 鬼在 `(3,2)` 时按 B，关闭上方 B 门 | 578 | 此临时停位与切 B 的组合不可绕过 |
| 上述组合之后，上鬼从 `(2,1)` 跨到 `(3,1)` | 2638 | 临时安排需要服务后续上鬼移位 |
| 上鬼上述跨边之后，下鬼从 `(3,2)` 跨到 `(3,3)` | 2573 | 原临时安置随后必须解除 |
| 两鬼分别占 `(3,1)` 与 `(4,3)` 时按 A，关闭操作格上门 | 3510 | 对应共同保护状态不可绕过 |
| 按 A 之后再次按 A | 2690 | A 需要承担先开启、后关闭的作用 |

涉及跨边的两项明确使用原图的鬼索引 0 与 1；不能推广为删鬼、换出生位置后的结论。原证书在鬼数组反序后仍无伤胜利，但未另做反序图全部关系证明。其余位置事件指任意鬼。必要有序子序列不等于唯一完整顺序，不能据此把 ABA 宣称为全部解的唯一按钮词。

## 元素与空间的作用

右侧三格既提供距鬼的身位，也作为两次诱导的往返路。`(3,1)` 先是玩家诱下鬼的暴露位置，随后成为上鬼停位；`(3,2)` 先停下鬼，后又参与再次引动。下侧与左侧的小回路控制鬼的连续转弯，最终同一条左侧路线用于撤离。终点旁的 `(2,1)` 同时承担上鬼离开终点的中间位置和玩家最后的入口。逐格有这些结构角色，不据此声称每格都拥有独立认知贡献。

逐门对照另外用不带上述关系限制的快求解器检查。四扇门改 EMPTY 或 SOLID 均穷尽无解；两扇门改 EMPTY 仍可通关：上 B 门改空是 22 动作，下方中 A 门改空是 23 动作，两条证书末段都有追逐。它们保留可解性，却绕过预期的再次安置和安全离场，因此未采用。完整数据在 `wall-ablation.json`，不把六扇门统称为可解性必要。
