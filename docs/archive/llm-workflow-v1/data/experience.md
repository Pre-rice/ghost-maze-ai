## 设计铁律（已验证，不得违反）

1. **直线走廊 + 鬼端头 = 1:1 追尾必被咬**（2026-08-16 demo 开发实证）：玩家被盯后直线逃跑，鬼 1:1 同步追，距离恒 1 格，直线跑必死。**甩鬼必须靠穿 DOOR（挡视线挡鬼）或转角断视线**。
2. **威胁路径必须比安全路径短**（2026-08-16 demo 开发实证）：若威胁路径与安全路径等长或更长，求解器与玩家都会选安全路径 → 鬼被完全无视 → 威胁硬门（被盯 ≥1 步）不过。**"威胁近路 vs 安全远路"的取舍环是威胁成立的必要条件**。
3. **鬼的威胁要"可破解"**：无伤路径必须存在（硬门③），且破解靠技巧（穿门时机/路线选择）而非运气。
