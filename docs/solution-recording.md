# 解法录制、同页回放与历史迁移

更新：2026-10-11。回放已进入本体同一游玩页，使用共同规则。旧 /replay.html?id=… 入口和局面差分猜操作的运行链路已删除。

## 分享与观看

点击游玩页“回放”后，直接复制地址栏链接：

```text
/game/?map=地图码&replay=操作码
```

地图码保存原图和开局设置，操作码保存 U／D／L／R／STAIR 与地图 CRC32。回放无需本地录制服务、编号或账号。地图与路线必须对应；非法码和不能执行的步明确失败。

默认停在第 0 步、显示全图，点击播放才开始，提供暂停、前后一步、步号与进度条，速度为 0.25×、0.5×、1×、2×、4×。关闭全图后沿路线计算探索，不记录此前循环视野。原游戏状态保留，只有确认“加载该步”才替换；存档清除。探索用路线视野，死亡循环同图加一次循环并与原探索取并集。

## 当前路线与研究留档

本体 GameController 在每次有效动作时直接保存操作，不从前后局面反推动作。移动、原地按钮、楼梯都计一步；无效输入、思考间隔和已裁掉的未来分支不进入分享码。

死亡循环只保留最后轮；探索复活保留物理变化，因此保留开局以来操作，由共同规则在下一步前推导必要复活。循环次数、已探索图与存档不进入操作码。

AI 本地服务仅在通关时后台留档，不再增加录制面板、保存按钮、导出按钮或回放入口。游玩统一使用本体“回放”与地址栏链接。JSON 留档用于研究，不能将它解释为游戏存档或完整试错时间线。新录制不保存 localStorage 游戏草稿。

正式真人资料在 data/solutions/；QA 仅写独立 runs/ 目录。服务端逐步核验操作和完整物理终局，同 ID 重试幂等，内容不同拒绝覆盖；研究 JSON 单条最多 2000 步，独立于本体操作码的更大上限。录制标识和研究 JSON 的 schemaVersion 不进入分享协议。

每张新题同时提供无剧透试玩和折叠的参考回放。优先使用已有动作证书生成新码并更新[总目录](https://github.com/Pre-rice/ghost-maze-ai/blob/main/docs/ai-map-catalog.md)，不为生成回放重复浏览器通关；QA 路线不能复制进真人目录。

## 历史迁移

```text
npm run migrate:recordings
npm run catalog
```

当前 14 份真实保留路线全部迁移和核验通过，新结果在 data/generated/recordings-current/，原地图、原 data/solutions/ 与生成证据保持原样。

旧录制需要**明确关联的原图 JSON**。依据原始验收标识或已保存的精确来源关系关联，不解旧码，不按终局猜地图。死亡循环取最后 REVIVE 后的操作，从原图初态重放；不要求重演已废弃体力规则下的早期循环。核对末局物理投影，忽略旧体力、旧计步、循环与探索。

原先差分录制保留的等价动作歧义仍需保留，并调整到最后轮索引；不能称已知道录制者实际按键。新录制来自直接操作日志，才可明确原始动作。

存在楼梯数据冲突或悬空按钮的原图不自动修复、不提供假入口，详见总目录。旧页不因服务升级自动安装新录制器；保留用户正在玩的页面，不通过刷新或注入新工具破坏旧局。

## 使用边界

无伤通关、最优解与人类质量标签分别核验。含死亡的路线可留档与分享，但不是无伤证书；同一地图的一条最优人类路线也不等于通用质量正例或独立测试集。

当前研究反馈服务与原六图试玩包的冲突边界见[工作流说明](review-workflow.md)，训练数据制备见[真实示范说明](demonstration-learning.md)，地图与操作位流见[当前协议](https://github.com/Pre-rice/ghost-maze/blob/main/docs/share-codes.md)。
