初始 A 门封着钥匙房后口，直接离开会把第一只鬼拉到不合适的位置。先开 A，利用中间回路把第一只鬼留在中部普通门右端，再关 A 取第一把钥匙。下方回路把第二只鬼带离右侧操作位；从下面回到 B，再关下 B 门暂时保护第二只鬼。这次 B 同时打开上方第二把钥匙的通路，却封住目标的接近路线。

此时第一只鬼占着下一阶段需要的中部位置，不能永久留在那里。再开 A，把它拉回钥匙房，重新经过中间回路向右上方引导，取第二把钥匙并跨过顶部门，把第一只鬼安置到更上面的普通门右侧。随后要回下方，从底部把第二只鬼引出临时保护，带经过同一钥匙房和 A 门，到第一只鬼刚腾出的中部普通门右端。

拿齐钥匙后直接重开 B，会释放仍靠着操作位的第二只鬼，无法完成目标。完成上述交接后还要先关 A，再去操作 B：第一次打开的数字门已永久消失，不能继续替玩家遮挡追来的鬼，A 门要接过这段保护。最后 B 恢复目标入口，原来用于第二把钥匙的上方 B 门同时关闭；两只鬼都已离开会妨碍目标的活动位置。

六项原图有序关系与至少四次 A，分别在 BFS 与 A* 的禁止子序列搜索中穷尽无解：第一只鬼经中部右端再到顶部右端；它到顶部右端之后第二只鬼才经中部右端；第二只鬼从 B 下方移动出来后经中部右端；第二把钥匙所在格、第二只鬼经中部右端、重开 B 的先后联系；至少两次 B；访问第一把钥匙格先于 B。这里只证明列出的子序列，不能外推成唯一完整解法或人类难度证明。

安全前缀 `U`（不先开 A）与 `LURUR`（先把第一只鬼放在中部左侧）后续分别穷尽无解；`LURRULDLD`（先放右侧并返回）仍有胜利后缀。它们由两种完整搜索核验，不是拿一条错误后缀失败推断全部策略，更不是用户实际尝试。
