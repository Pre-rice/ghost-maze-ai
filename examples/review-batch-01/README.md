# 第一批成对试玩

> 历史批次说明（2026-10-11）：下文六图包保留当时内容和反馈。两张跨层原图的楼梯表冲突，当前严格规则下不能直接重建；不要重跑 builder 覆盖原图。最新合法地图与同页回放见[总目录](https://github.com/Pre-rice/ghost-maze-ai/blob/main/docs/ai-map-catalog.md)。旧分享码和旧回放地址已弃用。

共 3 组、6 张小地图。试玩前无需查看地图文件或解答。

在 `ghost-maze-ai` 仓库运行：

```text
npm run review
```

打开 [本地试玩页](http://127.0.0.1:4178)。选择一组，分别打开 A、B；试玩后回到评审页选择更喜欢的一题、差不多或暂时无法判断，可附一句理由。方向键移动，面向按钮按对应方向，站在楼梯上按空格换层。游戏中可以撤回或重试。

如果你已经在此前讨论中看过某题解法，请据实选择“了解其中一题或部分解法”或“两题都了解”。界面只隐藏来源和解法提示，不把已看过题目的体验当作首次接触。

点击“保存这组比较”后，反馈追加写入 `data/feedback/<试玩包标识>.jsonl`。可以修改后再次保存；训练导出只取每组最新选择，同时保留旧记录以便追溯。网页顶部可以导出所有记录。“差不多”与“无法判断”分开，后者不生成偏好标签。

浏览器草稿按组保留，但草稿不会进入训练数据。反馈目录被 Git 忽略，需要备份时使用导出按钮或备份目录。仅面向这台电脑的一位评审者，不支持多评审者身份与并发编辑合并。

默认端口已占用时可用 `npm run review -- 4180`；以终端输出的地址为准。服务只监听本机，关闭终端服务后用同一命令恢复。游戏从固定子模块提供；浏览器压缩依赖由已安装的 pako 本地提供，无需 CDN。

技术契约与验证记录在 [试玩反馈说明](../../docs/review-workflow.md)。`packet.json` 是内部清单，包含来源和地图标识，建议试玩后再看。
