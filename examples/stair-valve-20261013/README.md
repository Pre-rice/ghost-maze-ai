自然计划是离追鬼远一些，尽快去按按钮。但上层鬼来得太慢时，下层鬼先进入上层，会把后续的回路堵住。关键是先从更靠近追鬼的一侧进入楼梯，让它在玩家沿同方向离开时及时占住楼梯，阻止另一端的鬼上来。随后通过上方回路改变上层鬼的停位，再按A，最后才把下层鬼带上来，换另一处楼梯回到目标层。

楼梯在此是选择进入和暂时保留另一层空间的工具，关键争位发生于配对两端；只把它理解成甩开鬼或搬运路线不足。预期认识变化是“离鬼近一些，反而能保留之后的通路”，不记作用户已确认的顿悟或挑战评价。

两条五步前缀，玩家都在同一按钮、同一门态，**公开鬼位不同**：较近的接近路线仍可续解，较远的接近路线已经无解，不是隐藏编号导致同局面不同结果。原图禁止上述楼梯进入争位，全部通关无解；不是删鬼对照或只选一条参考。22步唯一最优。[参考回放](https://ghostmaze.novic.cc/?map=AWN4ocDAwMDcyMDAy3CAgYGBaYEHBwMEdHCBSAWFhISEBAYNBgWhBrDwH8YfYAkGASGmBfoXGBhYGJQB&replay=RvY1_B6igAVkJmSw)。
