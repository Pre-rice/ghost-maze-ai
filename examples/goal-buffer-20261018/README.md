左侧的B、A也不能各自处理完毕再撤离。把上鬼调开后，A同时放出先前安置的下鬼；还需要在它逼近时操作B，配合后续转角的追距。先多按一次B并不会立刻让题目无解，可以再按B补救；真正穷尽无解的是在左A之后再也不操作B。这个区别保留在证据里，不把某条参考的操作次数当成唯一解法。
