# 《周转》

2026-10-14。单层17格、两只鬼、A／B各一个按钮、五扇字母门与两扇普通门；无钥匙、玻璃或楼梯，初态可观察。生成时未获评价；本轮用户评价“难度一般，但设计还不错”，明确上架的是[用户15格优化版](../gallery-adjustments-20261014/README.md)，本17格原图及证据留档。

<summary>设计思想与参考（含答案）</summary>

最自然的计划是先把挡A的鬼停在左门内，再开A、恢复目标B。这个停车和开A本身还能补救；但继续直接开目标，会安全完成18步前缀，随后无伤无复活续解全部无解。不是只选错下一格，也不是只试一条后缀失败。

预期关键认识是：**先停好一只鬼，不代表给后面留下了正确位置。** 初期需暂留在左门外，保留再次引动的条件；再把它迁到右门内，恢复B的保护后去开A。另一只鬼随后归左门内，A的隔离才使最后恢复B安全。停车的用途、门的阶段与操作站位相互准备。

原图禁止第一鬼进入右停位、入口鬼进入左停位、右停位→操作A→左停位的有序关系、第一鬼临时经过左门外，以及右停位获得B保护，五项分别穷尽无解。左门外的两种可走进入边均覆盖；只禁一条边仍有42步解，不能扩大为整个停位不必要。

这与《接力》的交接及《换边》的门两侧安置有亲缘。它是否带来足够挑战和新发现仍需真人体验；事件必要、40步和多个阶段不自动代表精妙。

验收：快与原生参考均证明最优40，全部12条最优无鬼重合；去终点重放仍安全，地图／操作码逐步往返一致。指定从外部(1,4)向右进入(2,4)，零钥匙、无外部鬼，全部最优内部状态一致；整图接入仍须重验。416个可达局面、2070类动作含死亡，两种排列与改编号共4140次物理后继一致。

经济性：删除无必要的顶部B门属性，把右侧下门改为实墙，原件留存。保留(2,2)是因为它让“先开A、再恢复目标”的合理计划能安全完成而失去未来撤离条件；删掉该格同40步，却使这个对照变为当步死亡，不能只用同最短判断推理作用。删鬼均变为22步，两按钮缺一无解；其余门与非实体格的对照见私人研究原件，不声称全局最小。
