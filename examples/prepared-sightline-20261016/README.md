## 调整依据

加钥匙的研究版要60步；改为0门后50步，提前准备引鬼通道的必要关系仍在，因此去掉钥匙任务。0再下移一格有48步合法解，但晚开立即死亡，少了“当步安全却失去后路”的判断，未采用为当前稿。

原15格环形主体保留；补齐左下外轮廓一格，形成单入口死路，没有新增任务，全部最优动作、每步鬼位及按钮操作与15格版完全相同。59项有限删改、邻格移动按钮、移动0、填中部和移整行均保存。去掉装饰格、把B移左都仍50步，前者轮廓失衡，后者没有省路且分开控制点，未采用；压为13格虽有合法18步解，却已丢失先开0及困鬼的必要关系。不声称全局最小，也不以这些机器事实评价趣味。[研究范围](../../docs/archive/research/objective-preparation-20261016.md)。
