# 以门为核心的单元题（2026-10-11）

用户明确要求当前阶段继续设计更多精妙单元题，从门的作用展开，不继续以字母门和按钮序列为中心。本批两题没有按钮或玻璃，不改变本体规则；质量保持待试玩，不能把依赖证明当作精妙评价。

试玩和折叠回放统一列在[本体地图总目录](../../../ghost-maze/docs/ai-map-catalog.md)。两题仍是单层单元，没有包装为全图，也没有启动模型训练。

实际过程：先按明确的门规则提出小布局，排除单纯取钥匙或分别绕开两只鬼的题，再保留双鬼占位与门作用相互联系的候选。普通门阶段种子 101107，43,269 个提案中 6 个通过机械筛选，选取索引 43268；数字门阶段种子 101108，在这些母图上提出 50,000 个编辑，2 个通过，选取索引 3324（母图索引 42426）。这些数量仅是程序提案与筛选计数，不是精品数量或质量评分。更早的探索没有被当作最终筛选成果。

普通门源图从 15 格精简为 12 格；数字门源图从 14 格精简为 11 格。精简保留指定操作依赖、双鬼占位联系和普通门的双重作用，不固定解长；第二题精简后路线反而从 19 步变为 21 步。审计仅覆盖单项删格、删实体、墙替换为空或实心墙，没有证明全局最小。

两个候选共享 `door-mediated-ghost-queue-v1` 拆分组；不要因种子、门数或地图码不同而拆成独立训练与测试家族。`humanQuality` 都是 null，未收集新的真人评价或录制。

<summary>机制证据与解法边界（剧透）</summary>

《两面》的普通门先隔开一只鬼，再用同一扇门从相反侧安排它。第一轮隔离不能直接当作最终安排；后续再次引动它会影响另一只鬼的追逐。禁止同一只鬼先进入门左端、再进入右端，或禁止玩家先左端、右端、再回左端，原图均穷尽无解。

《开路》先借普通门暂时隔离上方的鬼，再打开下方数字门，为它新建可通行的追逐路线；同一只鬼最终要转到普通门另一端，随后还会参与下方的双鬼占位。数字门改为普通门（玩家仍能过，但鬼永远不能过），以及改为初始空通路，均穷尽无解。禁止那只鬼通过数字门创建的通路，或禁止它先进入普通门右端再进入左端，原图均穷尽无解。

两题的普通门改为空或实心墙均无解，说明玩家通行与挡鬼两种作用都不能删除。禁止两只鬼任何一次相互阻挡也均无解；`ghost_blocked` 是单层影子诊断，不改变游戏规则，不代表真人体验评价。逐个去鬼后均有更短路线，两只鬼都不是装饰。

BFS 和 A* 独立搜索算法分别核验最短路线、以上受限无解与改图对照，物理仍共同调用本体。原图、快环境与地图码解码图逐动作物理状态一致，动作码往返一致；删除终点后执行参考路线仍不死亡。交换鬼数组顺序后仍有同长最优解，原参考路线也仍获胜，但不声称每一步鬼位逐字段相同。

分享与回放使用当前规则锁；参考录制只作为证书，未混入真人数据。没有证明迷雾知识策略，也没有用浏览器通关代替质量判断。
