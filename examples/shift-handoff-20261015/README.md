# 《换手》

2026-10-15，单层15格、两鬼，一个A按钮、一个B按钮，两扇A门、一扇B门；无钥匙、普通门、玻璃或楼梯。中性开局，最优38步，按逐步鬼轨迹区分有两种最优解。**未获真人评价，未入地图集。**

把旧鬼关在A门上方，只解决了眼前的安全；以后重新开A会立刻遇险。必须从另一侧把它引离门边，再回去开A。此后才开B，调来原本挡住出口的新鬼，让两鬼一起向北移动，再带旧鬼从左侧绕回；新鬼此时接替阻挡，帮玩家撤离。

预期关键是“关住并非完成，放出的新威胁才是最后的保护”。开A的安全、开B的时机和最后两鬼的站位互相制约。没有把这种预期记作玩家已经体验到的顿悟。

原图分别禁止以下事件，四次均穷尽无解：关门隔住上方贴近的旧鬼；A保持关闭时从另一侧向上引动旧鬼；在旧鬼已安排好后释放新鬼；最后由新鬼优先行动阻挡旧鬼。范围是全部无伤无复活路线，允许非致死重合，不只挑选最优参考。

全部最优无重合，去掉终点重放仍安全，地图与回放码逐步往返通过。192个可达局面、含死亡的955类动作，与两种鬼排列及改编号共1910次后继一致。指定实际从外部(1,5)右入(2,5)，再右到出生(3,5)，开局及两条最优路线的内部后继均保持；只验证零钥匙、无外部鬼且其余外边封闭的接入条件，整图另验。
