## 每关保存与检查

`build.mjs`是人工布局和设计卡；`levels/<编号>/`保存规范地图、生成时来源、全部最优和规则QA、地图码。`publish-level.mjs`验证后保存该关，`sync-site.mjs`只向Site写出不含答案或教学意图的关卡入口。地图码和行动均复用同级本体，不增加一套物理规则。

分别记录已知前提、新发现、可见证据、迁移用途和误解风险。首次介绍允许简单，但不能依赖碰巧通关认定理解；后续换布局检验应用。无伤可解、全部最优非重合、去终点安全、编号无关、合法边界与编码往返按现有验收工具检查；空鬼地图不使用仅适配1—3鬼的旧排列助手。当前为独立关卡，不声称已验证整图接入。

Site为用户明确要求的公开逐关试玩试验，源代码独立保存在Sites源仓库；不修改或发布正式站UI。仅手动进入下一关，不从跨域iframe读取通关状态，不伪称自动判胜。Site源码的轻量页面由Sites技能维护与发布。

## 当前范围与验收限制

现为20关的首条试验线路，前11关与17关为新设计，其余选用已确认图的课程副本。复用码冻结在`gallery-sources.json`，不随本体地图集以后改动自动漂移。除第16关外，复用旧码只在课程副本补齐外围墙，全部可达内部物理后继（含死亡动作）逐项对照不变。第16关把目标移出鬼的初始格，所有20条原31步最优前缀逐动作内部物理保持，末尾增加一步进入独立终点；正式地图集原码不改。[观察与迁移证据](learning-evidence.json)只证明现象与可解性，不是学习效果验收。

第03关将目标移出鬼的初始格，保留守卫入口与引开关系；最初12格版本另存`levels/03/revisions/v01/`。第04／07关成对调整距离，保证鬼在未碰门前停止，能观察视线与通行的区别；旧版均存各关`revisions/v01/`。第16关原目标与鬼重叠的课程初版亦另存。桌面1360与手机390已验证正式站嵌入、真实方向输入和下一关跳转，无脚本报错或横向溢出。页面定期读取关卡清单，增补时不打断正在进行的关卡；跨域iframe不读取玩家进度。

真正未知规则玩家是否形成准确推断、13／16／18／20的跨度是否合适，尚待真人体验；不预判。当前机械证据与规则锁验收通过，未自动调用AI试玩skill、训练或修改本体。
