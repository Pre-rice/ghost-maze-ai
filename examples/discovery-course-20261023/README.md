## 每关保存与检查

现为40关的重排版本，19张课程专用图、21张既有图的复用或课程变式。顺序以`course-order.json`为准，目录编号是稳定ID。试玩正文只显示关卡入口，不插入设计提示、规则或解法；设计意图集中在显式“设计说明 · 含剧透”入口供审查。玩家手动进入下一关，可以自由选关。刷新清单时保留正在玩的局面，被移出流程的关卡也可继续完成。

本轮改变的是组织原则。原31关将可见规则证据逐条拆开，用户认为教学明显、缺乏趣味、连续换元件太快，因此已留档撤下。现在每关先有目标、可尝试的计划和需要改观的地方，规则在解决问题时被发现；不再为补齐元件或预先讲清一条规则而加关。

前五关只围绕墙、鬼与普通门，经历引离、调位、从另一入口返回、先准备工作空间、借威胁阻路。第六关才加入字母控制，下一关仍只用A，在完整双鬼问题中主动安排保护并换控制位置，然后才进入《错位》的A/B与按钮推进。《接力》进一步交接两组保护，不再把主动困鬼称为此时首次发现。第10关57再用单A、一普通门和共享内室的三鬼继续完整任务，之后才引入钥匙。《内外》才在取物并安全返回的任务中引钥匙和数字门。53先在完整取物问题中引入0与普通门的保护差别，《暂驻》随后把停位冲突推进为重新引走，52随后撤去A继续同一0门的开启方向与退路，再由《再借》变为重新招回当帮手，49撤去字母控制后继续完整取物与追逐，再由《对门》用于共同安置，48再用两钥匙的完整任务交接B与A的保护，《换席》随后打破立即关门的收尾习惯；0在53后继续由《暂驻》的完整问题使用，之后《回望》再深化开门时机。方向主题先由11格无鬼控制室50提出“关回入口、经单向口出来”，随后19格46使用两个相反接口完成双鬼取物回程；此前43双端小室和《归途》均保留原稿，不在当前流程叠放相近题。51随后让A门影响内B控制的可达性，取物回来又要恢复A；之后《侧入》再由玩家自行选择进入方向。

《侧入》现用18格双鬼变式，删去独立的首鬼安置，集中在由终局倒推接近侧；《同行》随后用A/B与方向口继续三鬼任务，深化召回与掩护，不再称首次三鬼。《布阵》把“安置占用未来空间”应用到自己的避追口，再由《调度》改变逐段安置的办法；《留隙》随后撤去可反复关闭的字母保护，《门庭》再观察回合对相对位置的作用。少元件不等于少新关系，四鬼到三鬼也不表示思考降级。以上是当前设计假说，不是未知规则真人已经学会的结论。

第10关57为[内室交接](reviews/inner-queue-20261026.md)，接在接力与内外之间：普通门能保护进入，却可能被外鬼堵住回头，需在进入前准备队列和另一出口。25格23步、三鬼、单A、一普通门，无新元件；是课程试验，未知规则真人跨度与趣味仍待观察。

第17关55复用未评价研究《悬置》，接在逆渡与再借之间：先保留右鬼的未完成安置，才能处理左鬼，再回来完成。延续A／0／普通门，不提前增加新元件，也不当作新的高级机制突破；原图、旧锁证据和[现行另验](reviews/suspended-course-20261025.md)分开。

第24关56复用未评价研究《借道》，放在回望与借影之间：用不可恢复的0与双取物进一步应用“为未来开路”，不是立即增加新元件。出生去纯靠近、钥匙另放死路，旧六条44步最优经映射保持，新增两处全封闭地面仅为美化；[取舍与完整范围](reviews/borrowed-route-course-20261026.md)区分物理证明和趣味假说。

第35关54撤去字母等较复杂机关，在完整取物任务中首次使用楼梯；近端安置会堵住未来入口，需要从另一端准备。它是既有规划的跨层应用，不宣称高阶楼梯独有突破。[取舍及原图实际反例](reviews/overpass-20261025.md)与[两端输入、撤销和回放](overpass-browser-check-20261025.json)分开留证。

第36关58为[同室两用](reviews/shared-slot-20261026.md)，接在54后。相同上层小室第一次保持追逐并带回楼下，第二次才留下另一追者；单向分叉与跨层A保护最后返回。15格26步两种轨迹，不声称楼梯独有突破；先永久安置仍能34步恢复，不能称错误前缀无解。
