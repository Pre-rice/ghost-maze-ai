## 每关保存与检查

现为23关的重排版本，6张课程专用图、17张既有图的复用或课程变式。顺序以`course-order.json`为准，目录编号是稳定ID。Site仅公开关卡入口，不展示本表、设计意图、规则或解法；玩家手动进入下一关，可以自由选关。刷新清单时保留正在玩的局面，被移出流程的关卡也可继续完成。

本轮改变的是组织原则。原31关将可见规则证据逐条拆开，用户认为教学明显、缺乏趣味、连续换元件太快，因此已留档撤下。现在每关先有目标、可尝试的计划和需要改观的地方，规则在解决问题时被发现；不再为补齐元件或预先讲清一条规则而加关。

前五关只围绕墙、鬼与普通门，经历引离、调位、从另一入口返回、先准备工作空间、借威胁阻路。第六关才加入字母控制，随后连续使用已有元件形成不同的完整问题；第九关在取物并安全返回的任务中引钥匙和数字门。第十二关《暂驻》把停位需求冲突推进为重新引走，再由《再借》变为重新招回当帮手；0也在这个完整问题中实际用到，之后《回望》再深化开门时机。后段继续打破立即困鬼的习惯、为未来留路和整体调度。首次单向限制直接放在《归途》，不再单独加一关讲不能原路返回。

《侧入》先让第三只鬼参与进入方向的准备，再由《同行》深化提前招回与连续掩护。《布阵》把“安置占用未来空间”应用到自己的避追口，再由《调度》改变逐段安置的办法；《留隙》随后撤去可反复关闭的字母保护，《门庭》再观察回合对相对位置的作用。少元件不等于少新关系，四鬼到三鬼也不表示思考降级。以上是当前设计假说，不是未知规则真人已经学会的结论。

`build.mjs`保留人工布局与设计卡，`levels/<ID>/`保存原图、来源、全部最优、边界与分享证书。现行21关已绑定共同规则锁，全部最优无非死亡重合、去终点安全、指定实际中性入场、编号无关与编码往返通过；桌面和手机视口的正式站嵌入、真实输入与关间切换另有记录。触控仿真不等同真实手机或真人学习验收。

复用码冻结于`gallery-sources.json`，不随正式地图集漂移。课程副本封闭外围墙；《接力》另把终点移出鬼的初始格。源图、用户原评述和旧证书保持，亲缘图不转移好评、不拆成独立训练家族。正式网站代码及21张地图集均不改动，未训练或自动调用试玩skill。

## 修订依据与待观察之处

原版及每次判断改变保存在[复盘目录](reviews/)。当前证书绑定见[核对记录](certificate-check-redesign-20261023.json)；`learning-evidence.json`等旧规则覆盖材料对应撤下的31关，不能当现版关序的趣味依据。未成题原型存`drafts/`，不会因为可解、唯一或方向必要就接入公开流程。

目前仍缺真正未知规则玩家的过程反馈：能否识别按钮的操作方式、从首个A问题进入《错位》是否跨度合适、第一次借鬼是否被理解，以及后段是否产生重复感。没有虚构逐图评分、用时或提示条件，也不把原图认可当作新顺序已验收。后续依据真实卡点改问题和次序，不预先补成一串机制示范。
