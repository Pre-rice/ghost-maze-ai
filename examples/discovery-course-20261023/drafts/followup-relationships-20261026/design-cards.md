# 未采用构造的原始设计卡与判断变更

## 原设计卡：enter-control/design-card.md

# 进入控制源：外环与内室的完整取物问题

1. 目标在外环，钥匙与第二处A在内室；三只鬼也在内室，外侧A会切换几个出口，西侧单向口允许玩家进入但不能原路返回。
2. 直觉是先把鬼都留在内室，再入内取物。然而内室还是自己要去的控制位置；把鬼引出来也不等于已经为取物后的外环终点留下条件。
3. 预期是从外侧先调整出入关系，再进入内室重新取得A控制，安排出去的鬼和留下的鬼，最后恢复外环返回。两个位置切同一组门能留下不同局面，但仅机械交替不算新意。
4. 全新手工25格外环内室；与调度、57内室交接及历史互锁有构思亲缘，不伪装独立突破或继承评价。本题目标在外部且需进入内室取物，区别于直接走入内室终点。
5. 固定三扇A、两处A控制、西侧方向入口、外环1门；只比较三组三鬼初位、两个内钥匙位置、东A初态，共12稿。无额外空白房间、不新增字母或楼梯。
6. 先查全部最优重合、去终点安全及完整普通计划。再核对内外控制、出室鬼与方向普通替代的完整作用；若只是分别停车或外围持续追逐，不因必须进入／长度增加而采用。

## 原设计卡：enter-control/exit-and-reentry-card.md

# 从可行接近侧重新构造初态

保留完整外环后的12稿仍无解，去鬼诊断12项只有去掉西北鬼的4稿成立，而且都有分别处理的普通方案。可见完整外环是构造前提而非充分条件；撤回把最初无解完全归因外环的推断，不能用这个诊断声称西北鬼冗余。

具体几何问题是初始三只分布在不同角落，内室入口都被邻格守卫看护，清出中鬼也无法进入其他入口。新初态将两只移向同侧，保留另一侧的合理接近空间；西侧方向口再比较向内／向外，检验从内室退到外环之后重新取得控制，而不是单口强行闯入。

固定26格、一个钥匙、1门与三A，无新增门或房间。四组三鬼配置、两把钥匙候选位置、方向两种，共16项。检查安全与内外控制的完整作用，若只有一边按钮、外围尾随或逐只方案，拒绝该预期。没有继承其他图评价。

先对原完整外环的12项重做明确改题对照，西方向仍向内。不再扩大房间、加门或补更多控制；若无合格完整计划就停止该骨架。原37关保持。

## 原设计卡：offset-chambers/design-card.md

# 错开的两道横闸：手工21格试构

1. 钥匙在上方，目标在下方；两行A门的左右开口交错，三只鬼分别在上室、中间通道和下室，两个A控制在不同端。
2. 计划不能只说“开路、拿钥匙、再回来”：相同门态下，上下两处切换所留下的鬼位不同。希望一次切换既放行一只又保住另一处，不能三鬼逐个永久收尾。
3. 预期是先安排中间追者的停位，利用交错开口让它帮忙保住控制，再完成跨室取物与返回。若只是在外围持续追逐绕路，或全程同一按钮可完成，不以门数或三鬼包装成新意。
4. 新手工21格削角轮廓，只用既有A与1门、一钥匙、三鬼；比四个单口小室留出贯通通路。已否决的三室24项不再修补，原36基线和新37保持。
5. 固定几何与物品／控制，只比较上鬼三处、中鬼两处、两横闸相位配对两种，共12稿。不开新字母组，不加面积或普通门救场。
6. 初态冷、全部最优非死亡合并、去终点安全先筛；再用完整普通计划与真正控制历史审查，不从步数、独解或必要性宣称趣味。无真人评价。

# 三室控制与返回：完整问题试构

1. 钥匙在右室守卫身后，目标在左室的1门后，底室还有守卫；同一A会同时改变左右入口、底部入口及中间保护。
2. 熟悉的计划是先拿钥匙、在中间关A留住右鬼，再去左室。但这同时放出了底鬼，可能封住处理左鬼时的返回位置。
3. 预期必须把底室的控制与右室取物合在同一计划：在不同位置切同A，留下不同鬼位，并从方向出口恢复控制。完整计划若仍可三鬼逐个做完，不把多室或多个按钮当新意。
4. 全新手工22格T形布局，只用A、已有1门与方向口、三鬼；与旧交替控制构思保守视为亲缘，不继承评价。无需新增规则。

6. 先检查完整普通计划、去掉目标的到达安全与全部最优重合，再做按钮位置、方向普通替代和实际历史必要性。不能用必要性或步数证明趣味；尚无真人评价。
