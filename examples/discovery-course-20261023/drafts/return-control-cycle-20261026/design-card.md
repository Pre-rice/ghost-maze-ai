# 归还控制：先完成一个可执行的整体计划

1. 三处A/B/C控制沿同一个回路分布，目标路线需要A、C切换，但B要恢复初态；两个方向出口允许回到起点，却不能从起点反向进入控制区。
2. 自然计划是将需要用的开关都按好，再沿捷径返回。保持B开放虽可回到起点，却同时关闭重新取得A/B控制的路，目标中的B门又是关闭的，形成可见矛盾。
3. 预期发现：B只是暂时借用的进入条件，离开控制区之前必须将它归还；决定的不止目标门态，还有后面能不能再取得控制。关键不靠隐藏编号、追逐计时或死亡压力。
4. 完全新手工22格无鬼控制题，只用已有字母分组和单向通路，作为方向／控制可达性主题的后续候选，不宣称超过已确认精品或新增游戏机制。原37关保持。
5. 先按A→B→C→B的完整28步计划逐步核对原生引擎，再穷尽最优。之后只比较两个单向口的普通替代、B初态与目标条件作用，不加鬼或更多门增压。
6. 必须验证B未恢复就返回的真实安全前缀在原图无续解、普通替代可恢复；机械事实不证明真人有顿悟。来源与低观察负担角色要在统一说明里写清，暂不假定最终放在难度尾部。
