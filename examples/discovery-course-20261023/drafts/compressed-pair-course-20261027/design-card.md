# 并肩 · 六句设计卡

1. 目标夹在下方两只鬼之间；上端普通门看起来能逐只安置，A近控制可以隔开第一只，远控制在另一侧。先把头鬼带到普通门旁是自然尝试。

2. 直接从近控制上退并穿普通门，头鬼停在上角，尾鬼却停在目标的上方；头鬼已占住再次接近尾鬼的上口，安全安置反而失去完整后续。

3. 预期先在近控制关A：头鬼被门挡住，尾鬼因操作前看见玩家仍前进一步。再到远控制开A，回身引动紧挨的队列，穿普通门后两鬼恰留在上下相邻的两个保护位；从远处关A再进入目标。

4. 接在接力之后、三鬼内室之前：沿用普通门、A与按钮推进，在双鬼完整目标里区分先后和间距。没有新元件，不把关门最后一格另拆成规则教程。

5. 9格旗形，两个A控制、两扇同相A门、一普通门，无钥匙或新门型；下方直线表达两鬼的初始间隔。将目标由左支格移到两鬼间已有格，少一格、多一步，不宣称所有过程等价。

6. 13步唯一最优，全解范围禁止关近A、禁止两鬼从相隔两格缩成一格、禁止任一最终准备位均无解。错误先安置三步安全无续解，先按远A可共17步恢复；机械必要性和短唯一解均不代表有趣。
