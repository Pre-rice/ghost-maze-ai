# 共用落点与十字庭院：保留研究，不接入课程

2026-10-26。本组研究时公开线路为34关、Site85；后续内室稿独立发布，不属于这里的否决稿。以下没有真人评价，也不是正式地图集作品；未改本体规则。原设计卡保留为待检验假说，结论以本页和实际证据为准。

共用落点的预期是让搬上楼的鬼先占返回楼梯、之后还须清出。但15步唯一最优不用A：上楼后继续向右、取物，再从另一楼梯下降即可。删A完全同解；去上方保护变17步且全部最优重合边界失败，去取物侧保护则17步七条最优安全，但仍不用A。没有形成预期的反复调用，因此不以两层、搬运和必要楼梯当进步，也不再为这组加机关。

十字首稿12步唯一最优需要短墙，普通门替代有12步最优重合。它出生时不追，但四个邻接来向不能提供同局面的中性入场；不靠虚构外部协议放行。随后将出生改到南侧、目标移北，重新安排守卫，分别比较右侧错行与对称的布局：两者都12步四条最优、无最优重合、去终点安全，真正从南进入也与全部内部后继一致。它们是改题，非首稿的等价精简。

对称版较匀称。四条原始最优按含停顿鬼轨迹分两类，均在第11步让原目标守卫挡住两侧鬼；完整21个非致死可达局面没有合并。禁止争位或禁止这次目标守卫掩护，都穷尽无解。去任一侧鬼10步，去目标守卫6步，仅作角色诊断。

此前考虑把对称版接在第五关之后，让相同元件支持完整三鬼问题；当前不采用，因为它仍主要复述第五关“让追者帮助阻路”，并没有提出足以再占一关的新整体计划。最优参考有7步即时只余一个安全方向，但这不是单独否决理由；关键是额外威胁未带来值得延续的策略认识。对称外形、所有角色必要和机械安全不能推翻这一判断，也不因此否定所有简短三鬼题。
