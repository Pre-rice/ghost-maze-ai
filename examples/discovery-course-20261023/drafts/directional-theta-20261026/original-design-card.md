# 单向取物后必须从另一侧完成返回

1. 三条短路共享左右区域，顶部钥匙在单向口后、右守卫旁，目标在下方1门后。自然会先引开顶部守卫，再从左侧取钥匙。
2. 引走右守卫需要先保留下方转身空间，取物后又不能从原侧回来；三只鬼的停位应共同保留一次完整取物与返回，不只逐只停好。
3. 待检验发现是进入单向口前同时准备右侧离开与下方返回；两处准备是否相互制约，必须由完整路线体现。若只是绕一圈捡钥匙，或门外占鬼让方向无关，不成立。
4. 当前36关已有方向控制室、回程与楼梯的两用小室。本稿回到单层、无字母，比较能否有区别于现有46的完整安排；不因必须过箭头或原图无解就称创新。旧单向三图保持退役。
5. 17格，4×4主体含一全封闭美化格、一个目标支格；三鬼一钥匙、一方向口和1门，无新元素。出生在左上，箭头遮住同排右守卫；初始是否冷需实际核对。
6. 只比较两个中路、五个下路守卫初位，共十项有限手工配置。先查全最优与去终点，再查方向改普通的完整安排、普通无互挡通关和目标收尾冗余；不靠加门修补失败。
