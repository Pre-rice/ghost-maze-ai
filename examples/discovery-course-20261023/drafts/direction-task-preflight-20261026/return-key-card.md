# 把单向安排放进必须折返的取物任务

1. 上轮将目标放在右守卫身后，原生仍允许取完左钥匙后再引鬼，带追者一直到终点即可；“终点在后面”本身不产生停位义务。另一稿甚至去终点死亡，均不采用。
2. 本轮保留原目标位置，改用右守卫身后的死路钥匙，使进入后必须折返。只比较右侧唯一钥匙（撤左任务）与两侧各一钥匙、目标2门（保留左任务）两种完整任务。
3. 右单钥匙稿希望左区从取物区转成无直接物品的调度区；若左鬼不动、两鬼独立就能完成，不能称需要借空区。双取物稿看是否必须把回程安排提前，而不是两个独立困鬼任务。
4. 新增下端一个功能格，原19→20格，无新按钮、门种类或第三鬼。两钥匙与2在当前方向段之前已出现。不包装成原图等价精简，不转移好评。
5. 查询都排除先判胜掩盖到达死亡，普通替代使用普通门隔离玩家的单向属性；清洁常规方案明确不经过非死亡合并。不因“使用过箭头”就认定其是谜题核心。
6. 只有证明预想形成完整且值得推断的关系再作经济性与发布验收；若仍只是顺次处理或方向只增加赶路，止于此有限对照，不继续添机关修补。
