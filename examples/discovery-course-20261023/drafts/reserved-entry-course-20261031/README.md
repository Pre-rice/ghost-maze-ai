# 《门外》：出去前先留下能回来的入口

稳定ID71，替换第33关原无鬼方向小室50；仍47关。11格十字形，一鬼、一箭头、一钥匙和目标1，没有普通门、A/B或0。11步唯一最优、一类含停顿鬼轨迹；尚未经过未知规则真人评价，不进正式地图集。

## 完整问题与编排理由

钥匙在门外，目标在门内；出生在下方单向出口前，看起来先取钥匙即可。直接出去确实能拿到钥匙，但鬼仍守着上方返回通路，下方出口又不能反走。先往左引动，再把鬼留在下出口内侧，取物后才能从空出的上口回来。原守卫又会跟在身后，自己继续到达目标。

另从上口出去也能安全离开，却会把鬼留在上口，仍不能回来。重点是为返回选择离开的门与停位，不是看见箭头后照走一遍。

此前用原50的A/B控制室首次引方向，是想降低同时观察鬼的负担。现选择让一次完整取物返程承担首次方向：回到一只鬼，只新增一箭头，接着46再比较双鬼和两条返回；控制可达性仍由后面两张无鬼控制题提供发现机会，不先把其关键拆成教程。不是因为11步比原13步短而认为更好，也不声称已被真人认可。原50的9格13步v02、旧版和证书均留在[levels/50](../../levels/50/)，[原说明](old-course33-note.md)保留，原46不改。

## 普通替代与实际错误

[原图历史检查](constraints.json)五项穷尽无解：取物前鬼从不动、鬼未动就首次出门、从不穿下箭头出去、从不上口返回、取物后鬼不再移动。历史标志进入完整状态键，获胜当步以去终点排除死亡。

**箭头改普通门，最优仍11步，却可先取钥匙、再回来补做引鬼。** 改空也有同11步先取钥匙的方案；改墙无解。单向限制的作用在于把准备提前到离开前，不能按最短步数相同宣布属性无用；也不能只说它强制多走一圈。

- 直接 `R` 一步安全但无续解；`R U R` 三步已拿到钥匙仍无续解。
- `L R U U R` 五步从上口离开，暂时安全，也无续解。
- 只 `U` 一步是可恢复探看，可共13步完成；不是所有偏离都会失去后路。
