# 出口不能当回程入口

1. 出生与目标在下方小室，钥匙在上方死路。两侧出口只出不进，拿到钥匙后必须从中央门户返回，不能只考虑出去。
2. 上方两个守卫会被A的视线开闭调入中央与侧面；把威胁甩到中央不等于完成，因为它会堵住回程。希望玩家先安排接纳位置，之后再改变门态与鬼位。
3. 两个A控制位置具有不同的安全条件，先核对是否真的都需要；两鬼不能只是两次独立停车。若全程只是机械关门、绕外围取钥匙，仍不交付。
4. 第一轮不加新元素：墙、两鬼、A、两侧单向退出、钥匙与1门。去掉为开局临时想到的0，改出生偏一格保持冷开局，不保留只为增加元件种类的门。
5. 单向口的方向必须影响完整返回计划；普通门或改空若保留同一关键安排，要重新评价其作用。全部最优重合与去终点另验，不拿唯一解或互动必要性当趣味。
6. 先看真实完整方案和普通替代，布局与无条件冗余再收紧；30格方形只是工作稿，不作为最终外形，也不因已经求解就公开。
