# 《留层》v02：在完整任务里需要两次楼梯保护

2026-11-17。当前第49关、稳定ID72的修订候选，25格双层、双鬼、一钥匙／目标1、两箭头与两对楼梯，27步唯一一类。去掉原A门和按钮；原24格31步的四件资料及[旧说明](old-course49-note.md)保留。不是旧解等价精简，不入正式地图集，没有未知规则真人或盲AI评价。

## 判断怎样改变

[最初六句卡](initial-design-card.md)想让玩家先腾空楼上取物、再把下鬼放上去；实际完整检查否定这个叙述：上鬼一旦迁层就没有禁重合的完整胜利，最短反而让两鬼始终各留原层。下鬼41／43步可短暂上楼再回来，只是绕行，不当作另一种设计策略。因此撤回以“先搬走、后停车”为核心的假说，采用实际成立的双向保护问题。

原72只有31步最佳需要两次保护，37步可以独立处理。新题去A，钥匙移到上守卫后，目标改到下守卫后1门；下守卫从(0,0)移到(0,1)，增加(0,3)、(1,3)作为两步外引鬼回路，上层旧目标叶格删除，24变25格。不是地图更小，也不以少一组机关宣称品质更高。

## 完整问题

先把上鬼带下、留在下箭头下，看似清出了楼上钥匙路，却会看住自己后来引出下守卫的左侧绕路。要先引来下鬼；上左梯时，上鬼仍见玩家新位置，优先占住上端，挡下鬼跟上。带上鬼去右梯，再借下鬼占下端，挡它跟下。随后把下鬼留在箭头下，上鬼停在上右梯；取楼上钥匙，再回楼下目标。

在[完整禁重合查询](complete-plans.json)中，分别禁止全部实际互相影响、首梯口保护、次梯口保护都穷尽无解；不只是27步最佳成立。最终两鬼同上／同下也无解。下鬼允许中途上楼再返回，上鬼则不能迁层；这是本图的完整任务结论，不推广到所有楼梯题，也不扩大到用户允许的非最优重合路线。

它仍沿用原《留层》的保护主题，不称全新机制或最高新意。相较《迁居》，前题需要实际换层，本题是让追者互相阻止换层；是否能让玩家主动计划、能否看清两个事件，仍待人审。

## 精简没有只看最优

[23格左移重画](compact-review.json)将两梯与上层移近，最优24步两条也安全；但产生34步完全无互相影响的完整通关。改变了暂存鬼与左侧引鬼回路的相对位置，原25格的对应尝试第21步会死亡。这个压缩削弱了完整问题，故拒绝，没有再添墙强迫原路线。

[当前25格的单删及门替代](economy.json)是新任务的16个合法非实体单删，未重复旧72的14单删。14项无解或最优重合，不采用；上层底部两格各删仍27步，却会破坏先走上箭头后的31步恢复回环，保留这份实际可探索选择，不称全部格子机械必需。上箭头改普通门19步、改空25步、改墙仍27；下箭头改墙或空无解、改普通27。方向与原图事件是不同证据，不凭步数判断趣味。

## 验收与真正待审

[全部物理证书](final-task.json)核对唯一27步、去终点、参考／快速、地图与回放码、冷开局、两鬼跨层后的当前排列与重新编号；801态3970动作含死亡、7940次编号对照通过。真正从下层包络外(1,4)沿两步上行进入，零钥匙、无区外鬼，801态3970后继对应，只声明此入口。

[错误与补救](wrongs.json)中，先探左梯可29步、先去右梯35步、先走上箭头31步干净恢复；零钥匙提前探目标的六步安全前缀无续解，四种死亡和四种无效输入另列。直接从左梯上去的已找到51步补救含非最优重合，不当作干净方案展示，也不伪称所有安全错误均无任何续解。

浏览器验收记录另存课程根目录；以实际完成记录为准，不把原生证书替代电脑／触屏操作。最关键待审仍是：两个梯口的关系能否被主动看懂、是否只是沿安全方向自动触发、上楼后的追逐是否偏固定，以及两层观察负担。完整必要性、27步和唯一都不证明有趣。
