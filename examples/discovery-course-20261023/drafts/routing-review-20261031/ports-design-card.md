# 北口送出，侧口取物（核对前）

1. 内室右上钥匙、外侧下方目标1；两鬼分别守北口与内室。玩家两侧有箭头可过，鬼只能从北口到外围。先需要让内室腾出接近空间。
2. 直接北入会撞内守卫；从左箭头进去后不能退回，必须在内室走出取物与东口离开的完整路线。把第一鬼留外面似乎处理完，它又会占右侧以后出去的区域。
3. 先用北侧的距离把下鬼带出，在右侧安置；从西箭头进入引左鬼向下、向中，再从内室绕到钥匙，从东箭头退出，外鬼当时的位置须仍留得出后路。是否真需这种互相制约由原生普通计划反证，不先称完成。
4. 这是新手画31格双鬼取物，不用A/B／0／普通门，只用两右箭头、一个开口和目标1。与既有入内前留后路有概念亲缘；若只是两鬼逐只处理或长执行，不上站。
5. 外框5×6、内室3×3，北侧多一格深度供引出，左右箭头在内室下侧，底部单格目标支路；暂未精简或美化，不宣称匀称。
6. 比较两箭头分别及共同改普通门，核对全部最优重合／去终点、冷入口、顺次处理和不把北鬼带出等完整替代。原课程47关与正式原图都不动，通过后再做单删和入场。
