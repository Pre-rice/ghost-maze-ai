# 共用庭院：先后打开的保护

1. 目标：在相连但错开的两处取物区取得两把钥匙，再从中央目标口离开。自然计划是先进入最近取物区，借边门隔开该处守卫后再去另一边。
2. 预期矛盾：进入一处取物区会永久开放0门；隔鬼保护的消失可能妨碍后来从同一庭院调动第三守卫。必须先考虑两次返回需要的鬼位，不能把两处取物当独立小题。
3. 待检验发现：有用的不是分别困住两只鬼，而是保留一只守卫的活动，使下一次返回时它能改变中央守卫的落点。
4. 与《再借》《留隙》比较：继续借鬼本身不是新意。只有两个安全取物计划留下的全局局面确实不同，且不能照搬“逐个停好、收齐钥匙”时，才有课程应用价值；不以三鬼、两钥匙或循环帮助必要证明有趣。
5. 可观察：单层、不引入新元件，冷开局，错开庭院而非又一个方形环；所有影响来自可见门与位置。错误先手要能指出失去的后续条件。
6. 最小结构：先仅普通门、0与2门；不为补救无解堆A/B。首批只比较少量明确门位，若成为单一强制追逐链或独立分区任务即停止该组。
