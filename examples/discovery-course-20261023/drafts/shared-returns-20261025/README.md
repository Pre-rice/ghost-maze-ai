| 构思 | 实际反例与取舍 |

| 错开庭院、两次取物 | 初稿24格，两个守卫的接近受限，24个门位／任务对照均无安全到达解。纠正接近方向后，有15、17步通关却仍是单次持续尾随；返回稿的16步参考能忽略中央鬼，另一24步版本有最优重合。未达到预期整体安排，停止该组。 |
| 单楼梯、把下层守卫带走后返回 | 首稿错误地把资格门放在守卫与楼梯之间，门也挡住引动方向，九种构造均无解。把目标移到守卫后方才可搬运，但18／16步最优出现非致死重合。准备取物区的返回门后，17／19步全部最优安全，仍只是先搬走守卫再沿上层局部回路关门取物，不能解释成楼梯独有突破。 |
| 三鬼共用A/B庭院 | 八种固定接口均无安全到达解；A与单向边切断了预想的中央引动方向。是作者构造不成立，不是游戏机制故障，不加更多按钮来追回原假说。 |
| 四个3×2小室、0门逐步开路 | 16种接口中五种可解，全部存在最优重合，参考还可以不移动东南鬼。没有成立为三方安排，不把开门数量当解谜深度。 |
