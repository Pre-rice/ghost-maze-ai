# 四小室：开路也会连接追逐

1. 两把钥匙分别在北侧两个小室，目标在西南，玩家从西南出发。自然计划是就近取钥匙，依次走四个小室回来。
2. 四处连接最初是0门，经过后永久消失。顺手多开一条路也会把原本隔开的追者连通；抵达另一处入口的方向影响两只守卫是否会对称争位或挡住后路。
3. 待检验发现：不是把四处通路尽快全开，而是把尚未打开的连接保留为临时墙，并安排最后从哪边返回；取两物是同一张逐渐开放的追逐网络中的任务。
4. 对照《逆渡》与《留隙》：首次开门方向和绕圈调位均已出现。只有这里的多处开路选择确实要求整体准备，而非两个熟悉困鬼小室或连续尾随一圈，才考虑作为后续应用；不强称新机制或最高质量突破。
5. 仅0／2、三鬼两钥匙，开局可观察；6×4四块3×2小室，每块很短，不加长走廊。错误追逐产生的对称重合不能成为任何最优解的利用。
6. 先比较四个连接的端点选择，共16个固定拓扑。普通门或全部预开作对照。若参考是持续尾随取物或能完全忽略一只守卫，停止此组，不靠更多元件修补。
