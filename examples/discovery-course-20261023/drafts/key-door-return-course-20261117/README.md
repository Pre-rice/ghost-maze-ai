## 结论：不采用

三组共56个明确配方，包括未选出生与门替代。编码冻结原形，省去重复矩阵；原始构图卡的希望已被完整方案修正。

第一组13／14格双1稿的上方环行可直接到目标，左1并非原预期的必需返回；不能把画在图上的第二扇1当作钥匙复用已形成任务。收成3×3九格后，单钥匙12／13步虽会让鬼经过已开数字门，下面普通门改空依然同最优，仍可一直带着追者绕回目标。它是入门演示的可用结构，未形成值得单独插入现流程的完整推理。

再改12格双钥匙与目标2，选定出生版17步，确需先右再左；去掉普通门后21步仍可通过已打开的右口绕回，不能说普通门为全解必要。两种版本各有实际回程，却仍偏按通路排列顺次取物：下普通门版是熟悉的先困鬼、再往返；去门版是连续追逐的一圈赶路。没有因为第一次资源或机械条件不同就采用。新构没有真人体验，不能说玩家必然无聊；不采用是针对当前稿与课程价值的设计判断。
