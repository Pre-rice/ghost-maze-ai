# 单向口外的安置，还不是结束

2026-11-17。另画单层完整任务，不沿留层添鬼或给逆渡加机关。只做课程候选，公开49关与Site123保持；不是已获评价的新颖作品，不进正式地图集。

## 起稿时的六句设计卡

1. 目标在上方中路，第一只鬼守在其后；右侧另有守卫，唯一单向口从中央向下通外环。地图由外环、十字中道与右下侧室组成。
2. 把目标鬼引下来、从单向口脱身，会让它停在中央入口前；自己安全离开了，却仍回不到目标。先从右边进入还可能过早引动右鬼，不能把两项熟悉安置分开收尾。
3. 手工计划先从左侧引出目标鬼，借向下单向口暂留；再从右边重新引动它，让右侧追者在转角继续看见玩家新位置、挡它跟来，目标鬼改留侧室，自己绕回中路。
4. 使用已知借鬼与方向限制完成保护交接，不把无字母或多一间室当新机制。若普通门替代仍保同一完整问题、或只沿唯一安全方向自动发生，就不称单向门为核心，不用必要性当趣味。
5. 5×5共25格，三处全封闭格保留外形，右下侧室上下封墙、左右相通；两鬼、一向下单向门，无钥匙／数字门、按钮、字母、玻璃或楼梯，出生在下环左侧冷开局。
6. 先复放上述完整动作、全最优重合与去终点，再查普通逐只与方向普通替代、不同进入顺序；不因计划走通就插关，先判断它相对门外和既有方向回程有什么用途。

最后一稿的关口改成普通门，**两条34步的玩家输入和鬼每一步的位置／停顿均完全相同**。两种门下，禁止双鬼相互影响、禁止向下跨口，各自都穷尽无解；同口改空或封墙则原生无解。这说明门提供了必要的隔离，但这些检验没有找出值得教给玩家的方向差异，也没有证明所有次优走法都等价。

本组不纳入逐关线路。较长的取物任务确实消除了只带着鬼冲终点的捷径，但还不能说明它为玩家提供了不同于已有安置题的发现。应先能指出一种**普通门允许的完整计划**，再看箭头是否改变它；只把门列为必经元件容易误判。
