# 《留席》整区位移精简

1. 现版15格24步的中间连接格只把上下区相隔一行；任务关系是上鬼占控制、下A反相开放鬼路、取物后再处理上鬼。
2. 尝试将整个下区上移一行，删除中间连接格。并合边界时保留中央A，两侧为墙，不因新相邻而连接房间。不是删一格就让两区之间多出横通道。
3. 另把出生移到上方普通门下，省掉一个两鬼/门/资源都不变的接近步；仍保留旧出生格供回程。不得移到按钮上造成开局追逐。
4. 分别测试移出生、整区上移、两者组合共3项；若24→21仍需全部原核心条件，才采用。完整错误空间可能变化，不称完全等价或更精妙。
5. 不把14格作绝对最小证明，也不为保住旧参考增加门。当前15格v01和原证书保持，最终入口改从真正右侧外区接到新出生。
6. 重新查全部最优安全、去终点、两鬼排列、码往返、真实入场、完整历史条件和两类实际错误；电脑/触控必须实走新版本。
