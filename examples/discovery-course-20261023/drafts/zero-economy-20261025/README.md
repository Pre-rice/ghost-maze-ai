# 《逆渡》课程副本的轮廓精简

现版是稳定ID52的v02，22格。原25格、原码、原证书、原操作与分组冻结在[课程原副本](../../levels/52/revisions/v01/)。正式地图集及2026-10-19研究原件保持，未转移任何好评。

`probe.json`保存一份基图和逐项删格／组合／换出生的诊断，不给每条变式复制基图。`comparison.json`核对删三格与删四格的原图事件及普通替代；删格后的全部新外边显式设实墙，三格稿与构造器整图相等，不能只用归一化推断边界合法。

`current-analysis.json`绑定22格现版，`verify.mjs`只读复验原图方向要求、错误前缀、24步普通方案及轨迹分组。`preservation.json`由`check-preservation.mjs`生成，对照全部24条原最优及原24步普通方案，共552帧玩家／鬼／资源；不声称所有非最优探索等价。

删四格也保留同24条最优，但外轮廓变成整块直角凹口；本次留(2,2)，让边缘逐格收进。该选择是设计者的构图判断，不是玩家审美评分。换出生的稿没有得到相同物理过程，未称纯精简，也未采用。
