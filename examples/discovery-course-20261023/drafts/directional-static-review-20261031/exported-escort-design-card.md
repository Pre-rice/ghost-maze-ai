# 把原来留下的追者带出去（原生核对前）

1. 延续门外的内目标／外钥匙，但外侧多一守卫。原来把内鬼留在下口的办法，会在取物后带外追者回来，与仍在里面的鬼共同妨碍目标路径。
2. 预期需要从上口把内鬼带出去，而不是安置；在右侧绕到钥匙另一面，使跟来的内鬼在离开钥匙时挡住外守卫，自己再回目标。纸面15步待核。
3. 用同一可见出口／入口产生相反安置目标，观察是否真要求更新原办法。内鬼不能跟过下箭头，上口才是它走出去的路。
4. 这明显与再借和同行的旧鬼再调用亲缘；若仍能完整复述为普通借鬼或箭头只添错误选项，留研究，不因是门外续篇或必要互挡自动发布。
5. 手工16格、两鬼、单箭头、钥匙与目标1，无A／0。新增右上绕行两格和外守卫支路为正确接近方向提供空间，不留空大房或长走廊。
6. 只比较下口箭头／普通／墙三个固定版本，查内鬼从不出去、没有实际互挡、取物前未出内鬼以及原停车后取物的真实续解；完整最优、无重合与去终点另验。公开47关先不变。
