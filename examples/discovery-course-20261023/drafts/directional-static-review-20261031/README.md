## 两个下行口的内院

新画5×5满院25格、双鬼、两下箭头、一普通门、中心钥匙与目标1。外追者与内守卫在北口争位，让仍能看见新位置的内鬼先过；玩家从东口隔开它，再绕到西门取物。两个箭头各自与共同改普通门，四个固定对照：26步两条、22步一条、26步两条、22步一条，均全部最优安全。东箭头改普通门后完整最优动作保持；它没有承担设计卡声称的第二项方向任务，因此原稿未上站。

这里保留“北口需要实际互相影响”的机械事实，也承认它不能抵消固定的前七步绕行与重复的借鬼思路。不用禁止逐只处理无解给图评分。初次手写的严格顺次监视器不允许同一步交接，故不作为证据存入；后续均改用现有`analyzeOrdinaryPlans`，允许一方末次与另一方首次移动在同一步发生。

## 整体精简后仍未交付

两种明示出生入口各比较南口箭头／普通／墙，共六例：把固定开场改为北横道的鬼位和上方冷入口，23格20步／24格21步；改普通各少四步，改墙均无解。再将目标支路分别收至3、2、0列，六例得到22格19步或21格18步；普通门稿仍少四步。原件、参数和每条实际证书见[cases.json](cases.json)，没有把它们宣称为与原题探索等价。

逐帧追踪还纠正了一项纸面解释：在21格18步稿里，原追者第7步已停在中心墙边，并未持续追到西普通门。所称“为持续追者安排返程”有一大段实际是安全赶路。不是把这段话换个名称就能变成精妙设计。

最后另作四个明示修改：移除拦住原追者的墙，令它实际跟到西门，并比较东口普通／空与南口箭头／普通。四例都可安全通关；东普通保留时南箭头18、改普通14；东普通也删去后，两者都18且首条动作完全相同。**一处单独看可删的门，删后会让另一处原本改变计划的方向限制失去该差异。** 因而逐项删减后必须重新读完整任务，不能只积累“仍有解”和单项必要性。本轮没有为保住自己的解说重新把东门加回来递交。
