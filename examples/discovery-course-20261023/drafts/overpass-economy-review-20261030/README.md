原课程54（当前第46关）25格35步、两条对称解，保持原码与关序。这里只研究外围路程，不改公开题、不增加地图数量，无真人评价。

三种明确改法：北侧外围顶排移近北楼梯，22格无解；南侧底排移近南楼梯，22格28步十二条、八类鬼动停过程；两侧都移近，19格无解。南侧压缩通过全部最优重合、去终点、跨层编号与码往返，六项通关历史查询仍无解，包括不能从南端第一次带鬼上桥。

**这些结果最初看起来保住了主解，但并没有保住完整问题。** 原版从近南端搬鬼是可安全做出的合理尝试：`R R L L U STAIR U` 七步，鬼留在南楼梯，后续109态无解，需要考虑未来回桥入口。压缩版完整157个安全可达态（允许非最优重合、包括终局）里，没有任何一步能安全把第一只鬼从南口带上桥。原本需要比较的入口选择直接消失，`firstGhostUpSouth`无解在此只是不可达，不能解释为玩家仍须预判同一个后果。

因此保留原版。即使少七步并保留若干主解必要条件，也不能称作解谜完全不变的精简；若另作新题，也仍缺新的完整问题，不因尺寸更小而递补。工作目录还查看过填封闭格的外形，未发布为新候选。
