# 在完整问题里选择两把钥匙

1. 当前49是18格、两鬼、一个1门与唯一钥匙的完整借鬼任务，公开原件和v75保持。试验不新增一关，只考察目标2门与三处取物能否让原有两类准备成为真实路线选择。
2. 候选额外钥匙放在左中(2,3)和右上(5,2)，均不叠鬼；不能把第二颗放右下(4,4)，那会允许不惊动右鬼就取得两把，绕开借鬼核心。
3. 原先先右取物的路线会再经过右上第二颗；先引左鬼的路线先取左中、再取右上原钥匙，不必取最后一颗。两种先后如仍具有完整意义，玩家可以观察目标只需两把，而不是把兴趣点当必须收齐的清单。
4. 不以多两把钥匙冒称难度增强。新增点若不改变任务选择且破坏简洁、或允许不用借鬼通关，就保留原单钥匙版。数字2是既有元件数量关系，不另外开说明小关。
5. 先检查全部最优是否仍17步、原动作及玩家／鬼帧是否保持、各解实际收取哪两颗、所有三颗是否能取、无优先争位普通解是否出现；不把一条原参考有效当作合格。
6. 几何完全不变，只调整钥匙与终点数门。之后再比较两端视觉，仍缺未知规则真人过程；只有有明确课程用途且不丢失原核心时才决定是否更新原49，正式集不动。
