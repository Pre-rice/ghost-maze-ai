# 目标在控制室后面：两次到访不是同一套收尾

1. 以16格两组控制骨架另做完整取物问题，不直接在50上加鬼：右上A室改钥匙，真正目标在左下内B控制之后，经1门进入。
2. 内B移到A控制更深一格；新增初始开启的A门隔在A与内B之间。为了取右上钥匙而切A时，也会关掉去内B的路，不能把两个控制按任意顺序当设置项。
3. 第一次应在用于取钥匙的那次A切换前准备好B返回相位，再经单向出口离开；取物回来则先恢复A，打开目标和内B所在的深处，最后不必机械重复第一次的B重设。
4. 右室补向下单向口，在A封闭旧桥之后仍能回下室再进A控制，但不允许反向从下室直接去取钥匙。两个方向口分别支持封门后的撤离和不同的返回面。
5. 只用既有A/B、两箭头、一钥匙和1门，原16格加两格独立深处；没有鬼、文字指令或新字母组，不用遍历所有元件作教程。
6. 验证单向普通／实墙替代、最优与普通通关的次序范围，再做删门与走路精简。若只是同一圈照走两次、串门标签或控制次序并无区别，就不发布，不拿步数和必要性当趣味证明。
