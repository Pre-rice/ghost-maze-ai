2026-11-17，第14关课程候选，拟替换未评价的《借角》63，仍49关；[原双鬼22步及说明](old-course14-note.md)保持。新稿14格、一鬼、一钥匙与目标1、两普通门，无字母、箭头或楼梯。六条14步按含停顿鬼过程分四类，设计思路有两种，两种统计不混。没有未知规则真人或盲AI评价，不入正式地图集。

## 任务与判断变化

可以先将鬼留到房外再进去取钥匙，也可以先拿钥匙，再将追来的鬼留在房内，随后借普通门离开。下侧门有一种看似安全的停位，能拿钥匙却无法退出；保护必须服务完整返回，不是只让自己到物品上。

[初始六句卡](initial-design-card.md)曾预计必须在取物前把鬼留右侧。完整反例却给出同14步、先取物后内停的方案，故撤回唯一先安置的说法，没有加墙迫使所有玩家按原剧本。第三项历史检查仅指“取物后鬼从此不再移动”，不等于检测从静止中重新召回；旧分析字段no_recall_after_key的实际含义在这里明确。

新图主动取消原双守卫先后准备，以较少的已知角色负担引入钥匙与1；这是课程取舍，不称原图等价精简或难度增强。原双鬼本来也可先探1门，已有30步安全见证；新图只是让开局无需先调鬼，三步即可安全试资格，随后18步仍能完成。

## 构造与外形

[单鬼14格与13格两稿](construction.json)都可玩。13格会使外停13步、内停15步，不因少一格自动采用。当前将单鬼14格的目标叶室从右侧(4,2)转到右上(3,1)，原末步R改U，仍保留全部六条14步及两种思路，轮廓收成阶梯；没有增加第二资格门。

[完整叶室对照](goal-leaf-comparison.json)比较单鬼两份14格：在(3,2)交换U/R，并按语义映射目标坐标与1门，115态、560后继含无效及死亡一致，三种获胜到达另去终点也一致。此证明只适用于已经去右鬼的稿，不扩大到原双鬼，也不证明视觉体验相同。

十个合法非实体单删、两种去门分别留证。部分删格仍14步，却移除了另一种有效策略的分路；去下门可12步但改变了追逐与保护，去右门则失去房外保护。没有把每格都在所有解中必要，或两种方案同长当成趣味分数。原两鬼集中到钥匙区的单个固定对照无解，也只对该布局下结论，没有继续堆走廊凑解。

## 验收和限度

[完整条件与错误](economy.json)：不在取物前右停仍14步可解；取物前下停后完成目标无解；取物后鬼始终静止也无解。前两种停车旗标进入完整键，不能以一条参考的现象推定所有玩家必须这么做。

全部六条最优无伤、无复活、无重合，去终点安全；码往返、原生／快速最优、编号及冷开局通过。从下侧包络外(1,4)一步进入，零钥匙无区外鬼，115态560后继含死亡一致，只声明所列入口。

五步`U L R U U`虽有钥匙却无续解；开局右侧探门三步的局面安全，向1门移动不推进物理状态、鬼不动，再规划可18步通关。四死亡与四无效输入均留实际证书。
