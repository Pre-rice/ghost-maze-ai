# 《借道》课程适配原件与对照

原图仍在`examples/borrowed-route-20261013`，无人评分状态保持；平面旧资料不改写。通过原分享码交给本体解码得到规范层地图，当前原图44步六条参考仍成立。选用版本见[课程复盘](../../reviews/borrowed-route-course-20261026.md)，不是原历史入口脚本的旧锁证据替换。

本轮先试仅移出生、仅移钥匙、组合与交换目标。把上钥匙挪到通路格会44→30，换目标也30并失去实际互挡；这两项没有保留原取物折返，未采用。设计方法早已要求分清死路钥匙与终点，本轮这些结果是应执行既有边界的反例，不再造一条新口号。

选用版本把取物端点移入左侧新死路，初位不再与鬼重合；出生内收两步但保留仍用于普通门回程的(1,5)。六条旧最优各去两步开场靠近、增两步取物，仍44步；258个对应玩家／鬼／共同门态帧匹配，12个新增取物帧鬼不动。资源在新钥匙格才增加，不能说每一帧完整状态都没变。

初步先不填装饰格，是尚未核对整体外观。电脑实际画面暴露出两处完全封闭内虚空，目视比较后按用户“美化允许保留无任务地面”的既有要求填成地面，全部墙保持。22→24格纯美化不增加路线，286态、含死亡1425类动作后继完全一致。原22格机械分析、完整证书与操作记录分别以`pre-void-fill-*`保存，当前操作与证据绑定24格版本，不把旧截图冒充当前验收。

`variants.json`用原规范地图加编辑保存有限对照；`current-evidence.json`是24格选定版本，包含适配新取物格的八项原图约束、错误计划、全部最优与映射。`cosmetic-equivalence.json`单独列明填格范围。两种左／上取物端点均可45步；最终出生进一步内收到(2,5)，选择左端点与整体重心，44步、六条原始最优、两种含停顿鬼轨迹。步数或轨迹数量不作质量标签。
