# 取物端点保持为端点

相邻必经格钥匙30步、交换目标30步都未保留原任务：前者免去死路取物后的折返，后者把需要返回的取物位置改成可以直接结束的目标。现成的方法已要求区分死路钥匙与终点，本轮应执行这个边界，不把反例命名成新发现。

仅比较把原上钥匙移入原位置左侧或上方的一格死路：保持从(2,1)进入、取物后仍须经(2,1)返回，出口仍在右侧2门后。目的为消除鬼／钥匙初始重叠；代价是一个取物格和两步短往返，不把它算作增强难度。出生内移的一步纯赶路仍去掉。两种外形只选读图与匀称更合适者；不擅自填装饰封闭格。

若最优动作仅在旧取物后插入两次无鬼移动，并且原0准备／交接仍成立，可作为保持任务的课程适配；仍不称所有错误探索等价，也不把两步停顿从解法分组中删掉。原图、两份放宽任务的反例都保持。
