## 完整问题与取舍

左室先取钥匙，把左鬼暂留普通门外，再到右室取另一把。回程从侧面经过左室，会重新引动先前已安置的守卫；应把右追者带回来，让它优先占旧格，挡住旧鬼，自己才有到目标的通路。它是“旧鬼重新成威胁、新追者要保留”的问题，概念仍与再借亲缘，不宣称发现新物理机制。

[最初六句卡](initial-design-card.md)及[两份20格构图与手算30步](construction.json)保留。原方案把左／右室分界放0，普通门暂留左鬼；但[原20格完整审查](analysis.json)与[去0对照](without-zero-20.json)表明0改空后全部十条26步最优、逐步鬼位、玩家与资源保持，因此去掉。0换普通门可22步先右后左，不是原图必要性证据；不能因此说0必不可少。也没有宣称全部错误探索等价。

20格有下侧回廊；再删两格成为两个斜接3×3室及一个目标格，保留四条26步与两种右侧调动，18格实景更匀称。主动减少部分探索，不称全状态等价。[形状对照](shape-comparison.json)另存：只删右室左中格的19格稿虽20步，却已有完整顺次与无实际影响方案，未采用。

[最终12个合法非实体单删](final-economy.json)：十个无解；删左室中格可36步但增加外围赶路，删右室封闭美化格保持26步却形成不美观的虚空，均不采用。普通门改空或实墙均无解，删任一鬼分别18／16步；只留一份钥匙任务也大幅退化。这些消融不等于原图事件必要性，更不等于趣味评分。
