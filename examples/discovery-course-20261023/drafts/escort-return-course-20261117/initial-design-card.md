# 追者作伴的返回（设计中）

2026-11-17。当前49关、Site117保持。全新手画的斜接双室取物返回问题，与再借、借道的角色交接有概念亲缘，不复用原布局，也不继承好评；没有字母机关或楼梯。不把普通门换单向门就称新方向核心。

六句设计卡（待证）：

1. 左室上方、右室下方各有一把钥匙和守卫，目标在左上独立小室，需要两把；出生左室下边，可以先观察。
2. 预期先收左钥匙，把旧守卫留在普通门上侧，再去右室。若把第二追者甩掉，回左室从侧面又会引动旧守卫，通路不再安全；要比较是不是只有熟悉的逐只困鬼。
3. 正确预期让右鬼沿打开后消失的0门继续跟来，最后回左边时它仍见玩家新位置，抢先占旧格，把被重新引动的左鬼留一格，让自己到目标。不是将每只各关一门就完事。
4. 已经接触钥匙、0、普通门和争位后，用完整的两份取物与回程安排提出“追者不能甩掉”的问题；它是角色用途的更新，不宣称新物理规则。
5. 两个斜接3×3室与一条下侧回廊，共20格，右室中心四面封墙作轮廓填充；两鬼、一普通门、一0、目标2，无按钮、箭头或玻璃。下回廊与右室中段本应隔墙，另作开通对照，避免把自动相邻当默认必须连通。
6. 手算30步先用唯一引擎重放；再查全部并列最优、去终点、完整普通替代、两鬼再引动和实际互挡，之后再决定是否值得精简或接入。若只有原计划可走，也不能据此宣称有趣；原49图不改。
