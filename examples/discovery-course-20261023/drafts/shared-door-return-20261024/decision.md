# 先看实际完整方案，再决定是否接入

初始手工想法是两房取物返回：以为把鬼停在门后会占掉回程，所以需要重新安置。4×4稿穷尽无解。扩右房一列供引出守卫后横向退让，再加一段短墙留出转角遮挡，得到20格、19步、八条原始最优且全部无重合；封闭目标的一个入口、只留一扇1门后仍19步，两条最优。

逐步读实际方案发现，原先预计的停车与重新接管没有发生：第一只鬼始终跟随，两次在转向中挡住第二只，玩家取钥匙后直接返回。上普通门从未必需通过，下普通门也不需要隔断后续追逐。上门改墙或下门改空，分别保留全部两条最优；两个改动组合后也保留同样最优。短墙改空则穷尽无解，说明右侧退让后的视线确有作用，但不能据此把整图称为新的回程发现。

因此不按原六句卡宣称发现成立，也不因19步、两次优先争位或看似很少的元件直接接入。它还可以作为未评价的追逐取物原型，但当前不能替代《内外》的首钥匙完整问题，更不该为了讲数字门再加一关。保留全部原件和改图事实，未分配关卡ID、未公开、未做完整交付验收。
