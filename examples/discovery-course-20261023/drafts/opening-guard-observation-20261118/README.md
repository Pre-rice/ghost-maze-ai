# 开场时，能不能先看见路是怎么被堵住的

1. 保留开场只用墙、一只鬼与目标；看玩家从两个方向走近，是否能看见不同的结果。
2. 第1关的守卫原在目标正上方。玩家走到右下角，它就踏进目标；此时玩家仍活着，应查能否继续完成，而不假设必须死亡才知道有危险。
3. 比较原出生、靠近目标的下排出生与中间连接处出生。想缩短“看见目标还空着，到鬼堵住它”这一段，也想保留从另一边先调动守卫的办法。
4. 第2关要延续的想法是换角度再引动。分别查首两关是否真的非得让鬼停下再引动，还是持续让它紧跟也可以完成；不能把设计者的意图当玩家必须学到的规则。
5. 三个开场构造只动出生。若靠近导致回头又回头、轻易绕半圈就通、或丢失了原图的安全观察，优先保留原开场。新稿仅作方案对照。
6. 分别核对原生最短、去终点、先看到堵住目标的安全方案、首次动作及恢复。时间、实际是否注意到鬼、是否有趣都需要未知规则真人，不从搜索长度推断。

## 11月20日的取舍

保留公开版第1、2关。第1关的8步最佳已经展示鬼移动、停下和再次追击。若走另一条路，也可在启动追击后让鬼一路跟着，10步通关。另有安全看到鬼占住目标后退回的12步走法。第2关的两条13步最佳都安全，而且穷尽合法的安全走法后，找不到鬼一旦开始追击就从未停过的胜利，也找不到停下后始终不再行动的胜利。两关在这一点上形成进阶。

| 第1关对照 | 安全通关与可观察现象 |
| --- | --- |
| 13格原图 | 8步最佳就能看到鬼停下再动。只持续追击的10步走法仍可通关。 |
| 13格，出生移近目标 | 向右一步可见鬼占住目标，向左能从另侧引鬼。两种都是8步。最短看到停下再动的胜利是12步。 |
| 8格小环 | 保留走近时的两种8步计划。每种胜利都要至少一次即时折返，但穷尽走法后看不到鬼停后再动的安全胜利。 |
| 11格，环的左侧保留回廊 | 两种8步仍在。也能10步看到停后再动，可供以后试比较。回廊全开与中间留墙都核过。 |
| 填满9格 | 2步能碰到目标，但去掉提前判胜就在最后死亡，弃用。 |

保留第1关的依据是原稿较早提供了两个与第2关相关的现象。近出生稿在观察目标堵塞上更直接，是否更适合初次接触仍待试玩。第1关能用不同走法完成，后续也不能从某一次通关推断玩家已经掌握追逐规则。
