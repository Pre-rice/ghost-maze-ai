## 希望玩家自己发现什么

目标在下方守卫前。直接从右口往中道切，看似更接近目标，两步仍安全，却让横道鬼抢先跟来，之后始终无法腾开目标。预期先从右端调整横道鬼，再到下方引动目标守卫；把目标守卫带在前面，在交汇时让它优先占格，横道鬼暂少走一格。再经另一条横道绕回目标。顺时针和逆时针两种都可完成。

目标守卫启动后可以持续追来，不需预先困住它。作用从“阻碍我取目标”变为“帮我通过另一威胁”；这延续已知借鬼主题，在课程早段用少量元件提出完整目标，不宣称新规则或最高新意。

原短题只有7步，可能偶然完成而没理解。选择替换它的依据是新布局有完整进入和返回，以及可以安全做出、会失去后路的中道选择，**不是17比7长所以更好**。未知规则初见是否仍能自然接上、会不会只是多绕一圈，尚待人审；旧图继续留在[levels/35](../../levels/35/)，[原说明](old-course5-note.md)和原码不覆盖。
