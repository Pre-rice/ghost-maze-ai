# 单向回程的单鬼减负（核对前）

1. 原34关46是左室取钥匙、按右鬼停位选返回，两个相反方向口承诺进入和回程；希望减轻首个带鬼方向问题的观察负担，不增加教程。
2. 单删鬼也可能删除禁止捷径的条件。纸面怀疑只留右鬼能从0侧口进入而绕开上箭头，只留左鬼则可跟随绕出直接到目标、绕过右箭头；两者都可能只剩普通取物。
3. 若原有进入前考虑返回、两种准备和安全错误选择仍保留，才考虑替换；短解或更少鬼不直接证明更好。
4. 亲缘仅当前46，原图未获未知规则真人评价，不继承任何旧图好评。旧研究已列删边／格，未列这两种删鬼，故只做两个明确对照。
5. 不移动墙、目标或钥匙，分开保留左鬼／右鬼。完整物理仍由本体给出，逐步编号重排只为合法编码，不改变状态推理。
6. 查原生最优及全部并列、去终点安全、禁止每个箭头跨越、近口停车的恢复。发现目标变化则记录未采用，原图与公开47关不动；不为保住解释再加机关。
