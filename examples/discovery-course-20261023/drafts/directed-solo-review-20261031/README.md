# 单向回程单删鬼：两种均不采用

当前第34关46的两个对照：只保留左室鬼、只保留右侧目标守卫，墙、钥匙、目标和位置都不动。原19格、16步九条及公开47关保持，无新质量评价。

| 布局 | 原生最优 | 不穿上方入口箭头 | 不穿右侧出口箭头 | 原停车后进入五步错误 |
| --- | --- | --- | --- | --- |
| 原双鬼 | 16步，九条 | 全部无伤获胜无解 | 可同16步 | 安全但无续解 |
| 只留左鬼 | 14步，六条 | 全部无伤获胜无解 | 可同14步 | 可共16步恢复 |
| 只留右鬼 | 12步，八条 | 可同12步 | 可同12步，同一方案绕过两者 | 安全但无续解 |

原图的停车前缀`L U R U`四步仍能共24步恢复；多走一步进入上箭头后无续解。只留左鬼时这五步可以共16步完成，前置安排对返回的影响被抹去。只留右鬼虽然保住这个错误，却允许从0侧口进入取物、12步不用任何箭头到目标，原上方单向进入的作用被绕过。

**原图已经存在同最优不走右箭头的方案。** 因此不能只凭删鬼后“不用出口箭头”判损失，更不能声称原图所有通关都得穿两箭头；原题是按右鬼实际停位选不同返回，左鬼还限制了侧口捷径。也不把原所选路线里的互挡说成全部最优必学，已有无实际互挡的同最优证据仍有效。

两种单鬼稿均通过冷开局、全部最优无重合、去终点安全、码往返和物理编号检查。拒绝替换的依据是完整任务和进入前规划发生变化，不是无法求解或步数太短；这些仍可能成为其它简单题的构件，不宣布单鬼方向题没有潜力，也不把原双鬼题的趣味视为已获认可。

[固定对照与原码](review.json)只保存配方和证明，不复制两份完整地图。查询历史与物理态一同入键，获胜当步另以去终点排除死亡；允许非最优重合，没有把错误分支中的重合扩大为禁令。原流程未改，不做网站或真人试玩声明。
