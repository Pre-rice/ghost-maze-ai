## 三鬼入口暂不替换

原《腾位》现行23步唯一最优仍安全，但参考有13步即时只有一个无伤方向，后段仍主要是连续尾随；更短没有直接解决作为三鬼过渡的完整体验问题。没有因此否定原图的一般价值，也不拿这个动作数单独判趣味。

改目标的对照把任务放到交接区：

| 调整 | 当前实际结果与取舍 |
| --- | --- |
| 目标内收至(3,3) | 26步两条最优，全部无重合且去终点安全；不用A。A固定为墙、删除按钮后仍同26步。 |
| 两只中排鬼内移 | 24步唯一最优、安全；省去一次纯拉近，后面仍主要按安全通道跑，没有据两次实际交接就当作新意。 |
| 左转收窄及删旧终点 | 无解。原左侧绕行不仅是赶路，还决定侧鬼停在哪格；缩圈破坏间距，不能声称“精简保持核心”。 |
| 目标改到(5,3)或(4,4) | 分别2步、14步，均可不移动远端鬼；不是三鬼的新应用。 |
| 去掉目标下保护墙 | 12步最优虽然无重合，但去终点重放会死亡；不把本体先判胜当解谜保护。再开左侧另一段墙则无解，保留A也未救回。 |

这些改稿不接入，不用多放几只鬼、增加新保护或操作次数修补价值不足。原《腾位》及其无真人评价状态保持。

## 两处新的构思没有成立

四小室将目标改到东南并调整守卫，试图使那只鬼真实参与返回；16种固定接口均穷尽无解，不扩大为所有四室布局不可能。

双环17格构思的八个初位也均无解。更根本的问题是箭头允许方向从终点出发，正常终局以前不能实际使用：固定为墙后，全部非终局可达物理动作后继（含死亡）一致。因此这张设计卡提出的“方向迫使切换返回”没有成立；箭头只是换外观的障碍。没有改成普通门后可走捷径，就声称方向已经成为关键。

这个构思层面的反例应在求解前发现。后续先画允许方向在完整计划中实际承担什么，再分别比较普通门与实墙；“限制了玩家”“出现了箭头”不足以说明有趣，不复活已遭否定的旧单向三图。
