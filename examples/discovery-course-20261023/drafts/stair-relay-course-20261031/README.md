钥匙在楼下，目标在楼上。先上楼开A，才能安排取物和返回。上鬼能在左梯口替玩家挡住想跟上楼的下鬼；跨过箭头暂时隔开它以后，却不能就此算处理完，因为它还堵住最后目标的接近。最短计划先由下环重新召回它，再从右梯回楼下，由下鬼反过来挡住它下楼。两只鬼都留在原层，玩家取物后从左梯回到目标。

这不是“所有通关都要两次互挡”。[完整历史查询](analysis.json)在无伤、无复活、无非死亡重合范围中：无实际互相影响或省首互挡最短37步，省第二互挡35步；先取钥匙后召回35步；任何一只鬼真正换层最短41步。召回本身、不把上鬼永远留在首次停位，以及A则对完整获胜必要。角色位置和事件历史进入完整搜索键，最优条件与全部获胜条件分开。

《同室两用》用一只鬼在同一小室先带回、再留下；本题讨论两鬼在不同梯口接替保护。楼梯追击与当前位置一起争位是实际关键，但是否形成了新的发现而非自动走出、是否难以观察，都待未知规则真人审查。31步和唯一解不作趣味评分，35／37步普通办法也明确保留。
