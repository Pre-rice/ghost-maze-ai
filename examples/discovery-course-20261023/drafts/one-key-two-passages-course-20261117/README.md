# 同一把钥匙打开两处通路（本组未采用）

2026-11-17。公开49关保持。此前单鬼双1的新画环路未形成值得插入的任务，本次不重做那组；只研究《借道》已承担真实引鬼通路的两扇1，能否在较少角色负担下保留完整的准备与返回。

六句设计卡（待实际反例修正）：

1. 近处钥匙在右下，第二把在左上守卫身后；目标2在右上，两扇中途1隔着守卫要经过的路，普通门位于左下。
2. 自己能穿数字门不等于已安排好鬼的退路；只拿钥匙、从右上引鬼再走近出口，可能把它留在取物后还要经过的位置。
3. 希望同一把钥匙先开下方1，为未来引鬼准备，然后开上1、借普通门留下追者、取第二把回目标；“钥匙是资格而非消耗品”出现在一项真实目标中。
4. 参照未评价课程56去掉走廊鬼(3,2)，不把原双鬼合作当成保留；如果一只守卫可直接随便绕圈取物，不因两扇1仍出现就采用。
5. 先只去一鬼，不挪任何元件或补门；走通后才看哪些地面与普通门真的参与任务、能否通过移动收短，原56保持。
6. 比较完整不提前开下门、单门普通替代与无鬼诊断；全部最优／去终点、错误恢复、入场及网页仅在构思值得后才完整验收，不以步数、必要性或规则复用算品质。

## 实际结果

只留上守卫的24格稿30步十八条，仍可始终不打开下1；一条完整参考从右上引鬼、绕下方大圈、穿普通门，再拿上钥匙到目标。它没有保留期待的两处通路准备，不能把画着两扇1当成钥匙复用已经成为任务。

再反过来只留走廊守卫，22步唯一，同样可以始终不开下1；先拿近钥匙、借普通门留下鬼，然后收另一把即可。上1甚至可等收齐两把才通过，没有得到原设想的“持同一把先后开两处1”。两份全部最优去终点安全、重合／玻璃边界通过，但安全不意味着值得新增。

所以这两稿都不采用，也不继续缩成两次独立取物的演示。原56双鬼的完整准备确实不能只靠删鬼自动保留；既有原题及其资料不改。本组没有继续普通门消融、去鬼、全编号／入场或网页验收，没有完整发布证书、真人或盲AI体验，不进训练。公开49关、正式地图集与Site121保持。
