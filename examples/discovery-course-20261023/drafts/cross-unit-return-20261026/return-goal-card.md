# 改为取物后回旧区：先核对有无新的整体关系

原4稿均可解，63／56步且全部最优安全、不能三鬼逐段收尾（实际只有两鬼，应称两种独立次序）。但是前32步基本原样完成错位，后段沿再借借旧鬼，不因同一只鬼跨区就宣称整体新意成立。这只是兼容性正例，原稿未发布。

新完整目标：右侧原终点改钥匙，最终目标放在左侧原通路末端新增格(0,5)，以1门接(0,4)；不在既有主通道加锁、不截断原回环。右侧按A／B时还会改变左侧上口与底口，取物并不等于已经保留回程。

检验的是：若右操作把左A两口一起关上，左控制已不可达，应在哪里、什么鬼位下恢复；不是只追加几步回头走。全图仍须完整安全与真正控制位置查询。只对原4个映射／初相位重做，不增加其它机关。

若仍是旧两题加纯赶路，不接入；再考虑用实际冷中态作初局省去已学熟练前奏。中态重建必须另验初态冷、分享与全图物理，不能把录像截段冒充新好题。
