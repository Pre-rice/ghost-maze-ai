# 两个交叠小院的回程（本组未采用）

2026-11-17。公开49关与Site121不改；不沿留层继续添门，手画一份新的双层空间问题。与既有上下安置概念亲缘保留，未获任何评价，不先声称新颖。

六句设计卡：

1. 下层横向两端分别是守卫和1门目标，上层纵向两端是另一守卫和钥匙；两个紧凑小院相互交叠，只有两处配对楼梯连接，出生在下院侧角可先观察。
2. 沿最近楼梯上去拿钥匙，再直接回来，可能把追者带到自己以后仍须使用的落点；单纯“到了另一层就安全了”不足以完成往返。
3. 期望通过选择进入与返回的梯口，把一层的追者带走、让另一个暂留；同一投影位置的上下格必须分别计划，能否出现有价值的相互准备以完整获胜方案为准。
4. 不新增字母、箭头或普通门，只用已知钥匙／1与楼梯；若实际只是两个普通环路逐只绕行，或安全首步自动安排一切，不作为新关。
5. 原型上下各八格，两处楼梯在(2,2)与(3,3)；小院仅2×3，无长廊和整片空白，没有故意多铺空间来放大步数。
6. 先在本体走通全任务，再查全部最优重合、去终点与普通替代；不以使用楼梯、鬼迁层、独解或最优长度当趣味。之后才决定是否值得做完整入场及浏览器验收。

## 实际取舍

七份是按上述问题逐次手画的明确修改，不是随机撒元件。每份冻结完整地图和第一参考；[复核](complete-review.json)分别查全部最优、全部去终点与排除重合后的完整可解性。

| 固定稿 | 实际结果 | 未采用原因 |
| --- | --- | --- |
| prototype，16格，右侧目标／南端钥匙 | 10步两条，全部安全 | 可以直接取物再离开，下守卫没有真正阻挡目标，基本是赶路。 |
| goal-return，目标移到下守卫身后 | 13步最优重合；干净17步可解 | 最优不符合边界；不能拿另有安全解放行。 |
| return-bay，上梯横侧封墙、下院右增一列 | 18格15步六条，仍有重合；干净17步可解 | 错开入梯横侧没有解决后段两鬼从两面汇合；不继续说“新位置优先已全解决”。 |
| guarded-key，钥匙移上守卫后、一普通门在上院中口 | 19步三条，全部最优无重合且全部去终点安全；无实际互相影响同19步 | 参考先用普通门留下上鬼、取物，再单独绕下鬼；楼梯仍只是两个区域之间的通路，未达到预期关系。 |
| without-door，撤上院普通门 | 穷尽无解 | 空间关系本身尚不能完成任务，删掉熟悉装置不自动变成新题。 |
| lower-door，普通门移下院 | 19步重合；禁止重合无解 | 本稿整个干净任务不成立，不只是一条错误参考。 |
| split-return，下院中口再封一墙 | 21步仍重合；禁止重合无解 | 墙只增加绕行，没有修好整体关系，停止这一近亲迭代。 |

判断依据是实际完整方案，而不是“无A更纯粹”或尺寸更小。原构思希望两层相互准备，安全稿却仍可逐只用普通门处理，所以不接入，也不再给它添机关追回期望。没有执行入场／全编号／网页验收，不冒称已交付地图；没有真人或AI盲试玩、训练。本体、正式地图集、当前49关与Site121保持。
