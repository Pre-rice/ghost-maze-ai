# 被占用的控制点

1. 单A双鬼，钥匙在下方，终点在上方1门后；上方按钮是首次打开下方入口的唯一控制。玩家起初会尝试打开门、各自隔鬼、取钥匙通关。
2. 从上方按完A再跨普通门离开，会把追者引到刚才的按钮格，控制位置被占据；立刻彻底解决这只鬼又会妨碍离开上方，不能照独立关卡逐只结束。
3. 预想是暂时保留上方鬼，使用下方A开放另一追者的横向路，再恢复下方入口；取物后才回上方，把原守卫引到普通门另一侧以抵达目标。
4. 只用已见A反相、普通门、钥匙与1，无新元件。与悬置的“暂不完成”保守同亲缘，但控制点被追者占住是本次新的布局关系；不继承旧作评价。
5. 15格上宽下窄收腰轮廓，两处A、四A门、两普通门、一1门；上方最初误用的7格A/B小构思只有固定短顺序，未作为关卡发布。本次单A两区去掉资格型初始化A与冗余控制，完整计划已先手推，原先24步漏记从出生进上区一步，修正为25步后另用原生实走核对，不将可解归因于搜索量。
6. 必查所有完整通关能否依次彻底处理两鬼、能否不把上鬼停在上方控制、能否取物后上鬼不再动；并查安全前缀的恢复、普通替代、全部最优/去终点/编号/真实入场/码往返。若只是两道小题加路程，不发布。
