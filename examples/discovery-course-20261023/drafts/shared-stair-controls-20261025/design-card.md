# 一个楼梯、两层共用字母控制的试构

1. 上层取钥匙，下层目标；A改变上层取物入口，同时改变下层守卫与返回楼梯之间的隔断。
2. 希望玩家发现眼前安全的停位不保证在上层切换门态后还能安全返回；不以往返两层本身作新意。
3. 下层已有单向口可甩追者，关门困鬼与让鬼继续到另一格可能留下不同的回程空间；实际查是否真的有选择，而不是自动展示。
4. 一个中心楼梯，两个3×4小场地，已有普通门、A、箭头、1门与钥匙；不继续增加鬼数或新元件。
5. 比较删下层按钮、删上层普通门，以及不让鬼转层的完整通关；冗余按钮不能只为营造看似复杂的机关保留。
6. 若最优只是先完成下层独立安置、再完成上层独立安置和取物，不称合作；若普通分区已解释全部计划，不作为高级楼梯突破，不急于接入。

后续改为下层原退出小室的1门目标，移除无用的下层按钮。单楼梯共享保护原稿虽有目标与取物，但穷尽无解；接下来只试少量上层连接的单处改变，不扩大场地，不加第三只鬼。若开放后重新出现独立的同最优方案，也不采用。实际连接、预算未知与否决理由全部分别记录；必要性只是筛选，不预判趣味。
