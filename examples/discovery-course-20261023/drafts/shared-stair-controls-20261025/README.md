# 单楼梯的共享保护小室：不继续递补

最早22步稿把下层退出角用作暂驻，上层独立取物；不用下层按钮仍保留同22步参考和三条原始最优的计数，不据计数声称全部探索等价，也不把跨层控制当合作。它未接入。

把下层退出角改为1门目标、取消无用按钮后，两个上层共享保护稿分别穷尽212／265态无解。为了检查是连接过窄还是已有整体关系，只改上层一处内部连接做31项有限反事实：13项可解，其余无解，没有预算未知。13项都存在同最优且没有鬼相互阻路的完整通关。故这一组没有形成预期的合作，不继续加门、扩大场地或递补课程。这不是所有单楼梯或共享保护构造都不可能的结论。

`probe.json`、`shared-room.json`各保留一份基图及明确地图差异，`connections.json`保留共享保护基图和单处边改动。三个`verify-*.mjs`只读重建、复算，并比较冻结结果；未知不会当通过。逐鬼对照沿用临时唯一标记并核对物理不变，初始无交会动作不得误报互动，历史角色没有被塞进物理优先规则。

没有发布证书、网页试玩、真人评价或训练，原公开32关与本体保持。层数、必须转层、最优长度和互动必要性均不是趣味评分；当前否决的依据是实际普通方案或构造尚不成立，不靠这些指标代替玩家判断。

后续一步位移工具补上显式重合分类后，又实际重放本文件用于否决的13条原普通反例，全部无重合且去终点安全，见[补证](clean-witness-audit.json)与`verify-clean-witnesses.mjs`。旧查询是逐鬼位置对照，不自动排除所有联合事件；这里保留其原义，不改冻结数据。
