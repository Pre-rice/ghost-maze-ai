# 0门的开视线试构：有作用，仍不接入

25格单层，双鬼、0／1与一钥匙。初态0门确实遮住北侧守卫；改空会开局直接被看见，原路线也会改变鬼的停位。它不是完全无作用的装饰。但0改普通门后，仍可用同一15步玩家路线通关，实际规划主要是引离、沿外围取物再到目标，未形成足够新的完整认识。

本体参考、初始改空与普通门对照都为15步。原稿三条最优中含非致死重合，边界审查返回`optimal_solution_uses_overlap`，直接不放行；不为保住这稿专门堵掉捷径，也不拿真实无重合参考或相互阻路必要性辩护。

早期逐鬼位移查询会漏掉“两个鬼各自都能走入同一格”的重合路径，曾把15步重合捷径列作普通反例；[旧查询摘录](position-only-query.json)与当前结果分开。修正后原图没有无互挡且无重合的通关，但这不证明有趣，更不能替代全部最优边界。旧研究用于否决的13条普通反例已另行实际重放，均无重合，原取舍不变。

`verify.mjs`只读重建地图和复算新查询，调用[一步物理对照](../../../../src/design/ghost-influence.js)。它区分重合、位移影响和死亡；不同层可有重复编号；去终点死亡另查，不把终点之后的反事实当实际争位。没有发布、真人评价或训练，公开32关保持。
