# 取物之后在哪一侧停鬼

## 初始设计卡

1. 一只鬼守着上路。先从下方穿过单向门，能把它留在身后，腾出取钥匙的时间。
2. 钥匙和终点的两道 B 门初相相反。取到钥匙后，还得回到左室拨 B；一路带着鬼赶路时，多停的这一步可能致死。
3. 设想先去重新引动留在左室的鬼，把它带进右室上侧的 A 门，再从门下按 A 停鬼，自己走回左室。
4. 把单向门换成普通门时，要实测能否让鬼留在口的另一侧、自己安全回左室按 B。重点是回程想把追者留在哪边，以及玩家能否自己发现另一种安排。
5. 两个并排的小室，共18格。一鬼一钥匙，A 保护，B 交换，终点有1门。不给玩家文字指令。
6. 先实走取物、回程和按键，再分别查两种门下完全不按 A 是否能过。若可以直接跑回或普通门没有改变选择，撤回这个构想；若只有固定的一串几乎唯一按法，也须和已有课程比较后再作取舍。

## 交付稿《放行》

第35关，接《门外》，再进入双鬼回程。独立手画，尚无未知规则真人的尝试记录。[逐关试玩](https://ghostmaze-discovery-path.prerice.chatgpt.site/?level=78)

起初想让返程必须依赖右侧 A 陷阱。将两组门归并成一组以后，出现了更适合放进课程的解法。A 同时管着钥匙房、旁边的困鬼口和远处的出口。在右侧先困鬼会把钥匙也关起来。取到钥匙以后，可以把鬼从下方箭头左面带到上方 A 门再困住，20步安全完成。也可以在鬼还留在下方时先按 A 开出口，这时主动引它离开堵路处，自己领着它从上面绕回，18步安全完成。两种都是完整解。若先上去唤鬼，也有26步的补救，不把最短的取物先后说成唯一顺序。

| 为何保留 | 对照结果 |
| --- | --- |
| 箭头 | 禁止正向过口无解。普通门的最短同为18步，但另有20步能从右向左退穿，把鬼留下在右侧结束；原图无法以鬼在右口的状态完成。改空口或实墙均无解。 |
| 钥匙房的 A 门 | 拿掉这道门，熟悉的“先困住、保持困住、再拿钥匙”立即成为18步解；原图不能如此完成。 |
| 按钮上方的 A 门 | 最短用不到实困，但取物后20步实困也可走通。删上方(4,0)仍能18步，却同时删掉了这条真实备选。所以保留。 |
| 左侧空间与按钮 | 打开左室，让玩家能从出生先向上看出口，再折回共20步。删去左侧第二按钮之后，上述两种回程和普通门的右侧停位仍成立。目标前室折向上，最终14格。 |
