# 分开一列守卫，再重新组织内外通路

1. 外环围住内室，内室钥匙通向外角1门目标。A开北口会关东口，左侧单向入、底部普通出；两只鬼在北口内同列，另一只影响横向通行。
2. 自然会从北口一次引走全部守卫，再进内室取物；但队列在转角分开，后面的鬼可能留在钥匙口，另一只还会妨碍进入。
3. 待检验发现是不能把内外鬼分别当作完成：先利用开口和转角重新分列，再决定从哪处入口进去、哪处保护出来。单向入口若让返回依赖预先安排，才有方向主题的价值。
4. 此前双叶取物稿虽然安全，却主要重复课程46的停位与未来返回，暂不替换它。这次换为共有内室与排队关系，不把加一只鬼或更长路线当增强。若仍是外围追逐顺路取物，或箭头原图可完全不用，就不接入。
5. 5×5连续地面，内外环自然分区，无零碎虚空；单A、两处控制、普通门、1门、钥匙与一个方向口，只有已出现元件，出生不在追逐中。
6. 首轮只比较右守卫及内钥匙的三个明确位置，不增加新机关。原图全解限制、箭头普通／墙替代及完整普通方案各自核查；重合或先判胜捷径直接否决。未有真人质量反馈。
