# 内室交接：课程57的取舍

2026-10-26。采用25格、三鬼、单A两处控制与一个普通门的版本。接在《接力》之后、首次钥匙之前，继续已有元件，作为共享空间的首次三鬼任务；没有真人质量评价，不进入正式地图集，也不声称高级新机制突破。

自然计划是开北门引鬼，绕到普通门进内室。少一次北A的11步安全前缀确实可以进室内，但门外追者堵住返回，东口却关闭，快搜与参考都穷尽无续解。正确参考先按两次北A：门恢复原相位，队列却已经推进。先从左口抽出中鬼，把它留在普通门外，再进入调动内鬼；借东向争位离开，关东开北，最后由北口进目标。区别不是多按一次的计数谜，而是进入前要同时准备队列和离开方向。
