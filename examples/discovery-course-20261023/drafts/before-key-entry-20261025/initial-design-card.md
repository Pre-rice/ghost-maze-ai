# 取近物之前先准备远处

1. 右侧目标被守卫挡住，还需要左室钥匙；出生在中间，左侧0门后是看得见的近任务。
2. 若先拿近钥匙，0已消失，左鬼会跟回中部；此时再到下方诱导右鬼，原本可用的普通门出口被左追者看住。
3. 预期应在进入钥匙室以前先从中部下侧引右鬼，让普通门暂时保护；再去左室取物、带追者经过上路进入已腾空的目标侧。
4. 只用0、1、一个普通门与两鬼，在已有消失门经验里继续比较“什么时候开始取物”，不引新字母、方向或更多鬼数。
5. 先用15格双排骨架核对完整计划，骨架的长直轮廓不能直接交付；若关系成立，再折叠空间、内移目标与清理无信息路程。
6. 先查原图“右鬼未准备即过0”的全部普通通关，再查0普通替代与去左鬼；不以参考顺序或短解推定必须，未有真人评价，不自动发布。
