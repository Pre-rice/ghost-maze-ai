# 一处安置空间，两次不同用途

1. 下层钥匙前的守卫会贴近入口楼梯，右端守卫挡着目标；上层只有一个普通门保护的位置。自然先把左鬼带上去，再取钥匙开右侧1门。
2. 右鬼也需要处理，但同一上层停位已被占用。下层取物后虽有新空间，却不能从原侧安全安置，需要先把上层旧鬼召回并另留在分叉。
3. 待检验发现是先完成的上层安置必须撤回，将那份空间让给另一只鬼；单向分叉只许由外回楼梯，必须准备新返回条件，不能从楼梯反向绕过守卫。上层A最后封住下层分叉，让留下的鬼不再攻击目标通路。
4. 这不是声称楼梯独有机制突破。54已支持一次搬运，这里检查是否形成真正的停位替换与后续空间开放；若可以各自绕路或直接同时留两鬼，就不作续篇。不以必须上楼次数代替趣味。
5. 低层10格、上层3×3，两个鬼、一钥匙、1门、A与普通门、一方向口；没有新元件，初始冷。短走廊的距离用于错开两只鬼的追击，尚未当作不可精简结论。
6. 手工只检原图与方向、上层保护和资源入口的有限对照；先看完整普通通关，再做事件限制、去终点与编号。错误规划如只给一条失败后缀，不能称无续解。未入课程、未有真人评价。
