# 同室两用：课程58

2026-10-26。采用下层9格、上层6格的15格版本，双鬼一钥匙，1门、单向口、普通门与A，26步两条原始最优、两种含停顿鬼轨迹。接在首次楼梯54之后，只做课程试验，没有真人质量评价，不入正式地图集。

原假说是“先把第一只永久安置上楼，之后必须召回让位”。实际最优没有先错一次：第一次走左侧小环，让追者继续跟回楼下，借单向分叉留住；第二次走右侧小环，把另一追者留在普通门后，再从上层关A保护下层返回。同一小室的用途改变，才是希望延续上一关、又打破永久停车习惯的地方，不以切层次数当新意。

若沿用永久停车，8步安全前缀仍可用26步重新调动后通关；快搜与参考都有证书，实际电脑输入也完成了这条34步恢复。不能把它写成无解。只有坚持上层原停位始终不腾空，才穷尽无续解。原图禁止鬼返回下层、要求最后两鬼都在上层、从不操作A的三个完整查询也分别无解；范围明确为无伤、无合并及去终点到达安全。现图282个非致死可达局面实际无合并，因此不是靠排除一条非最优合并捷径得到这些结论，也不把所有错路无合并升级为通用要求。
