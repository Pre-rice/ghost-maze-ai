# 双庭与中桥：私人构思

1. 钥匙在左庭，目标在右庭；右庭守卫占住从上口进入后能接近的两个方向，不能只从箭头绕过去。
2. 自然会先拿钥匙、按A开放上桥；但若右鬼仍在原处，上桥尽头无法继续，A同时关闭了可从左侧引鬼的中桥。
3. 希望发现的是先从左庭经中桥吸引右鬼，让它离开右庭，之后再关闭中桥并改走上方单向口；通行方向改变了对守卫的接近面。
4. 左庭另一只鬼既威胁钥匙，也会跟向中桥的诱导；检验它是否只是独立前置，若是则先减去而不称两鬼纠缠。
5. 两个三乘三庭院、三条相互隔开的桥；只用已有A、钥匙和1门，加两个相反方向口。先比较完整玩家计划，不能因箭头必要就交付。
6. 与50、46、51及侧入的实际新关系比较后才决定是否有课程位置；不为增加关数重复相同接近思想，没有真人评价。
