# 两次经过的保护对象不同

1. 左右各有一把钥匙，最终需回到左下2门；A开放上桥时，右钥匙的入口关闭。
2. 先将两鬼引到中部，再关A能暂时安全拿左钥匙；若立即穿上桥取右钥匙，最后的下方返回会撞到先前停在左庭的鬼。
3. 希望发现的是离开左庭前要再引出旧鬼，让它留在上桥；右侧再切A会封住上桥、开放钥匙，同时释放中部守卫，接下来借下方单向口回去。
4. 同一组A不能同时完成两项保护，第一次完成的停车仍须重新使用；相反，能放开的追者并非都要再困住，只需安排它跟不到最终返回口。不是给同一路线机械走两遍。
5. 18格两庭三桥、双鬼、两个A控制、两钥匙和2门；上方先试普通门减少重复箭头，下方的方向限制必须改变完整取物计划。
6. 与现行保护交接、方向回程和控制入口题分别比较；若仍只是明显装置逐只困鬼，或方向普通替代不改变完整办法，则不增加课程关数。未有真人评价。
