# 关门后的余步：私人构思

1. 目标在左下短支口，两只鬼分别占左侧两条接近线；右侧A同时交换上下通路。
2. 已知经验会建议先开路再引开守卫，但直接从上侧进入会让另一只鬼堵住返回；两条通路不能只逐条看。
3. 希望观察的是关A挡住视线的当步，较远鬼仍沿旧目标靠近一格，腾出之后进入的距离；不能假定鬼会穿过刚关闭的门。
4. 只用已有A、墙与两鬼，不为了补“关闭仍追一步”而做固定操作示范；若一条显然的绕行已解释完整方案，则不接入。
5. 布局初稿为上下两个五格带和一格目标支口，先检验完整计划及两鬼作用，再决定是否有课程位置。
6. 不按解长、A必要、两鬼必要或物理合格预判趣味；没有真人评价，不自动发布。
