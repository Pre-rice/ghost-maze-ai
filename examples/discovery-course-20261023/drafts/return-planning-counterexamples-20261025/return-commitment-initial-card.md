# 带追者返回以前，先前的停车已不够

1. 出生附近的2门需要左右两钥匙，远钥匙区域仅能经上方1门进入，下方箭头只能用来返回。
2. 左鬼引到门外即可拿近钥匙，玩家自然会认为这一侧已处理完毕；但它停在返回口旁，带着远处追者回来时会堵死进入。
3. 预期要在进入远处取物前重新招回左鬼，让它跟随离开旧区域；随后两只鬼在右侧争位，远处追者接管追逐，再从箭头返回。
4. 与早期再借同样认识旧鬼可重用，但这里不靠更多字母组或独立两次困鬼；取物先后、单向返程和持续追者共同约束准备时间。
5. 去掉旧稿的局部A、第二个诱导门和无效中桥；手工改为两个小区域绕一格中空成环，17格，一普通门、一箭头、1／2门、两鬼两钥匙。
6. 所有普通通关的回程前提需另做历史查询，不把最优中的提前召回写成全解定理；普通箭头替代、去右鬼与去1门分别作为不同反例。无真人质量评价。
