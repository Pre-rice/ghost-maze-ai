# 同一把钥匙与未来视线

1. 作为首次钥匙问题之后的完整应用，目标仍要把同一只鬼换到另一边；不单开“两扇1门”的机制演示，不动用户确认的《换边》原码。
2. 尝试在钥匙室下侧增加一扇1门。原计划拿钥匙立即离开，再开A从下侧引鬼；未打开的数字门会挡住这条未来视线。
3. 预期发现不是额外捡物或多绕一圈，而是在离开钥匙室前准备以后需要的通路；同时会实际经过两扇1门，观察同一钥匙可以继续使用。
4. 旧《回望》用0门和两组机关提出更复杂的准备时机；本题如成立，在单鬼、单A、已熟悉的取物返回中先支持较简单的预备判断，不继承旧图好评。
5. 所有门、钥匙和回程结构可见。确认关A后能否补救、先取物后再开新门是否总能完成，不把一个失败后缀说成全部无解；钥匙是数量下限，绝不按消耗或“恰好一把”解释。
6. 只试三处局部数字门位置并对照原图；新增门若只挡一下后必然顺手打开、没有改变计划，或让原流程更长而未增加判断，就不采用。视觉保持已认可轮廓，重新审全部最优与实际入场。
