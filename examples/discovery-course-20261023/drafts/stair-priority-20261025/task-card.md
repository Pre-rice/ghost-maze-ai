# 落点争位的完整任务试构（未接入）

1. 钥匙在上层，目标1门在下层出生旁；上下层初始各一鬼，两个楼梯的端点影响返回时能否安全落地。
2. 预期保留一鬼在下层北端，使玩家从南端回来时它还相隔两格；楼上鬼抢落点，让楼下鬼没有跟上，之后两者在另一端换位。
3. 原图禁止优先争位与普通暂存方案要分别核对；去掉一鬼或强行改落点不当作原图必要性。若借位自动发生而玩家无需安排，不能称顿悟。
4. 玩家计划若仍只是走唯一开放楼梯、沿唯一环路拿钥匙、再沿唯一环路返回，结束为构件，不因跨层和必要性接入课程。
5. 不增加教学标语或更多机关来遮掩线性。目标和钥匙只支持完整往返，不靠多绕路当推理。
6. 只做原生规划与事件诊断；未通过设计自审之前不做发布证书、网页试玩或新课程ID。
