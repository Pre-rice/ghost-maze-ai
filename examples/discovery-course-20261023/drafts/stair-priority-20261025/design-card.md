# 先审落点争位，不把跨层事件当完整谜题

1. 一个鬼留在楼下的楼梯端点，另一个鬼在楼上追击；玩家离开楼上端点时，仍看得见新位置的楼上鬼先占落点，楼下鬼不能跟上来。
2. 若把这个现象直接做下一关，玩家可能只是再看一次已经在再借等图里用过的优先争位；跨层本身不足以证明新认识。
3. 先对照普通平面T形通道的同一局部过程，确认不是边缘规则，也避免把已知借鬼重新命名成楼梯技巧。
4. 可能的后续价值是留下楼下的鬼，供取物回程再次使用；必须先构成真实整体任务，能解释为何不能把它一起带走，不能先指定“必须留住”再当趣味证明。
5. 只用已有追击、争位和楼梯；这个局部证明不加入课程，不加一句规则一关的演示，不改变54。
6. 若普通平面情况即可完整解释局部关系，保留作为机制核验；没有新的完整玩家计划之前，不包装成新题或再搬运一次的续篇。
