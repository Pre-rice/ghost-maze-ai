# 先延续同A的完整问题，撤下长关适配

本次仍为25关。在首次A的37之后加入新关45，再进入《错位》的A/B；原75步《换岗》课程变式44从当前流程撤下，原图、证据、正式地图集与用户原评述均保持。当前关序以course-order为准。

此前加入44，是想把数字门消失后的保护交接与两钥匙放进完整问题，并保留用户图四条最优的主要角色流程。继续比较后发现，改近目标能降到49步，却也跳过了最后一次回收和保护交接；这不是纯粹减少赶路。移动下方控制又会封死后路，增加控制则仍需67步。原稿没有因此失效，但没有足够理由为补两钥匙规则而在当前关序保留长执行。它作为课程试验撤下，不是撤销用户对原《换岗》的认可，也没有证明真人一定嫌它长。

新构思一度仍带0门和钥匙。完整替代查询发现，左侧普通门可以让两鬼分别安置，18步完全不按A；撤掉该门后，虽然A控制都必要，仍有同20步完全不经过0门的方案。不能把“0改普通门后计划改变”说成0就是整个问题的核心。因此继续去掉数字门与钥匙，不把它们包装为新的交接发现；新关只使用既有普通门、两鬼和一组A。

现版45为13格、17步两条最优。目标通路初态已开，两个守卫却挡住接近；玩家需要先安排中央停位，再切门并转到另一处控制。早先的下方操作位置在恢复门态时会释放贴近的鬼，所以两个同字母按钮并非一直可以互换。第一只鬼的左右两套引动都保留；右侧两格不是参考之外的废路，删任一会失去其中一条完整最优方案。上方控制移到通路自身、目标内收，20步稿省掉三次没有鬼位变化的末端行动；全部并列最优的鬼位与共有A门状态按新旧行动映射保持，上方操作位与终点刻意改变，不声称全物理局面等价。

物理上，两处控制、先处理右鬼、移动两鬼均在无伤无复活且不重合的通关范围中必要；全程不使用争位优先也有17步通关。全部两条最优无重合、去终点安全；63个可达安全局面未出现非致死合并，620次排列／变编号后继、外侧(0,4)一步上入、地图及回放码往返通过。普通替代与删减记录见[查询与比较](../drafts/single-letter-control-20261024/plan-and-reduction-comparisons.json)，完整QA在[45证据](../levels/45/evidence.json)。这些只证明对应机械事实，不证明趣味或学习效果。

为什么放在此处：37中普通门先保护操作，45让玩家在一个完整双鬼问题里自己创建保护并换控制位置，之后才用《错位》引入A/B分组及按钮推进。这样连续两题只使用同一种字母机关，而不是第六关见A、第七关马上加B和新任务物品。它包含完整目标、两套引动、可见的错误先手与控制位置选择，未恢复几步执行的困鬼演示。

这也改变了原先对《接力》课程角色的判断：此前由它首次呈现主动关门困鬼；现在该策略在45的完整问题中先出现，《接力》继续将其用于两组保护、目标通路与另一只鬼的先行安排。不是原图评价改变；仍需未知规则真人检验它是否显得重复。地图不改，来源说明已按新前置更新。

不声称45提高了挑战上限，也不因17步、两条解或控制必要而给出趣味评分。当前用途是让少数元件持续支持可探索的完整问题；没有真人尝试、提示条件或顿悟记录。原型、无A捷径、0的普通替代与44减负失败稿统一归档在[同批设计记录](../drafts/single-letter-control-20261024/)，保守归入dual-loop-relay亲缘，未训练、未正式入集、未调用试玩skill。
