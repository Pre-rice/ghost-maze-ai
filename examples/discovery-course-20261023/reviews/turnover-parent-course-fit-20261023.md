# 未接回完整《易手》的依据

第五关来自未评价《易手》的双鬼精简稿。复盘后考虑过把三鬼母图用作后段的第三鬼过渡，但没有采用。

母图的完整规划保留了更复杂的补位关系，然而其参考开头连续七次行动大多只有一条安全去路，最短选择资料也未显示前段有新的完整计划可比较。恢复整列和底部房间会增加追逐执行，不能因为三鬼和24步就视为课程进化。原研究在 examples/turnover-passage-20261019 保持，尚无真人评价。

当前先保留已安排的完整三鬼题，不为补满一次三鬼过渡加入这张母图。这里是课程适配的设计判断，不是用户对原图的差评，也不是证明这张图没有价值。

2026-10-24另试改变出生与鬼阵的12／16步冷开场，并非加载原图检查点。虽然允许不同的首次引动，12步参考仍有8次、两个16步稿仍有10／11次即时唯一安全行动，后段成串追逐的原因没有解决，因此仍不接回；不是只因原出生位置而拒绝。指定入场也没有为这些私稿做完整认证。[原型与查询](../drafts/single-letter-control-20261024/turnover-opening-comparison.json)保留，不当作新手体验或差评。
