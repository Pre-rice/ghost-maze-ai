## 为什么值得单独保留

前两个结构都是“多次标记”（10 步两次、28 步四次），这一版是**唯一最优解、只放一次标记**：

- 唯一解意味着几乎没有试错空间——任何一次多余或错位的动作都会把解变长或变死；
- 只放一次标记意味着玩家要精确判断“在哪一步、在哪个格子放这一次”；
- 它是从 40 格精简到 17 格的结果，四格边缘与整列冗余都被删掉，结构与玩法保持不变。

三版合起来：**10 步两次标记（入门）／13 步一次标记唯一解／28 步四次标记（挑战）**。
