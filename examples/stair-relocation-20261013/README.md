第一次把鬼带下楼，虽然清空了上层，但它停在原楼梯另一端，使原开关再次使用不安全。关键是先重新引它上来，再经另一处楼梯把它送下去；最后借普通门把它留在楼梯外，让原开关恢复安全。

楼梯承担搬运和重新安置的作用。两扇反相门使“先开另一处楼梯通路”和“最后重开目标”互相约束。只有一只鬼，不依赖争位、重合、玻璃或编号。
