预期发现是：**先为两只鬼安排好追逐距离，开B把它们带离出口，再回到安全的位置关B，让终点重新打开。** 上鬼先通过A的保护被重新安置，之后才能放出下鬼；最后的关门又依赖两只鬼都停在上方。它们在这个安排里需要被引出来，而不是始终困住。

设计者核对的两种错误计划都能安全走完前缀，却穷尽续解无解：先开B再去上方引鬼；完成前置安排后，从低一格的位置接近两鬼。后一种会使追逐者跟到回程一侧，无法安全完成关B。机器证据不代表玩家已感到顿悟。

## 调整与保留

最初“旧终点取钥匙后返回”的四稿均无解；另给终点一条侧向入口后，又发现5步直接取物旁路。最终去掉必经钥匙，把终点门和放鬼口改为反相B门，让开路、引走守卫和重新开终点互相制约。

多余的B门和重复B按钮均删去，B移到左侧，与右侧A处在同一横排。上方0门增加的是《回望》已有的提前准备，选择本稿不重复该任务；另一扇0实际只需作墙，因此改为墙。侧向单向门也可删空，唯一最优仍安全、全部五项关系仍成立，故不保留装饰性机关。

19格相对17格稿补齐左右下角，形成完整外轮廓；唯一最优的动作、鬼轨迹与按钮操作完全不变。有限18项合法删改、邻格移动和整行收缩另存，不宣称全局最小：删去内侧(3,2)仍38步，但会消除另一种可安全接近鬼、随后丢失后路的实际方案，保留这一通行空间；B上移一格也不省步，保留横排对称。两处实际整行收缩均无解。前两份把编码容器缩到7格的尝试仅为格式拒绝，不计物理无解。
