# 《换席》

2026-10-16，单层16格、双鬼，**一个A按钮、两扇反相A门、一扇普通门**，没有钥匙、数字门、玻璃或楼梯。中性开局，最优30步，按逐步鬼轨迹区分有三种最优解。未获真人评价，未入地图集。

中央旧鬼先要留在普通门左侧，才能安全到A按钮；按A后，又必须把它调到普通门右侧，腾出接近下方新鬼的条件。但把新鬼引上来后，原本可借普通门脱身的位置正被旧鬼占住，不能把两只鬼依次处理完就结束。

需要带两鬼一起向上走。转向时，新鬼优先占位，让旧鬼留在关闭的A门另一侧；玩家再带新鬼向下，旧鬼也会从中路重新跟上。最优收尾不再按A，借旧鬼优先追击，反过来挡住新鬼，走入出口。若最后再按一次A，也有31步的安全解。

预期发现是“这处庇护不能永久分给一只鬼”：要主动换普通门的使用侧，之后还要撤销临时安置，让两鬼重新参与。同样借用了《再借》的重引与优先阻挡，是否带来新的顿悟仍待实际体验。

## 验证范围

原图分别禁止以下条件，均穷尽无解：第一次按A时旧鬼已在普通门左侧；按A后旧鬼在门右侧、下鬼仍在原房时的准备局面；新鬼开始移动后再次引动旧鬼；新鬼取得可见目标优先。范围是全部无伤无复活路线，允许非致死重合，历史标记进入完整搜索状态。

禁止旧鬼取得优先仍可31步通关，因此“两次相反方向的优先阻挡”只对最优通关必要，没有扩大成全部通关必要。开局先安全引下鬼的五步计划，虽然玩家仍活着，但全部14个后继局面均不能通关；先把旧鬼放在门右侧则能恢复，不是软锁，需要重新安排。

全部三种最优无鬼重合，去掉终点重放仍安全，地图码与操作码逐步往返一致。239个可达局面、1150类动作（含致死动作），两种排列与改编号共2300次后继对照一致。指定从外部(1,3)向右入出生(2,3)，初态及三条最优的内部后继保持；仅验证零钥匙、无区外鬼、外边其余封闭的接入条件，整图另验。

## 为什么保留这些门

普通门改空或改墙均无解。上A门改空无解，改常墙出现15步捷径；下A门改墙无解，改空也出现15步捷径，这些捷径去终点仍安全。两扇反相A在不同阶段提供保护，不能以静态墙代替。删任一鬼后最优降为7或9步，不把这种改图消融替代原图必要性证明。

原草稿的两A按钮、右凸按钮室和目标资格门都未保留。右室并入原A门下方后，同一A门承担按钮保护；再删目标A门，用两鬼的反向让路收尾。单钮19格36步方案收至16格30步，无内部虚空；左上出生省去两步单纯接近。最后45次单项删改，在明确关系、30步上界与最优边界条件下无可接受项，只证明给定编辑集合内的局部结果，不声明全局最小或质量已获认可。
