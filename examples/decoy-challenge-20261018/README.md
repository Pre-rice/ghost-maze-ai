## 为什么它值得作为挑战版

- 入门版 9 步、2 条解、1 次标记，用来理解规则；
- 挑战版 **18 步、唯一解、2 次标记**：先向下绕到最远处放第一个标记，再折返放第二个标记，最后按下按钮回到终点——两次标记的位置和顺序都不能错；
- 两版都是“本体无解”，差异不是难度微调，而是**新规则带来的新解法**。
