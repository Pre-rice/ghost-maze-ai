## 精简与范围

36步原型的上方入口原为字母门，改普通门后省两步，仍保留两处控制的交替约束，因此采用普通门。四扇剩余A门和两个单向门分别改为空／墙／普通门后，或无解，或出现绕过交替安排的捷径；两个普通门也不能直接删空或改墙。移上方按钮到邻格会出现22步、只用两个位置段的捷径。

顶右角及终点右侧三个格子可删而不改变最优长度与控制关系，但会留下凹口及突出终点，故保留完整4×5轮廓。这些格子没有增加任务或必走路线，不宣称全局最小。右按钮邻移不省步，留在钥匙旁形成同一兴趣点。原型右下角两处边界误留为空，不符合设计要求；当前稿明确重建实墙并重验，全部最优动作与鬼轨迹不变。问题原型另存隔离，不覆盖，也不以原型QA代替当前验收。

与《送客》沿用双环放鬼不同，本次检验的是操作位置与返回通路的互相限制；没有使用双鬼冲突优先。是否确实有新的理解与挑战仍需实际体验，不能从证书、门数或长度推出。构思有历史亲缘，训练时保守合并母图家族；没有新增训练或质量标签。
