# 本题的突破与逐格作用

<details>
<summary>剧透：建议通关后展开</summary>

本题希望形成的矛盾是：先把危险隔开确实有用，但隔开之后不能一直保留这个布局。B 的临时保护同时关闭上方入口，恢复 B 时原来停在旁边的鬼又会立刻抓到玩家；右 A 的保护也必须解除，否则无法完成上钥匙的往返。解法要先改变另一只鬼的位置，再让保护职责交接。

选中证书中，上鬼指初始 `(2,0)` 的 index 0，下鬼指初始 `(3,4)` 的 index 1。这个称呼仅描述本证书；全局 `ghost_at` 条件允许任一鬼满足，不宣称所有胜利路线身份分工相同。

| 成功动作 | 本证书发生的事 | 对后续的作用 |
| --- | --- | --- |
| 1–11 | 左侧经过时引下鬼移动，按 C 开桥；从上方把上鬼引到 `(3,2)`，到右 A 站关闭其下边界 | 暂时隔开上鬼，能够进入右下取钥匙 |
| 12–17 | 拿右下钥匙，绕中央引下鬼至 `(2,4)`，在 B 站切换 | 关闭该格的上、左边界，获得临时安全；同时关闭上方 B 入口 |
| 18–28 | 从底部再次进入下鬼视线，把它带到 `(1,3)`；到外侧 C 站关左门 | 为之后恢复 B 提前清空 `(2,4)`，并阻止下鬼跟进左列 |
| 29–31 | 绕到左 A 站，重新打开右 A，关闭下方 A | 主动撤销上鬼的原保护，同时准备它的新安全位置 |
| 32–46 | 从下方引上鬼下移，再让它向左到 `(1,5)`；回 B 站切换 | B 关闭 `(1,3)` 的右边界，完成下鬼隔离；同时重开上方入口 |
| 47–59 | 经右侧回上方取第二把钥匙，再返回二钥匙终点 | 先前鬼位与门态的安排允许安全往返 |

右 A 关闭后 `(3,2)` 左侧仍可通行，是视线条件下的隔离，不是四边全封闭。下鬼临时停留的 `(2,4)` 底边也开放，正是重新引出的通路。C 关闭时 `(1,3)` 右侧 B 还开着，要等最后一次 B 才完整围住。最终上鬼 `(1,5)` 被上 A 与通关路线隔开，其他方向仍能移动；不要把两只鬼都说成永久封死。

三条具体错误计划在原引擎中核验：直接取上钥匙于第 8 动作死亡；右 A 保护后原站重开于第 12 动作死亡；两处暂时安全后不搬下鬼就恢复 B，于第 29 动作死亡。保持原布局直接去上钥匙的路线则被 B 入口阻挡，但有 46 动作补救后缀，不能称为永久无解。这些是人工审查假设，不是用户实际尝试。

逐格作用如下。这里记录地图和证书中的实际用途，不声称每格都有独立认知必要性。

| 格子 | 作用 |
| --- | --- |
| `(1,0)` | 上钥匙死角，拿到后必须返回 |
| `(2,0)` | 上鬼初位、上钥匙入口 |
| `(2,1)` | 上鬼接近的中间站、钥匙往返通路 |
| `(3,1)` | 两钥匙终点，迫使上方往返 |
| `(0,2)` | 左 A 外侧转角，切门后避开中央视线 |
| `(1,2)` | 左 A 站，解除右侧保护并关闭下 A |
| `(2,2)` | 初次诱上鬼的站位、上方 B 内侧、返回分岔 |
| `(3,2)` | 上鬼临时安置格和终点入口 |
| `(0,3)` | C 外站，先开桥后关闭左边界 |
| `(1,3)` | 下鬼最终隔离格，由 C、B 合作封住 |
| `(2,3)` | 双鬼交接通道和引下鬼向左的距离 |
| `(3,3)` | 右 A 站、两鬼转向格，同站重开会死亡 |
| `(0,4)` | 初次引下鬼的视线端，后期返回 B 的转角 |
| `(1,4)` | B 站，临时保护与最终交接 |
| `(2,4)` | 下鬼临时停留格，底边保留引出通路 |
| `(3,4)` | 下鬼、下钥匙初位及纵向追逐入口 |
| `(0,5)` | 左侧旁路、引上鬼向左的视线端 |
| `(1,5)` | 上鬼最终安全安置格，上 A 隔开目标路线 |
| `(2,5)` | 从下方引出下鬼、上鬼向左转移的中间格 |
| `(3,5)` | 右下 B 两侧及纵向诱导转角 |
| `(0,6)` | 下移后向左绕行的转角，为后续引鬼留距离 |
| `(1,6)` | 起点与两次下方诱导后的退路 |
| `(2,6)` | 进入下鬼纵向视线的站位、上鬼下移后的退路 |
| `(3,6)` | 两次下方诱导的转角，维持追逐间距 |

下方区域承担视线和转移几何，认知贡献未必随格数增长。C 小室也可能明显提示围住用途。比上一题多出六格和一个按钮并不是难度证据；待评审的是玩家是否必须重新理解已有安排，还是仍能顺手试过。
