# 《悬置》

2026-10-15，单层15格、两鬼，一个A按钮、一扇A门、一扇0门、一扇普通门；无钥匙、玻璃或楼梯。中性开局，唯一最优22步。**未获真人评价，未入地图集。**

[试玩](https://ghostmaze.novic.cc/?map=AADAGBwcPBgIAAHDgPQgBQAoAgcAmcBSBAEAAAEgIgVQQgSAUAAAAAA)

<details><summary>设计思想与参考（含答案）</summary>

自然会想先把第一只鬼彻底引走，再去处理第二只。但这样会失去安全接近A按钮的条件。预期发现是：故意暂留第一只鬼，把“没有完成安置”当作下一阶段的准备。先开控制室下门引来另一鬼，回到按钮关掉自己的出口隔住它，此后再借上环完成第一只鬼的转移。

这仍属于已有双鬼协作关系的探索，未确认它能带来人的顿悟。相对简单的顺序困鬼，所检验的是提前把一件事做好，反而会破坏后续条件。

</details>

原图分别禁止初次争位、按钮旁暂留第一鬼、关门隔住第二鬼、后期从上环引走第一鬼，四次均穷尽无解；范围是全部无伤无复活续解，允许非致死重合。提前彻底引走第一鬼、首次接触后直接向上退，两条安全前缀也均无后续解。必要性是设计者的因果检查，不代表已达到人的挑战或趣味目标。

全部最优无重合、去掉终点仍安全、地图和回放码往返通过。132个可达局面、含死亡的650类动作，与两种鬼排列及改编号共1300次后继一致。指定从外部(7,1)向左进入(6,1)，再左到出生(5,1)，零钥匙、无外部鬼，入场及完整最优路线的单元内部一致；只验证该条件，整图接入另验。

精简删除了无用左区、北A门和终点A门；最后将出生移到已有回路中，去掉一步纯赶路。再移一格虽能少一步，但尚无保持开局一致的实际入口，因此未采用。最终三扇门均有作用：A门和普通门改空或墙均无解；0门改空出现12步普通解，改墙无解。删任一鬼变为4或10步。删非实体格大多无解，删(4,3)会切断左鬼与核心，产生10步简单解。这里只检查局部删改，未声称全局最小或人类体验等价。
