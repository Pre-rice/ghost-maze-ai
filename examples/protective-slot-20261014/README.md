# 《腾位》

2026-10-14 新候选。单层20格、三只鬼、一个A按钮、一扇A门；没有钥匙、普通门、玻璃或楼梯。开局可以观察，没有鬼在追。未获真人评价，未入地图集。

[试玩](https://ghostmaze.novic.cc/?map=AADAAAD9_PAQEBGZYFJBkAGAAABVUlciUoqAAAAAAABAkBEIBQCgAAA)。网站“求解”可查看全部最优解，当前唯一最优23步。步数与机械必要性不代表人类挑战或精妙程度。

<summary>设计思想与参考（含答案）</summary>

自然的两种想法是先引走左边守路的鬼，或者只按A把出口鬼困在门下。两种实际前缀都进入无伤无复活死局，快环境与原生参考环境分别穷尽核验；这不是只试某一条后缀失败。

关键认识是：**门后的鬼既可以暂作刹车，也可以让位；保护的是位置，不是固定的一只鬼。** 先接近出口鬼再退回，出口鬼仍能看到玩家，优先进入门下。左侧鬼被它挡住，另一只左鬼却能继续靠近，原来的间距被改变。关A后，再从侧边释放队列，让另一只鬼接替门后的保护位置；出口鬼改为回程追者。

这与《再借》有亲缘：同样重新引动已安置的鬼，但这里是解除阻挡、校准间距与交换保护位置。这个新认识只是设计者预期，尚未获得用户的顿悟反馈。

验收已证明唯一最优，全部最优不经过鬼重合，去掉终点后重放仍安全。原图禁止初期优先制动、禁止出口鬼真实停住再离开且由另一鬼真实停位接替，两项分别穷尽无解；不以“经过同一格”冒充保护。164个可达局面的815类动作含死亡，与六种鬼排列和改编号共4890次后继对照一致。

真正从外部(6,1)向下进入(6,2)，零钥匙、A初态关闭、无外部鬼，入场与23步参考全程单元内部一致；只验证这个接入条件，整图仍须重新验收。地图与回放码逐步往返一致，按钮依附合法。

经济性检查删掉了资格钥匙、整组B、第四鬼、普通门及两扇A门。最终去掉A按钮或把唯一A门改为空／墙均无解；删任一鬼，最短分别变为8／14／16。删非实体格时，除(3,3)删除会割断左鬼与核心、产生14步简单解外，其余均无解；不声称全局最小。
