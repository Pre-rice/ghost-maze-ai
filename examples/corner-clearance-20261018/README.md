# 《腾挪》

单层19格、双鬼、一把钥匙；一个A按钮控制两扇A门，另有一扇普通门和终点1门。最优41步，三种保留移动时机和停顿的鬼轨迹。**新候选，尚无真人评价，未入地图集。**

<details><summary>设计预期与参考（含答案）</summary>

左边门角看起来是现成的困鬼位置，但先困住最近的鬼，会让另一只占据唯一出路。先在右侧追逐中借争位分离两鬼，留一只在右边，让另一只进入左角，才保留取钥匙的空间。

左角的保护也不是最终安排：按A会让角里的鬼直接走到按钮位置，所以取钥匙后还要把它引到普通门上方。这个新停位开放了A的操作，却封住通往钥匙的上方区域；不能先做完停车再回来取物。最后重新引动右侧鬼，绕回终点。

预期重点是**同一处安置同时决定后续的活动区和开关条件**，不以再次困鬼、必要事件数或41步声明已产生新的顿悟。《再借》已有招回挡鬼，《换边》已有门两侧换位；本稿需要真实反馈判断这次整体关系是否足够有挑战。
