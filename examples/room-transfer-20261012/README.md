# 《换边》（2026-10-12）

11 格、单层、一只鬼、一个 A 按钮、一把钥匙，普通门与数字门各一扇，两扇 A 门反向联动；无玻璃和单向门。不改本体规则，没有训练模型。

[试玩](https://ghostmaze.novic.cc/?map=AWM4wZDw4UECAwNjWIMLkwIvA8MCF-4vAqwMILCFs0T4C0sDiMnEAQA)。完整地图、解法与后续评价加入[统一目录](../../../ghost-maze/docs/ai-map-catalog.md)。2026-10-12 用户评价“不错”、比前面几题更巧且简洁，但解法仍简单、容易想到；认可其甜点单元／靠前简单关价值，尚未达到主线挑战目标。详见[反馈与后续方向](../../docs/room-transfer-review-20261012.md)。

实际来源是手工逆向构造“保护鬼的位置同时影响钥匙与目标入口”的冲突，再用完整状态搜索找捷径。初稿 12 格有连按 A、绕上方小圈的 20 动作捷径；增加下方数字门也未消除捷径。删去上方一格后形成 28 动作的换位关系，再把下方冗余数字门改为空；四项原图关系都保留，最终只剩一个数字门。之后执行条件内精简：32 项尝试与最末审计，接受编辑零，预算未决零；不宣称全局最小。

此前有限提案中的双数字门、零钥匙门和原地连按 A 的候选没有作为精品交付。它们虽有机械依赖，仍主要重复追逐绕圈。本题也不凭事件限制、路线长短或局部精简获得质量标签。

沿用 `dual-loop-relay-v1` 家族与拆分组，细分关系记为 `room-mediated-door-side-transfer-v1`。从零手工构造不自动意味着与既有回路题独立；源图与所有同源变体共组，未扩大独立高质量训练样本数。生成时 `humanQuality:null`，后续用户评价另存。

[28 步无伤回放](https://ghostmaze.novic.cc/?map=AWM4wZDw4UECAwNjWIMLkwIvA8MCF-4vAqwMILCFs0T4C0sDiMnEAQA&replay=AJOILtmM5m-reKM3)，默认暂停、全图。BFS 与 A* 分别证明最短 28 次有效操作，其中 24 次移动、4 次按钮。

设计假说是“先甩开鬼”有两个看似成功的结果，只有一个能继续取得钥匙。初次需要让鬼留在普通门右端，暂时占住目标入口；这样才能关闭钥匙房后口、恢复前口并拿钥匙。拿到钥匙后，第一处保护不能直接带来目标：需要主动重新开放后口，从下方把鬼引回钥匙房，再在按钮处换口，将它引到普通门左端，最后访问目标。相对于本轮负例，重点审查的是同一只鬼与同一间钥匙房的再次利用，及两种保护安排对不同目标的冲突；这仍是家族内的机制探索，不宣称绝对新颖或已获人类认可。

四项原图限制分别由 BFS 与 A* 穷尽无解：至少四次 A 操作；鬼先从 `(3,2)` 到普通门右端 `(3,1)`，再取得钥匙；随后从 `(3,2)` 返回钥匙房 `(3,3)`，最后从 `(2,2)` 到普通门左端 `(2,1)`；取得钥匙后按 A 开后口、鬼回房、按 A 关后口、鬼到左端这一有序子序列。仅证明这些事件或有序子序列，不能外推成唯一完整解法或人类认知难度。

两条实际安全前缀的对照由原引擎 BFS 与快 BFS 核验：`LLURUR` 把鬼放在普通门左端，虽然当下存活且靠近目标，但之后穷尽无解；`LURURLDLD` 把鬼放在右端，仍有胜利后缀。不是只拿一条错误计划失败来推断玩家体验；原图全部无伤解的右端先于钥匙、回房后再到左端关系也另有受限搜索证明。

普通门改为空，出现 15 动作、无需四次 A 的追逐路线；改实墙无解。不能沿用早期带下方数字门的“普通门改空无解”结果，那个对照属于另一地图。数字门改空或普通门，出现无需钥匙的 6 动作捷径；改实墙无解。两个 A 门逐项改墙的结果另存：前 A 改空 9、改实墙 32；后 A 改空 10、改实墙无解。不能声称每项改墙都使地图无解，也不能把更长替代解误写成冗余检查未通过。

唯一按钮删除、唯一钥匙删除均无解；删鬼后有 7 动作解。原图的额外下方数字门删除后，参考路线、最短 28 与四项关系都保留，因此没有保留这个门。原始构造与证据另存，不覆盖旧图。

空间组织：左侧是按钮与返回路径；上方普通门两端是不同阶段的安置位置；右下钥匙房既是初始障碍，也是后来的中转位置；底部两格提供拉动后切换视线的站位；右侧钥匙门把取得钥匙与目标访问连接。没有证明每格独立具有认知价值。
