# 内部分析：双开关、诱导、隔离与重新配置

本文件含剧透。用户尚未试玩；机制证据不能代替质量反馈。

## 产生过程与谱系

参考第一张组合题及用户优化图的操作依赖，扩大为双开关提案。固定种子 `8100892`，10 万次提案循环，部分循环因模板条件跳过；实际归类结果为 65,599 个无伤无解、12,164 个弱序列、2 个未用钥匙，以及一个待审候选。不能称生成了 10 万张有效地图，也不以留下比例衡量质量。

原始序号 `59215`，20 格、52 次动作；候选原含一把钥匙、一扇数字门及六扇字母门。逐项消融后，删除钥匙/数字门、两扇冗余字母门、五格，保留 15 格、一只鬼、两个按钮、四扇字母门和一扇普通门。177 次精简尝试，最后审计 42 项，未决 0；只证明声明单次编辑范围内收敛，未证明全局最小。

最短为 46 次成功动作，其中 40 次移动、6 次按钮；去鬼对照 16 次。体力仍为默认 100，终局剩余 60。这些成本用于核对和诊断，不当作趣味分数。

按钮词 `BAABAB` 与用户优化图相同，不据此宣称发现了完全独立的新解谜思想。具体差异在普通门对鬼的隔离，以及隔离后仍需重配两组门。未来数据与旧题采用同一 `dual-loop-relay-v1` 拆分组，不把相关改图当作独立泛化成绩。

## 具体关系

坐标沿用数组索引：起点 `(4,5)`，鬼 `(4,2)`，终点 `(5,2)`；A 按钮 `(3,2)` 朝右，B 按钮 `(2,5)` 朝左。

| 边 | 初态 | 操作作用 |
| --- | --- | --- |
| `hWalls[3][4]` | B 关闭 | 切换鬼守出口的下侧通路 |
| `vWalls[4][4]` | B 开启 | 与上表 B 门互补，改变中段横向通行 |
| `hWalls[5][4]` | A 关闭 | 下侧诱导口 |
| `vWalls[4][3]` | A 开启 | 与上表 A 门互补，改变回到 B 的通路 |
| `hWalls[2][1]` | 普通门 | 玩家可过、鬼不可过且挡视线，提供隔离出口 |

选中最短证书的过程：

1. 先 B 配置通路，去 A；第 8 次动作按 A，开放下侧诱导口并关闭中段另一条路。
2. 从下侧把鬼引至 `(4,4)` 停住，回来第 17 次按 A，才能重新去 B。
3. 第 22 次按 B 放开中段；贴身引鬼走左侧。第 31 次玩家到 `(1,1)`、鬼到 `(2,1)`；第 32 次穿普通门到 `(1,2)`，鬼停在 `(1,1)`。
4. 隔离后还不能直接出门：第 35 次按 A、第 40 次按 B，重新配置通路，才抵达终点。第 33～46 次鬼都停在 `(1,1)`。

最短动作串：


## 原图受限搜索与改图对照

每项单独搜索，不把条件合并后的无解当作各自必要。A* 和直接调用原引擎的 BFS 均完成核对。范围是固定规则、体力 100、无伤、无复活、全信息物理状态；不是迷雾知识策略证明。

| 原图禁止条件 | BFS 结果 | 能支持的结论 |
| --- | --- | --- |
| 第三次按 A | 穷尽无解 | 至少三次 A |
| 第三次按 B | 穷尽无解 | 至少三次 B |
| 有序子序列 A→B→A | 穷尽无解 | 存在回来操作 A 的必要，子序列不要求连续 |
| 有序子序列 B→A→B | 穷尽无解 | 同样必须回来操作 B |
| 鬼到 `(1,1)` | 穷尽无解 | 避开这个安置位置无法无伤完成 |
| 鬼到 `(1,1)` 后再按 A | 穷尽无解 | 安置鬼后仍须操作 A |
| 鬼到 `(1,1)` 后再按 B | 穷尽无解 | 安置鬼后仍须操作 B |

这些证据排除“机关预先全开，再一次绕行结束”，但开关交替本身仍不是趣味证明。操作关系需结合真实轨迹、门态和玩家/鬼位置解释。

| 修改地图 | 无伤最短结果 |
| --- | --- |
| 普通门改空地 / 实墙 | 两者均穷尽无解 |
| `hWalls[3][4]` B 改空地 / 实墙 | 12 / 无解 |
| `hWalls[5][4]` A 改空地 / 实墙 | 31 / 无解 |
| `vWalls[4][3]` A 改空地 / 实墙 | 38 / 无解 |
| `vWalls[4][4]` B 改空地 / 实墙 | 15 / 无解 |

普通门的通行不对称确有作用。四扇字母门改空地均简化成本，但不能说“改掉任何一扇门原图都不可解”。修改地图改变规则局部条件，不能混称原图的必要事件证明。
