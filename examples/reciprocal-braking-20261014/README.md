自然想先向下脱身，或从近处直接去按钮。这两种实际安全前缀都经快环境与原生参考穷尽续解后无解；不是只尝试某一条后缀失败。

预期发现是：**同一对鬼可以交换帮忙和受挡的作用。** 先让右鬼优先追来，阻住北鬼；随后重新接近北鬼，让它优先追下去，阻住右鬼。右鬼因此停在未来的A门一侧，北鬼继续跟来。最后从普通门的一侧到按钮，北鬼停在另一侧，才能安全切门并返回目标。

直接从上方到按钮，跟随鬼就在身后；按A会死亡，转入普通门则会让鬼占住按钮。普通门不仅用于逃跑，接近开关的方向也是安排的一部分。

与《再借》的单次借鬼、《暂驻》的同一鬼两次优先有亲缘，这里两鬼互换作用。它是否带来新意与挑战尚未获用户评价，不能用事件必要性或17步替代真人体验。
