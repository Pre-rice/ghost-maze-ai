# 内部设计分析：两处鬼位与保护的交接

本文件含剧透。本轮仍是候选；下列机械事实不等于玩家已认可质量。

## 可观察的死结

终点 `(1,1)` 被一只鬼占着。最终 B 站 `(2,1)` 从右侧接近会受到出口鬼威胁，从下侧接近会受到另一只鬼威胁。两条入口由 A 互补控制：放开下入口就封住右入口；B 同时控制终点门和右侧捕获室的两面门。关闭 B 能保护右侧站位，却把终点关上；重开 B 又释放那间捕获室。

这里的矛盾涉及入口、鬼位和操作站位。单纯把门调到“都能过”的想法无法同时处理这些条件。

## 四个相互准备的阶段

1. 从右下 `(4,4)` 开 B，去 `(4,1)` 露面，再退到 `(4,2)`。出口鬼先走到 `(2,1)`，失去视线后仍向刚才的玩家位置追一步，停在 `(3,1)`。A 的下入口仍关闭，下鬼没有被同时放出。
2. 回到 `(2,5)` 按 A：下鬼到 `(2,3)`。立即再按 A，把它引近到 `(2,4)`，同时恢复右上入口的门态。此时再转弯，下鬼沿玩家刚才的位置追，而不会直接截住玩家下一处转弯。
3. 绕至 `(3,3)`、`(4,3)`、`(4,4)`，让下鬼停在 `(4,3)`；按 B 关闭该室两面门，保证按键和撤离安全。但这次保护也关上终点门，不能就此结束。
4. 回 A 站重新配置，打开下入口并隔住上鬼。走至内侧 B 站 `(2,1)`，从这个位置重开 B。下鬼的室门恢复开启，但它没有看到当前位置；上鬼仍被 A 隔着。最后进入终点。

## 几种合理计划为何受阻

以下前两条是设计者提出的具体路线，不冒充实际人类行为，也不推广成整个策略家族都已失败：

- 直接开 A 再向上走：第二次动作死亡。
- 已先移开出口鬼，只按一次 A 后立即右、上转弯：第二个转弯动作被下鬼截住。右移当回合安全，但该固定前缀的后续搜索穷尽无解；改为先第二次按 A，则仍存在胜利后缀。

更广的排除来自原图全局限制，每项分别搜索，范围均为体力 100、无伤无复活、全信息物理状态：

| 单独禁止的事件 | BFS / A* 结果 | 能支持的结论 |
| --- | --- | --- |
| 出口鬼 `(2,1)→(3,1)` | 穷尽无解 | 不能始终把这只鬼留在原来的目标区域 |
| 第二次按 A | 穷尽无解 | 全局最多一次 A 的方案无法完成；不能只放开入口后保持门态 |
| 右下按 B 时有鬼在 `(4,3)`，且下侧 B 门关闭 | 穷尽无解 | 无法绕过这一带位置条件的保护操作；事件本身不指定鬼身份 |
| 上述保护后再在原 A 站操作 | 穷尽无解 | 捕获不能作为最后一次配置，后续还须重配 A |
| 保护、重配 A、最后在内站按 B 的有序子序列 | 穷尽无解 | 不能只在右下预先开好 B 再一趟到终点 |

选中证书中，右室被捕获的是原下鬼。搜索禁止条件中的 `ghost_at` 指任一鬼，结论不擅自加强为每条解都具有相同身份分工。

## 突破改变的前提

机关操作的安全性取决于鬼的位置、视线和玩家操作站位。玩家先把出口鬼移入可被 A 隔开的侧格；再主动引近另一只鬼，让它跟随刚才的位置转弯，并利用 B 在右室截住它。随后还需要重开同组 B，但换到内站后，释放右室与当前安全可以同时成立。

“原地按按钮让鬼更近”是已有思想，本题没有把它单独当作新巧解。待玩家判断的是：它与前置移位、B 的捕获、A 的再配置及换站重开共同作用后，是否形成了值得推敲的整体。
