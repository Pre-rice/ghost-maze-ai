先把远端鬼引成身后的追击者，再去引动中间鬼。两次让仍看得到玩家的鬼优先跟随，将中间鬼留在侧格。之后把中间鬼引进上方短通道，暂驻在出口下方；另一鬼继续追，玩家从左侧进入按钮格。

按A关上来路，隔开当前追来的鬼，同时打开出口。暂驻鬼仍挡住上行通路，因此玩家要先从右侧靠近，引它往下，再绕右列回到上方；不能把“已经安置好”当作永远不再动它。回放具体转弯不是唯一完整走法。
